# Spreader - 00 START HERE

## Purpose
Spreader widens stereo images while preserving mono compatibility. It uses mid/side-style processing and a low-frequency bypass to keep bass centered.

## 10-Minute Orientation
1. Insert Spreader on a mono source.
2. Increase Spread to hear width.
3. Set Low Bypass to keep bass mono.
4. Use the vectorscope and phase meters to monitor stability.

- Spread at 0/50/100 on mono source.
- Low Bypass sweep to find best bass focus.
- Separation effect on vectorscope shape.

## Mix Integration Checklist

- Use light compression for dynamic stability.

## Troubleshooting Matrix
- Harsh attack -> soften exciter/attack, reduce brightness.
- Thin body -> increase resonance or body emphasis.
- Too wide -> reduce spread, check mono.
- Too static -> add modulation or automation.
- Muddy low end -> reduce low-mid buildup or use high-pass.
