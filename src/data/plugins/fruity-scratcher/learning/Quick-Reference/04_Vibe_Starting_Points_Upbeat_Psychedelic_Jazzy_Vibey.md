# Fruity Scratcher - Vibe Starting Points: Upbeat, Psychedelic, Jazzy, Vibey

## Overview

This guide covers **four additional vibe targets** for hip-hop/R&B/pop-hip-hop production using Fruity Scratcher:

1. **Upbeat** — Energetic, confident, high-tempo feel
2. **Psychedelic** — Trippy, disorienting, experimental textures
3. **Jazzy** — Swung, laid-back, organic groove
4. **Vibey** — Smooth, sustained, atmospheric flow

Each section provides parameter starting points, setup instructions, and what-to-listen-for checkpoints.

---

# UPBEAT VIBE

**Character:** Energetic, confident, bright, rhythmic, aggressive scratching.

## Upbeat Setting #1: Rapid Vocal Cuts

**When to use:** Hype sections, hooks, or transitions in trap/hip-hop.

### Parameters

| Parameter | Value | Reasoning |
|-----------|-------|-----------|
| **SPD** | 1x to 1.2x | Normal or slightly faster for energy |
| **ACC** | 85-95% | High responsiveness for tight cuts |
| **SEN** | 65-75% | High sensitivity for rapid scratching |
| **Sample** | Vocal stab (0.5-1.5 sec) | "Hey!", "Let's go!", "Yeah!" |

### Setup

1. Load a bright, energetic vocal sample
2. Set SPD to 1.1x (10% faster = higher pitch, more energy)
3. Scratch rapidly in time with hi-hats or snare rolls
4. Use baby scratch or chirp scratch techniques

### What to Listen For

- [ ] Scratches are tight and percussive (clean transients)
- [ ] High pitch adds brightness and excitement
- [ ] Scratching is rhythmic and on-beat
- [ ] No digital artifacts (if present, shorten sample)

### Variations

- **Double-time cuts:** Scratch at 16th-note speed during build-ups
- **Pitch riser:** Automate SPD from 1x → 1.5x during scratch for rising energy

### Pitfalls

- **Don't:** Use low ACC (< 70%)—creates sluggish, non-upbeat feel
- **Don't:** Use dark/slow samples—kills upbeat vibe
- **Don't:** Scratch off-beat—breaks rhythmic energy

### Automation Ideas

1. **Accelerating scratches:** Automate SEN from 60% → 80% during a build
2. **Pitch jump:** Automate SPD to jump between 1x and 1.3x for syncopation

## Upbeat Setting #2: Quick Tape Stop (Build-Up)

**When to use:** Before a drop or energetic section.

### Parameters

| Parameter | Value | Reasoning |
|-----------|-------|-----------|
| **SPD** | 1x → 0x (automate) | Quick deceleration |
| **ACC** | 80-95% | Fast, aggressive stop |
| **Duration** | 1/2 to 1 beat | Short, punchy stop |

### Setup

1. Insert on drum bus or full beat
2. Automate SPD from 1x to 0x over 1/2 beat (1 eighth-note)
3. Set ACC to 90% for near-instant stop

### What to Listen For

- [ ] Aggressive, sudden pitch drop
- [ ] Creates tension before drop
- [ ] Stops exactly on the downbeat
- [ ] Feels "exciting," not "sad"

### Variations

- **Reverse start:** Follow stop with SPD 0x → 1x (quick restart)
- **Stutter stop:** Multiple 1x → 0x → 1x stutters in 1 beat

---

## Upbeat Setting #3: Syncopated Scratch Pattern

**When to use:** Adding rhythmic complexity to upbeat hooks.

### Parameters

| Parameter | Value | Reasoning |
|-----------|-------|-----------|
| **SPD** | 1x | Normal pitch for clarity |
| **ACC** | 80-90% | Responsive for tight timing |
| **SEN** | 70-80% | High for expressive scratching |
| **Sample** | Drum hit or vocal (< 1 sec) | Percussive transient |

### Setup

1. Load a short, punchy sample
2. Scratch in off-beat positions (between kick/snare)
3. Use transformer scratch (rhythmic cuts with Hold button)

### What to Listen For

- [ ] Scratches create syncopation (add rhythmic interest)
- [ ] Tight timing (scratches don't drift)
- [ ] Complements beat, doesn't clash
- [ ] Adds energy without cluttering

# PSYCHEDELIC VIBE

**Character:** Trippy, disorienting, warped, experimental, layered with FX.

**Critical note:** Scratcher alone is not psychedelic—it requires **FX chain** (reverb, delay, phaser, pitch shifter).

## Psychedelic Setting #1: Warped Pitch Bend

**When to use:** Creating "melting" or "bending" vocal effects.

### Parameters

| Parameter | Value | Reasoning |
|-----------|-------|-----------|
| **SPD** | 0.5x to 1.5x (automate) | Wide pitch range for disorientation |
| **ACC** | 40-60% | Moderate for smooth, curved bends |
| **Sample** | Vocal or synth (2-5 sec) | Sustained sounds work best |

### Setup

1. Load a sustained vocal or pad
2. Automate SPD with **curves** (not straight lines)—use Bezier curves in automation clip
3. Create unpredictable pitch movement (up, down, wobble)
4. **Critical FX chain:** Scratcher → Reverb 2 (50% mix, 3-5 sec decay) → Delay 3 (ping-pong, 30% mix) → Pitcher (±12 semitone range, automate)

### What to Listen For

- [ ] Pitch bends are smooth and unpredictable
- [ ] Reverb/delay create "space" and depth
- [ ] Sounds "trippy" and disorienting
- [ ] No digital clicks (if present, increase ACC)

### Variations

- **Reverse psychedelic:** SPD = -0.8x to -1.2x with heavy reverb
- **Stutter warp:** Rapid SPD changes (1x → 0.5x → 1.5x → 1x) in 1 beat

### Pitfalls

- **Don't:** Skip FX chain—dry Scratcher is not psychedelic
- **Don't:** Use straight-line automation—creates predictable, non-trippy bends
- **Don't:** Use short samples—psychedelic needs sustained material

### Automation Ideas

1. **Random pitch:** Automate SPD with random step sequencer (0.5x to 1.8x)
2. **LFO wobble:** Slow sine wave on SPD (0.7x to 1.3x, 4-bar cycle)

---

## Psychedelic Setting #2: Feedback Loop Scratch

**When to use:** Experimental psychedelic textures (advanced technique).

### Parameters

| Parameter | Value | Reasoning |
|-----------|-------|-----------|
| **SPD** | 0.8x to 1.2x | Slight pitch variation |
| **ACC** | 50-70% | Moderate response |
| **SEN** | 50-60% | Controlled feedback |

### Setup [UNVERIFIED: Requires testing]

1. Route Scratcher output to a Send track
2. Add Reverb + Delay to Send
3. Route Send output BACK to Scratcher input (feedback loop)
4. Keep send level LOW (< 20%) to avoid runaway feedback

### What to Listen For

- [ ] Self-feeding, evolving texture
- [ ] Unpredictable sonic artifacts
- [ ] "Alien" or "broken" quality
- [ ] No harsh feedback screech (adjust send level)

### Pitfalls

- **Don't:** Set send level too high—causes uncontrollable feedback
- **Don't:** Skip reverb/delay in feedback path—too harsh
- **Warning:** Can create loud, sudden sounds—use limiter on output

---

## Psychedelic Setting #3: Glitch Reverse

**When to use:** Creating "broken" or "glitchy" psychedelic effects.

### Parameters

| Parameter | Value | Reasoning |
|-----------|-------|-----------|
| **SPD** | -1x to -0.5x (rapid changes) | Unstable reverse playback |
| **ACC** | 70-90% | Quick response for glitchy feel |
| **Sample** | Drum loop or vocal (2-5 sec) | Complex material for glitch artifacts |

### Setup

1. Load a rhythmic sample
2. Automate SPD to **jump** between -1x, -0.5x, and 0x randomly
3. Create stuttering, unstable reverse playback
4. Pair with Fruity Phaser or Flangus for movement

### What to Listen For

- [ ] Unpredictable reverse stutters
- [ ] "Broken tape" quality
- [ ] Disorienting rhythm
- [ ] Fits psychedelic context (not clean/polished)

# JAZZY VIBE

**Character:** Swung, laid-back, organic, warm, "dusty" feel.

## Jazzy Setting #1: Lazy Tape Stop

**When to use:** Smooth transitions in jazzy hip-hop or R&B.

### Parameters

| Parameter | Value | Reasoning |
|-----------|-------|-----------|
| **SPD** | 1x → 0.7x (automate) | Partial slowdown (not full stop) |
| **ACC** | 25-35% | Low for smooth, lazy deceleration |
| **Duration** | 4-8 beats | Long, relaxed stop |

### Setup

1. Insert on jazz loop or full beat
2. Automate SPD from 1x to 0.7x over 2 bars
3. **Don't go to 0x**—stop at 0.7x for "lazy" feel
4. Set ACC to 30% for smooth curve

### What to Listen For

- [ ] Gradual, relaxed slowdown
- [ ] Feels "loose" and organic (not tight/digital)
- [ ] Maintains some groove (doesn't fully stop)
- [ ] Creates "leaning back" feel

### Variations

- **Swing return:** After reaching 0.7x, automate back to 1x (slow → fast)
- **Partial reverse:** 1x → 0.5x → -0.3x (slow down, then gentle reverse)

---

## Jazzy Setting #2: Swung Vocal Scratch

**When to use:** Syncopated vocal chops in jazzy hooks.

### Parameters

| Parameter | Value | Reasoning |
|-----------|-------|-----------|
| **SPD** | 0.9x to 1.1x | Slight pitch variation (not extreme) |
| **ACC** | 50-70% | Moderate for relaxed feel |
| **SEN** | 50-60% | Controlled, not twitchy |
| **Sample** | Warm vocal (1-2 sec) | Jazz vocal, scat, or ad-lib |

### Setup

1. Load a jazz vocal sample (prefer warm, vintage-sounding)
2. Scratch with **swing timing** (not straight 16ths)—delay second scratch slightly
3. Use baby scratch or slow scribble technique
4. Pair with Fruity Parametric EQ 2: Boost 200-500 Hz (warmth), cut 8 kHz+ (smoothness)

### What to Listen For

- [ ] Scratches have swing feel (not robotic)
- [ ] Warm, vintage tone
- [ ] Fits with jazzy chord progressions
- [ ] Relaxed, not aggressive

### Variations

- **Pitch wobble:** Automate SPD subtly (0.95x to 1.05x) for human imperfection

---

## Jazzy Setting #3: Texture Warble

**When to use:** Lo-fi jazzy texture on loops.

### Parameters

| Parameter | Value | Reasoning |
|-----------|-------|-----------|
| **SPD** | 0.92x to 1.08x (slow LFO) | Gentle pitch wobble |
| **ACC** | 30-40% | Loose, analog feel |
| **Sample** | Jazz loop or piano (4-8 bars) | Harmonic material |

### Setup

1. Load a jazz sample loop
2. Automate SPD with slow sine wave (0.92x to 1.08x over 2-4 bars)
3. Creates "tape warble" or "vinyl wow/flutter"
4. Pair with Effector (vinyl mode) for full lo-fi effect

### What to Listen For

- [ ] Subtle pitch drift (barely noticeable)
- [ ] Warm, analog character
- [ ] Blends with lo-fi jazzy beats
- [ ] Sounds "vintage" or "dusty"

# VIBEY VIBE

**Character:** Smooth, sustained, atmospheric, low-energy but engaging.

## Vibey Setting #1: Sustained Reverse Texture

**When to use:** Background atmosphere in vibey verses or intros.

### Parameters

| Parameter | Value | Reasoning |
|-----------|-------|-----------|
| **SPD** | -0.6x to -0.8x | Slow reverse for smooth texture |
| **ACC** | 40-50% | Moderate response |
| **Sample** | Pad, vocal hum, or ambient (5-10 sec) | Sustained, non-percussive |

### Setup

1. Load a sustained sound
2. Set SPD to -0.7x (reverse at 70% speed)
3. Let it play continuously (no scratching)
4. Pair with Fruity Reverb 2 (50-70% mix, long decay) and Delay 3 (30% mix)

### What to Listen For

- [ ] Smooth, flowing reverse texture
- [ ] Blends into background (not focal)
- [ ] Creates "floating" or "dreamy" feel
- [ ] Doesn't distract from main elements

---

## Vibey Setting #2: Slow Pitch Drift

**When to use:** Creating subtle movement in vibey pads or vocals.

### Parameters

| Parameter | Value | Reasoning |
|-----------|-------|-----------|
| **SPD** | 0.95x to 1.05x (slow automation) | Subtle pitch drift |
| **ACC** | 35-45% | Smooth transitions |
| **Sample** | Pad, vocal, or synth (4-8 sec) | Harmonic content |

### Setup

1. Load a sustained melodic sample
2. Automate SPD with slow, smooth curve (0.95x to 1.05x over 4-8 bars)
3. Creates gentle pitch movement (not dramatic)
4. Layer with static pad for depth

### What to Listen For

- [ ] Almost imperceptible pitch movement
- [ ] Creates "breathing" quality
- [ ] Adds organic feel to digital production
- [ ] Doesn't break groove

---

## Vibey Setting #3: Minimal Vocal Flutter

**When to use:** Subtle vocal texture in vibey hooks.

### Parameters

| Parameter | Value | Reasoning |
|-----------|-------|-----------|
| **SPD** | 1x (with brief 0.9x dips) | Occasional pitch flutter |
| **ACC** | 50-60% | Moderate for smooth dips |
| **Sample** | Vocal phrase (2-4 sec) | Sung or spoken |

### Setup

1. Load a vocal sample
2. Mostly play at SPD = 1x (normal)
3. Occasionally automate brief dips to 0.9x (1/8-note duration)
4. Creates "flutter" or "tape glitch" effect

### What to Listen For

- [ ] Subtle, occasional pitch drops
- [ ] Sounds "human" or "analog"
- [ ] Doesn't disrupt vocal intelligibility
- [ ] Adds vibey character without overpowering

## Multi-Vibe Workflow Tips

### Upbeat → Vibey Transition
1. Start with rapid scratches (Upbeat setting #1)
2. Automate SPD from 1.2x → 0.95x over transition
3. Lower ACC from 90% → 40%
4. Result: Energy drops into smooth vibey section

### Jazzy → Psychedelic Transition
1. Start with lazy tape stop (Jazzy setting #1)
2. At 0.7x SPD, add heavy reverb + delay
3. Automate SPD wildly (0.5x to 1.8x) during transition
4. Result: Smooth jazz morphs into trippy psychedelic

### Vibey → Upbeat Build
1. Start with slow reverse texture (Vibey setting #1)
2. Gradually speed up: -0.7x → 0x → 1x → 1.3x
3. Increase ACC from 40% → 90% during build
4. Result: Smooth vibe builds into energetic drop

## Quick Reference: Vibe Decision Tree

```
What vibe are you targeting?

UPBEAT
├─ Use: High SPD (1x to 1.3x), High ACC (80-95%), High SEN (65-80%)
├─ Techniques: Rapid scratches, quick tape stops, syncopated cuts
└─ Avoid: Slow samples, low ACC, dark tones

PSYCHEDELIC
├─ Use: Wide SPD range (0.5x to 1.5x), Moderate ACC (40-70%)
├─ Critical: MUST pair with reverb, delay, pitch FX
└─ Avoid: Clean/dry signal, predictable automation

JAZZY
├─ Use: Subtle SPD variation (0.9x to 1.1x), Low-Moderate ACC (25-70%)
├─ Techniques: Swung scratches, lazy tape stops, texture warble
└─ Avoid: Tight/digital timing, extreme pitch shifts

VIBEY
├─ Use: Minimal SPD drift (0.95x to 1.05x), Low ACC (35-50%)
├─ Techniques: Reverse textures, slow pitch drift, minimal flutter
└─ Avoid: Aggressive scratching, rapid changes
```

## Genre-Specific Multi-Vibe Applications

### Trap (Upbeat + Vibey)
- **Verse:** Vibey reverse texture (SPD = -0.7x, low ACC)
- **Pre-drop:** Upbeat quick tape stop (SPD 1x → 0x, high ACC)
- **Hook:** Upbeat rapid cuts (SPD = 1.2x, high SEN)

### R&B (Jazzy + Vibey)
- **Intro:** Vibey slow pitch drift (SPD = 0.95x to 1.05x)
- **Verse:** Jazzy texture warble (SPD sine wave, low ACC)
- **Bridge:** Jazzy lazy tape stop (SPD 1x → 0.7x, low ACC)

### Experimental Hip-Hop (Psychedelic + All)
- **Build:** Jazzy texture (SPD = 0.95x) → Psychedelic pitch bend (SPD 0.5x to 1.8x)
- **Drop:** Upbeat rapid cuts (SPD = 1.3x)
- **Outro:** Vibey reverse texture (SPD = -0.6x, heavy reverb)
