# Live Performance Lighting Setup

## Pre-Performance Checklist
- [ ] Test all Chroma devices
- [ ] Load performance profiles
- [ ] Set proper brightness levels
- [ ] Configure emergency presets
- [ ] Test backup lighting

## Performance Profiles

### High Energy Sets
**Settings**:
- Brightness: 100%
- Beat sync: Aggressive
- Color scheme: High contrast
- Effects: All enabled

**Best for**: EDM, Dubstep, Techno

### Ambient Sets
**Settings**:
- Brightness: 60%
- Beat sync: Subtle
- Color scheme: Warm tones
- Effects: Limited effects

**Best for**: Chillout, Ambient, Downtempo

### Band Performance
**Settings**:
- Brightness: 80%
- Beat sync: Moderate
- Color scheme: Thematic
- Effects: Reactive only

**Best for**: Live bands, DJ sets

## Emergency Procedures

### Device Failure
1. Switch to backup profile
2. Disable problematic device
3. Continue with reduced lighting
4. Address issue during break

### Software Crash
1. Activate emergency static lighting
2. Restart FL Studio
3. Reload Chroma plugin
4. Restore last working profile

### Power Issues
1. Immediately reduce brightness
2. Disable non-essential effects
3. Switch to battery backup if available
4. Prepare for graceful shutdown
