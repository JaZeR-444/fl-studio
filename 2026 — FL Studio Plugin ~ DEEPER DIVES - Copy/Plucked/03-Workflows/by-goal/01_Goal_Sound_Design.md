# Workflow: The Alien Harp

**Goal:** Sci-Fi string texture.

1.  **Plucked:** Max Decay, Max Color, Widen ON.
2.  **FX 1:** **Fruity Flanger**.
    *   Rate: Very Slow.
    *   Depth: Max.
    *   Feedback: High.
3.  **FX 2:** **Fruity Delay 3**.
    *   Time: Dotted 8th.
    *   Ping Pong: ON.
4.  **Result:** A metallic, swirling string sound that evolves over time.
