# Slicex - 00 START HERE

## Purpose
Slicex slices loops into regions and provides per-slice articulation, routing, and layered playback with Deck A and B. It is designed for detailed loop editing and performance.

## 10-Minute Orientation
1. Load a loop in Deck A and run Auto Slice.
2. Audition slices from the keyboard.
3. Assign a slice to an articulator and shape its envelope.
4. Set OUT for per-slice mixer routing.
5. Load a second loop in Deck B to layer with Deck A.

## Listening Tests
- Auto-slice modes on the same loop.
- Articulator filter envelope vs no envelope.
- CUT/CUT BY for hats and stabs.

## Pitfalls
- OUT is an offset from the Slicex mixer track, not an absolute track number.
- If slices stop early, check articulator envelope and note length.

## Mix Integration Checklist
- Confirm mono compatibility for wide settings.
- Control low-end with high-pass or low-bypass tools.
- Use light compression for dynamic stability.
- Avoid extreme modulation in dense mixes.

## Troubleshooting Matrix
- Harsh attack -> soften exciter/attack, reduce brightness.
- Thin body -> increase resonance or body emphasis.
- Too wide -> reduce spread, check mono.
- Too static -> add modulation or automation.
- Muddy low end -> reduce low-mid buildup or use high-pass.
