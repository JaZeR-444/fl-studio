# Goal: The Soulful Sample "Flip" (Slicex)

## Step-by-Step Setup
1.  Drag a 4-bar soul/jazz sample into **Slicex**.
2.  Click the **Knife Icon -> Auto-slice -> Dull auto-slicing**. (Dull mode is better for long melodic chunks).
3.  **The Clean-up:** Zoom in and manually move markers so they land exactly on the "One" of each beat.
4.  **The Play:** Use the Piano Roll to play the chops in a new order. 
    - *Example:* Instead of `1, 2, 3, 4`, play `3, 1, 4, 2`.
5.  **Vibe Polish:** Assign all slices to **Articulator 1**. Enable the **Filter** and set it to a warm `Low Pass @ 800Hz`.

## Result
- You have "Re-sampled" the old record into a completely new melody. The low-pass filter adds that "Vintage/Moody" atmosphere found in dusty hip-hop.

## Vibe Check
- **Jazzy/Moody:** Perfect for creating "Boom Bap" or "Lo-Fi" foundations.

## Variation
- **Reverse Throw:** Select every 4th slice and hit **Tools -> Reverse**. It adds a psychedelic "breath" to the rhythm. [SRC: REPUTABLE]
