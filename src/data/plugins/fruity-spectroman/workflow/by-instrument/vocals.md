# Vocals Analysis with Fruity Spectroman

## Vocal Frequency Zones

**Body/Warmth:** 200-500 Hz (chest, fullness)  
**Clarity/Presence:** 2-5 kHz (intelligibility, forward)  
**Sibilance:** 5-8 kHz (s, sh, ch sounds)  
**Air:** 10-15 kHz (breathiness, shine)

---

## Vocal Mixing Workflow

### Step 1: Remove Mud (2 min)
1. Solo vocals
2. Check 200-500 Hz in Spectroman
3. If too much red: Cut 300-400 Hz
4. Goal: Warmth without mud

**Check:** Yellow/green at 200-300 Hz, not heavy red

---

### Step 2: Boost Presence (3 min)
1. Check 2-5 kHz zone
2. Should be prominent (red/yellow)
3. If buried: Boost 2.5-4 kHz (+2 to +4 dB)
4. Vocals should sit "above" the mix visually

**Check:** Clear presence at 2.5-4 kHz

---

### Step 3: Control Sibilance (3 min)
1. Check 5-8 kHz for harsh s sounds
2. If excessive: Use de-esser or cut 6-8 kHz
3. Peak hold helps identify exact sibilance frequency

**Check:** Controlled at 5-8 kHz, not harsh red spikes

---

### Step 4: Add Air (Optional, 1 min)
1. Check 10-15 kHz
2. If dull: Boost air shelf (+1 to +2 dB at 10-12 kHz)
3. Adds breathiness and shine

**Check:** Some content visible at 10-15 kHz

---

### Step 5: Vocal in Full Mix (3 min)
1. Unmute full mix
2. Check if vocal presence (2-5 kHz) is visible
3. If buried: Boost vocals OR cut competing elements
4. Vocals should be clearly present at 2-5 kHz

**Check:** Vocals stand out in spectrum

---

## Common Vocal Issues

**Muddy Vocals:**
- Too much 200-500 Hz
- **Fix:** Cut 300-400 Hz

**Buried Vocals:**
- Weak at 2-5 kHz
- **Fix:** Boost presence, cut competing instruments

**Harsh/Sibilant Vocals:**
- Excessive 5-8 kHz
- **Fix:** De-ess, cut 6-8 kHz

**Thin Vocals:**
- Weak at 200-400 Hz
- **Fix:** Add warmth, boost 200-300 Hz

---

## Genre-Specific Vocal Presence

**Hip-Hop/Rap:**
- Strong 2.5-4 kHz (clarity and aggression)
- Controlled 200-500 Hz (clean)

**R&B:**
- Warm 200-400 Hz (emotion)
- Smooth 2-4 kHz (intimacy)
- Air at 10-15 kHz (shine)

**Rock/Pop:**
- Present 2-5 kHz (cut through mix)
- Moderate warmth (200-400 Hz)

---

## Vocal Checklist
- [ ] Mud removed (200-400 Hz controlled)
- [ ] Presence strong (2-5 kHz prominent)
- [ ] Sibilance controlled (5-8 kHz not harsh)
- [ ] Air added if needed (10-15 kHz)
- [ ] Vocals sit above mix visually
