# Goal: Vibe - Moody

## Goal Statement
Create a dark, "dusty" lo-fi pad that sounds like a found-footage VHS tape.

## Step-by-Step Setup
1. **Oscillator:** Saw 50%, Noise 10%.
2. **Filter:** LP 12dB. Cutoff 25%. Resonance 0%.
3. **Unison:** 8 Voices. Detune 20% (Maximum drift).
4. **Envelopes:** Attack 500ms, Release 1.5s.
5. **Matrix:** LFO (Sine, 1Hz) -> Master Pitch. Amount 1.5%.
6. **Acoustics:** High Reverb Mix (30%), High Damping.

## Starting Settings
- **Noise:** 10%
- **Detune:** 20%
- **Attack:** 500ms

## Variations
- **Variation 1:** Use **BP filter** at 500Hz for a "radio" effect.
- **Variation 2:** Set LFO to "Random" for unpredictable pitch jumps.
