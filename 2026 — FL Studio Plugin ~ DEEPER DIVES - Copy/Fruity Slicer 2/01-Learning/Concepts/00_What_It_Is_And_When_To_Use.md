## Chromatic Mode Explained (The Game-Changer)

### What Is Chromatic Mode?

**Without Chromatic:**
- Each slice = one MIDI note (C5 = slice 1, C#5 = slice 2, etc.)
- Trigger slices rhythmically (like Slicer 1)

**With Chromatic:**
- Select ONE slice (e.g., slice 3 = vocal "Ahh")
- Enable "Chromatic" toggle
- **Play that slice across entire keyboard** (C1, D1, E1, F1, etc.)
- Each key = correctly pitched version of that slice

**Result:** Single slice → Playable instrument (lead, bass, pad)

## Typical Roles in a Session

### Role 1: Melodic Vocal Instrument (PRIMARY)
**Scenario:** Turn vocal chop into lead melody

**Workflow:**
1. Load vocal loop into Slicer 2
2. Auto-slice (or manual)
3. Select best "Ahh" or "Ooh" slice (sustained vowel)
4. Enable "Chromatic" + "Play to End"
5. Play melody on keyboard (C4, E4, G4, etc.)

**Result:** Vocal chop = lead instrument

**Vibe Applications:**
- **Moody:** Low-pitched vocal pad (-5 semitones, reverb)
- **Upbeat:** Bright vocal melody (+3 semitones, compressed)

---

### Role 2: Pitched Percussion
**Scenario:** Snare rolls that change pitch (Trap)

**Workflow:**
1. Load snare sample into Slicer 2
2. Slice snare hit
3. Enable "Chromatic"
4. Program roll in Piano Roll (1/32nd notes)
5. Add pitch automation (descending roll: C5 → C4)

**Result:** Pitched snare roll (drops in pitch)

**Vibe:** Upbeat (Trap rolls), Psychedelic (extreme pitch ranges)

---

### Role 3: Chromatic Bass Instrument
**Scenario:** Create playable bass from 808 sample

**Workflow:**
1. Load 808 hit into Slicer 2
2. Slice 808 transient
3. Enable "Chromatic"
4. Play bass line on keyboard (C1, F1, G1, etc.)

**Result:** 808 sample = playable bass instrument

**Vibe:** Moody (dark sub-bass), Upbeat (bouncy bass line)

---

### Role 4: Advanced Beat Slicer
**Scenario:** Same as Slicer 1 but with better envelopes

**Workflow:**
1. Load drum break
2. Auto-slice
3. Apply per-slice Filter envelope (e.g., low-pass slice 5 only)
4. Rearrange slices

**Result:** Break with unique per-slice processing

**Vibe:** Jazzy (clean slices), Psychedelic (extreme envelopes)

## When NOT to Use Slicer 2

❌ **Simple Beat Chopping (No Melodic Playback)**
- Use Slicer 1 instead (lighter CPU, simpler)

❌ **Multi-Sampled Instruments**
- Use DirectWave or Sampler (better for multi-velocity, multi-sample)

❌ **Granular Synthesis**
- Use Granulizer (dedicated granular engine)

❌ **Complex Layered Slicing**
- Use Slicex (supports layer crossfading)
