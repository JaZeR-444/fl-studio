# Workflow: Vocals with Fruity Soft Clipper

## Goal
Smooth vocal peaks and create cohesive vocal presence using soft clipping.

---

## Routing Context

**Lead Vocal:** Insert slot 1 (before reverb/delay)  
**Background Vocals:** Usually skip Soft Clipper

---

## Workflow 1: Standard Vocal Smoothing

### Setup
1. Load Soft Clipper on lead vocal track (slot 1)
2. **Threshold:** -0.5 to -1.0 dB
3. **Post Gain:** 0 dB
4. Position BEFORE reverb send

### What It Does
Rounds off harsh consonants and peaks for smooth reverb input

### Listen For
- Smoother "S" sounds (less sibilance)
- Reverb tail sounds natural
- Vocal sits better in mix

### Vibe Mapping
- **Moody:** -0.5 dB (ultra-gentle)
- **Upbeat:** -1.0 dB (moderate)
- **Vibey:** -0.5 to -1.0 dB
- **Psychedelic:** -3 to -10 dB (creative distortion)

## Workflow 2: De-Essing via Saturation

### Setup
1. Load Soft Clipper on vocal
2. **Threshold:** -1.0 dB
3. **Post Gain:** 0 dB

### What It Does
Soft clipping rounds sibilant peaks naturally (alternative to de-esser)

### Listen For
- Sibilance reduced without losing air
- Natural-sounding vs. de-esser artifacts

### When to Use
- When de-esser sounds too aggressive
- R&B vocals (smooth delivery)
- Moody tracks

---

## Workflow 3: Creative Vocal Distortion (Psychedelic)

### Setup
1. Duplicate vocal to FX track
2. FX track: HPF at 500 Hz → Soft Clipper -10 dB
3. Blend distorted vocal at 20-30%

### What It Does
Creates lo-fi, telephone, or megaphone vocal effect

### Listen For
- Thin, distorted character
- Retains clarity on main vocal
- Creative texture layer

### When to Use
- Ad-libs (Trap)
- Psychedelic sections
- Travis Scott-style production

---

## Workflow 4: Parallel Vocal Saturation

### Setup
1. Send vocal to parallel track
2. Parallel Soft Clipper: **-6 dB** Threshold
3. Blend at 15-25%

### What It Does
Adds presence and density while preserving dynamics

### Listen For
- Vocal feels "bigger" and more present
- Natural dynamics retained
- Subtle warmth

## Starting Settings by Genre

| Genre | Threshold | Post Gain | Notes |
|-------|-----------|-----------|-------|
| **Trap** | -1.0 dB | 0 dB | Moderate smoothing |
| **R&B** | -0.5 dB | 0 dB | Ultra-gentle |
| **Moody** | -0.5 dB | 0 dB | Before heavy reverb |
| **Pop** | -1.0 dB | 0 dB | Radio-ready smoothing |
| **Psychedelic** | -10 dB | 0 dB | Creative distortion (FX track) |

---

## Chain Position (CRITICAL)

### Correct Order
**Vocal Track Chain:**
1. **Soft Clipper** (-0.5 to -1 dB)
2. Reverb Send
3. Delay Send
4. Other FX

**Why:** Prevents reverb from being triggered by harsh peaks

---

## Automation Ideas

### Automation 1: Chorus Presence
- Verse: -0.5 dB (gentle)
- Chorus: -1.0 dB (more present)

### Automation 2: Ad-Lib Aggression
- Main Vocal: -0.5 dB
- Ad-Libs: -3 dB (snap down for emphasis)

---

## Pitfalls & Fixes

**Pitfall:** Vocal sounds distorted  
**Fix:** Raise Threshold to -0.3 dB

**Pitfall:** Reverb sounds harsh  
**Fix:** Ensure Soft Clipper is BEFORE reverb send

**Pitfall:** Vocal loses clarity  
**Fix:** Use parallel saturation instead of insert
