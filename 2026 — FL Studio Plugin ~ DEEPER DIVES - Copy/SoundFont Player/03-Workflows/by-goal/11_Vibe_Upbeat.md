# Goal: Vibe - Upbeat

## Goal Statement
Create a bright, snappy, and high-energy sequence for pop-leaning hip-hop.

## Step-by-Step Setup
1. **Instrument:** Load a "Trumpet Section" or "Staccato Strings" SoundFont.
2. **Resampling:** **Extreme HQ** (for maximum clarity).
3. **ADSR:** Set **Release** to 10% (Short and dry).
4. **Filter:** Set **Mod** to 60% with Cutoff at 50%. This creates a bright "pop" on every note.
5. **Pitch:** Pitch up by +700 or +1200 cents for a "hyper-pop" energy.

## What to Listen For
- A "clickable" and "energetic" transient.
- Zero mud in the tail; notes should stop exactly when you release the key.
