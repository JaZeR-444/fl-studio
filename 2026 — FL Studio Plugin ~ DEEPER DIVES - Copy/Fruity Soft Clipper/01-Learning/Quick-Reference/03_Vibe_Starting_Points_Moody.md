## 30-Second Moody Setup

### Master Bus
- **Threshold:** -0.3 dB (barely clipping)
- **Post Gain:** 0 dB
- **Why:** Transparent glue without aggression

### Drums
- **Skip Soft Clipper entirely**
- **Use Instead:** Light compression (2:1, slow attack)
- **Why:** Moody needs dynamic breathing

### Vocals
- **Threshold:** -0.5 dB
- **Post Gain:** 0 dB
- **Position:** Before reverb
- **Why:** Smooth peaks for clean reverb tail

### 808/Bass
- **Skip Soft Clipper entirely**
- **Keep Clean:** No distortion
- **Why:** Moody bass must stay smooth and sub-heavy

## What to Listen For (Moody Validation)

- [ ] Mix feels "pulled back," not forward
- [ ] Vocals sit inside the reverb
- [ ] Low-end is smooth, not aggressive
- [ ] Transients are natural
- [ ] Wide dynamic range preserved

---

## Moody DON'Ts

❌ **Don't clip drums below -3 dB**  
❌ **Don't use Soft Clipper on 808s**  
❌ **Don't use Post Gain** (keep at 0 dB)  
❌ **Don't automate Threshold** (consistency is key)
