# Workflow: Drums with Fruity Soft Clipper

## Goal
Create cohesive, punchy drum mixes using soft clipping for glue.

[SRC: REPUTABLE]

---

## Routing Context

**Drum Bus:** All drums → mixer bus track → Soft Clipper (first insert)  
**Individual Drums:** Optional (snare/clap only)

---

## Workflow 1: Standard Drum Bus Glue

### Setup
1. Route kick, snare, hi-hats, percs to drum bus
2. Load Soft Clipper on drum bus (slot 1, before EQ)
3. **Threshold:** -3.0 dB
4. **Post Gain:** +1.0 dB

### What It Does
Fuses individual drum hits into cohesive rhythm unit

### Listen For
- Drums sound like "one instrument"
- Transients still punchy (not mushed)
- Cohesive groove instead of separate samples

### Vibe Mapping
- **Upbeat:** -5 dB (aggressive)
- **Vibey:** -3 dB (balanced)
- **Moody:** Skip Soft Clipper (use compression)
- **Jazzy:** Skip Soft Clipper (preserve swing)

## Workflow 2: Individual Snare Crack

### Setup
1. Load Soft Clipper on snare/clap track only
2. **Threshold:** -4.0 to -5.0 dB
3. **Post Gain:** 0 dB

### What It Does
Enhances transient snap and presence

### Listen For
- Snare feels sharper, more "cracked"
- Sits forward in mix without volume increase

### When to Use
- Upbeat Hip-Hop (needs punchy snare)
- Pop production
- When snare feels weak in mix

---

## Workflow 3: Parallel Drum Saturation

### Setup
1. Send drum bus to parallel track (30% blend)
2. Parallel track: Soft Clipper **-10 dB** Threshold
3. Blend at 30-40%

### What It Does
Adds density and aggression while preserving punch

### Listen For
- Fuller, denser drum mix
- Retained transient snap
- Saturated character

### Vibe Mapping
- **Upbeat:** 50% blend
- **Psychedelic:** 80% blend (extreme)
- **Vibey:** 30% blend

---

## Workflow 4: Asymmetric Drum Clipping (Psychedelic)

### Setup
1. Load Soft Clipper on **individual** drum tracks
2. **Kick:** -2 dB
3. **Snare:** -8 dB
4. **Hi-Hats:** -4 dB

### What It Does
Creates intentionally unbalanced, chaotic drum mix

### Listen For
- Drums don't "gel" (intentional)
- Unpredictable character
- Experimental vibe

### When to Use
- Psychedelic/experimental Hip-Hop
- Travis Scott-style production

---

## Starting Settings by Genre

| Genre | Bus Threshold | Bus Post Gain | Individual Drums? |
|-------|---------------|---------------|-------------------|
| **Trap** | -5 dB | +2 dB | Snare: -5 dB |
| **R&B** | -3 dB | +1 dB | Optional |
| **Lo-Fi** | -4 dB | 0 dB | All: -3 to -5 dB |
| **Boom-Bap** | -3 dB | +1 dB | None |
| **Moody** | None (skip) | N/A | None |

---

## Automation Ideas

### Automation 1: Drop Slam
- Pre-Drop: -3 dB
- Drop Hit: -6 dB (snap down)
- Drop Sustain: -4 dB

### Automation 2: Build Energy
- Verse: -2 dB
- Pre-Chorus: -3 dB
- Chorus: -4 dB

---

## Pitfalls & Fixes

**Pitfall:** Drums sound mushed  
**Fix:** Raise Threshold to -2 dB

**Pitfall:** No cohesion  
**Fix:** Lower Threshold to -4 dB
