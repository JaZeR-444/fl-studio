# Bad UI Feedback Examples

Avoid these types of vague, unhelpful, or hallucinated feedback.

## Example 1: Vague
**Bad:** "Make the design pop more. It looks a bit boring. Try improving the layout."
*(Why it's bad: "Make it pop" means nothing to a developer. No actionable CSS or structural advice).*

## Example 2: Hallucination / Scope Drift
**Bad:** "You should add a testimonials section here with photos of real users, and maybe a pricing table below it. Also, change the routing so clicking the logo goes to a new dashboard."
*(Why it's bad: Invents new content and suggests business logic changes outside the scope of UI polish).*

## Example 3: Unnecessary Redesign
**Bad:** "Delete this entire grid layout and replace it with a masonry layout. Change your brand color from Blue to Neon Green."
*(Why it's bad: Fails to respect the existing design direction. The goal is to polish what exists, not redesign it).*

## Example 4: Unhelpful Code Review
**Bad:** "Your Tailwind classes are messy."
*(Why it's bad: Does not point out WHICH classes are messy or provide a refactored example).*
