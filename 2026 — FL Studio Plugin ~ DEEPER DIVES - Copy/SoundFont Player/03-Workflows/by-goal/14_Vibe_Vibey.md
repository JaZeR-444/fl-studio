# Goal: Vibe - Vibey

## Goal Statement
Create a lush, wide, and smooth R&B "cloud" pad that sits perfectly in a lush production.

## Step-by-Step Setup
1. **Instrument:** Load a "Mellow Choir" or "Synth Pad" SoundFont.
2. **ADSR:** Attack 800ms, Release 1.5s.
3. **Chorus:** Enable internal Chorus.
4. **Filter:** Set **Cut** to 60%.
5. **Acoustics:** Route to a mixer track with `Fruity Reeverb 2` (Size 100%, Mix 30%).

## Mini-Recipe: "Silk Texture"
- String Section SF2.
- Low-Pass filter at 500Hz.
- Panned 50% Left.
- Layered with a Sine wave sub.
- *Result:* A smooth, wide "hum" that fills the stereo field without distracting from the vocals.
