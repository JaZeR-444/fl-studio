# Fruity Soft Clipper: Cheat Sheet

A lightweight, transparent limiter that saturates peaks rather than hard-clipping them.

## Parameters

| Parameter | Function | Context / Tip |
| :--- | :--- | :--- |
| **Threshold (Thres)** | Sets the level above which soft limiting begins. | **Tip:** A lower threshold introduces saturation earlier. At maximum, it acts more like a safety limiter. |
| **Post Gain** | Boosts the volume of the signal *after* the soft clipping stage. | **Tip:** Use this to recover volume lost by compression/limiting, or to drive the signal harder into the next plugin. |

## Quick Reference
*   **Best For:** Master channel safety, glueing Drum Busses, transparent loudness.
*   **Key Characteristic:** "Soft" knee compression that avoids the harsh digital distortion of hard clipping.
