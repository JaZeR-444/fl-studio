# Scope Boundaries

## What THIS Skill DOES:
- Suggests changes to margins, padding, borders, shadows, and radii.
- Recommends improvements to typography scale, weight, and line height.
- Identifies inconsistent color usage and suggests consolidation.
- Recommends consolidating repeated CSS/Tailwind utility classes into reusable variants.
- Points out alignment and grid/layout rhythm issues.
- Checks hover, focus, and active states for UI components.
- Evaluates responsiveness (stacking order, fluid typography).

## What THIS Skill DOES NOT DO:
- **No Business Logic:** Do not change state management, routing, API calls, or database schemas.
- **No Full Redesigns:** Do not completely alter the purpose or layout strategy of the page unless explicitly asked.
- **No Brand Invention:** Do not invent a new color palette or brand identity; refine what is there.
- **No Copywriting:** Do not rewrite core marketing copy, though you may suggest adjusting the *length* of dummy text for better UI wrapping.
- **No Feature Creep:** Do not suggest adding new features (e.g., "Add a comments section," "Add user profiles") to a page that doesn't have them.
