# Sytrus Parameter Cheat Sheet

| Section | Parameter | Sweet Spot | Vibe Insight |
| :--- | :--- | :--- | :--- |
| **Main** | Unison | 9 Voices | Maximum wide "Cloud" pads. |
| | Unison Detune | 2% - 5% | Keep it tight for "Silk" textures. |
| | Oversampling | 8x (Render) | Essential for clear FM bells. |
| **Matrix**| OP -> OP | 10% - 40% | The range for "Musical" FM harmonics. |
| | Feedback | 1% - 5% | Adds "Analog grit" to leads. |
| | BLUE Knob | ON | Switches FM to RM (Robotic tones). |
| **Filter**| Type | Mango | Best for saturation and "Weight." |
| | Drive | 20% - 50% | Adds "Meat" to FM bass. |
| **OP** | Ratio | 1.000 (Base) | 2.000, 4.000, etc. for octaves. |
| | Harmonics | Top Left Bars | First 3 bars = warm/muffled tone. |
