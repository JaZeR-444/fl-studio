# Vibe Workflow: VIBEY - Fruity Spectroman

## Vibey Vibe Spectral Signature

**Visual Target:**
- Smooth, lush distribution
- Full mid-range with warmth
- Reverb presence in highs
- No harsh peaks

**Quick Spectrum Check:**
```
60-200 Hz:   ██████ (warmth and fullness)
200-500 Hz:  ████ (body and emotion)
500-2k Hz:   ████████ (musical core)
2k-5k Hz:    ████ (smooth clarity)
5k-12k Hz:   ████ (spacious reverb)
```

**Spectroman Settings:**
- FFT: 2048-4096
- Decay: Medium-Slow (lush, averaged)
- Peak Hold: OFF (smooth view)
- Averaging: Medium-Heavy (lush appearance)

---

## Step-by-Step Vibey Workflow

### 1. Add Richness (3 min)
**Action:** +2 dB at 200-400 Hz, +1-2 dB at 1-2 kHz  
**Check:** Fuller, richer visual profile

### 2. Smooth Clarity (2 min)
**Action:** +1 dB at 3-4 kHz (wide Q)  
**Check:** Smooth rise, not sharp peak

### 3. Add Space (3 min)
**Action:** Reverb/delay (extends 5-15 kHz)  
**Check:** Visible reverb tail

### 4. Layer Textures (ongoing)
**Action:** Pads, atmospheres  
**Check:** Fuller spectrum overall
