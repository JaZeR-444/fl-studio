# Slicex vs. Fruity Slicer: When to Level Up

## Fruity Slicer (The Speed Demon)
- **Best For:** Quick chops, 1-knob time stretching, and basic drum rearranging.
- **Pros:** Extremely fast, very low CPU, simple interface.
- **Cons:** No per-slice filtering, no layering, limited wave editing.
- **The "Vibe":** Clean, functional, and "no-nonsense."

## Slicex (The Surgeon)
- **Best For:** Professional sampling, layering loops, sound design, and complex articulations.
- **Pros:** Edison-level editing, 8 Articulators, Deck A/B layering, independent mixer routing per slice.
- **Cons:** Higher learning curve, more complex UI.
- **The "Vibe":** Creative, experimental, and "limitless."

## When to Level Up to Slicex:
1. **Layering:** You want to add an 808 layer to a breakbeat.
2. **Filtering:** You want the Snare to be bright but the Hi-Hats to be dark.
3. **Routing:** You want to EQ your Kick and Snare separately in the Mixer.
4. **Vocal Chops:** You need to loop or sustain vocal regions for melodies. [SRC: IL-MAN-04]

## Summary Table
| Feature | Fruity Slicer | Slicex |
| :--- | :--- | :--- |
| **Slicing Engine** | Basic Transient | Advanced Transient/Manual |
| **Editors** | 1 | 2 (Deck A/B) |
| **Wave Editing** | None | Full (Edison Engine) |
| **Articulators** | Global only | 8 Independent Slots |
| **Mixer Outputs** | 1 | Unlimited (via Offset) |
