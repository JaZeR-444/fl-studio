# SoundFont Player Parameter Cheat Sheet

| Section | Parameter | Override | Research Insight |
| :--- | :--- | :--- | :--- |
| **ADSR** | Attack | Light | Set to 10-20ms to remove hammer noise. |
| | Release | Light | Essential for "bleeding" pads and chords. |
| **Filter** | Cut | Light | Use at 40-60% for lo-fi "dusty" vibes. |
| | Mod | Light | Positive values add "bite" to the attack. |
| **LFO** | Freq | Light | 4Hz - 6Hz is the natural human range. |
| | Amp | Light | Keep at 2-5% for realistic vibrato. |
| **Global** | Resampling | N/A | "Crunchy" adds authentic 90s aliasing. |
| | Pitch | N/A | Global transposition (+/- 2 octaves). |
| | Reverb | N/A | Disable this and use external Reverb 2. |
