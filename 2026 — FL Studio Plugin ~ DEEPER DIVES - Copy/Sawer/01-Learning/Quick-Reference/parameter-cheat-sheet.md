# Sawer Parameter Cheat Sheet

| Section | Parameter | Range | Research Insight |
| :--- | :--- | :--- | :--- |
| **Osc** | Sub Level | 0 - 100% | The foundation of modern Trap bass. |
| | Sub Phase | 0 - 360° | 180° is often the "sweet spot" for 808s. |
| | Noise | 0 - 10% | Use for "Tape Hiss" in Lo-Fi. |
| | Sync | Toggle | Toggles "Tearing" harmonics mode. |
| **Filter** | Slope | 12dB / 24dB | 12dB = Musical; 24dB = Aggressive Growl. |
| | Resonance | 0 - 80% | Adds saturation/distortion above 30%. |
| | KBD Track | 0 - 100% | Higher values keep high notes bright. |
| **Env** | Filter Amt | -100 - +100% | Positive for "Snap," Negative for "Suck." |
| | Amp ADSR | Standard | Critical for "Pluck" (Short D/S) vs "Pad." |
| **Master** | Unison | 1 - 8 Voices | Use 1 for Bass, 4+ for Vibey Leads. |
| | Detune | 5% - 20% | Controls the "Retro Drift" intensity. |
| | Glide | 0 - 500ms | Necessary for 808 slides. |
