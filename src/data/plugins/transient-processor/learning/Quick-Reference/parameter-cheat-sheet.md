# Transient Processor Parameter Cheat Sheet

| Parameter | Range | Typical Move | Vibe Insight |
| :--- | :--- | :--- | :--- |
| **Attack** | -15 to +15dB | +6dB | Making Trap snares "Cut" through. |
| | | -4dB | Softening "Digital" vocal harshness. |
| **Release** | -15 to +15dB | -10dB | Removing room reverb from samples. |
| | | +4dB | Giving Kicks more "Body" and thump. |
| **Split Freq**| 10Hz - 10kHz | 150Hz | Sub-bass safety crossover. |
| | | 2kHz | Processing only the Hi-Hat "Air." |
| **Drive** | 0 - 100% | 10% | Harmonic fatness for transients. |
| **Mix** | 0 - 100% | 30% | Parallel processing for Drum Bus. |

## Quick Tip:
The **Histogram** is your guide. The blue spikes show the Attack boost, the red dips show the Release cut. Adjust until you "see" the rhythm you want to hear.
