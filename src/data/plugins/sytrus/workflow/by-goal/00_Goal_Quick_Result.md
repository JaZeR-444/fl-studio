# Goal: The "Deep Sea" 808 (Sytrus)

## Step-by-Step Setup
1.  Initialize Sytrus (Default Sine).
2.  Go to **OP 1** tab.
3.  Go to the **MAIN** Matrix.
4.  Find the knob for **OP 1 Feedback** (the knob where Column 1 meets Row 1).
5.  Slowly turn it up to about `20%`.
6.  **Filter:** Go to **FILT 1**. Set to `Vanilla Lowpass`. Move cutoff to `300Hz`.
7.  **Envelope:** Go to **OP 1 -> VOL -> ENV**. Set a long sustain and a slow release.

## Result
- A deep, vibrating sub-bass with "movement." The self-feedback creates a subtle growl that feels modern and "heavy."

## Vibe Check
- **Moody/Dark:** The foundational bass sound for "Nocturnal" trap and R&B.

## Variation
- **Gritty 808:** Increase the feedback to `50%` and turn up the **Filter Resonance** for a more aggressive, distorted character. [SRC: REPUTABLE]
