# Instrument Workflow: Trap Drum Layering (The Perfect Duo)

*Goal: Using BassDrum to provide the low-end foundation for a thin drum sample.*

## 🎛️ Routing Context
- **Setup**: One track for a Snare/Clap sample and one track for BassDrum.

## 🚶 Step-by-Step Setup
1. **Choose the Sample**:
   - Pick a snare or clap that has a great high-frequency "crack" but lacks weight.
2. **The BassDrum "Thump"**:
   - Set **Start Freq** to 200Hz. Set **End Freq** to 80Hz.
   - Set **Pitch Decay** to 10% (Fast).
   - Set **Amp Decay** to 150ms.
3. **The Blend**:
   - Play the snare sample and BassDrum together.
   - *Result*: BassDrum provides the "chest punch" that the sample was missing.
4. **Phase Re-alignment**:
   - Slowly turn the **Phase** knob in BassDrum until the combined hit sounds the loudest.
5. **The Final Glue**:
   - Route both the sample and BassDrum to a single **Mixer Bus**.
   - Add a **Fruity Soft Clipper**.
   - *Result*: The two sounds will merge into a single powerful drum hit.

## 🔄 Variations
- **The "Kick Layer"**: Use the same technique to add a synthesized 50Hz sub-thump to a thin acoustic kick sample.
- **The "Digital Sizzle"**: Use the Sample tab in BassDrum to add a burst of white noise to your drum layers.

## ⚠️ Pitfalls & Fixes
- **Problem**: The drums sound "hollow."
- **Fix**: You have phase cancellation. Invert the phase of one of the tracks or adjust the **Phase** knob in BassDrum.
