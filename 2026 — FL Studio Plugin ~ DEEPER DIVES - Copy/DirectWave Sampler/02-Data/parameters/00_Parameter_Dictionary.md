# Parameter Dictionary: DirectWave Sampler

| Parameter | Location | Vibe Impact | Mix Impact | Description |
| :--- | :--- | :--- | :--- | :--- |
| **Key Range** | Zone Graph | **All** | **Pitch** | Notes that trigger the sample. |
| **Vel Range** | Zone Graph | **Jazzy** | **Dynamics** | Velocity levels for the sample. |
| **Root Key** | Zone Tab | N/A | **Pitch** | The sample's original pitch. |
| **Loop Mode** | Loop Tab | **Spacey** | **Sustain** | Forward, Reverse, Ping-pong.|
| **Crossfade** | Loop Tab | **Vibey** | **Artifacts** | Smoothness of the loop point. |
| **Filter Cut** | Zone Tab | **Moody** | **Spectral** | Per-sample filter frequency. |

- **Vibe Impact Tag (Velocity):** Precise velocity mapping is the only way to achieve "Jazzy" realism in sample-based instruments.
- **Mix Impact Tag (Looping):** Poor loop points cause "Clicks." Always use the **Crossfade** slider to smooth the loop transition. [SRC: IL-MAN]
