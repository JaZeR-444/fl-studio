# Goal: Lush Additive Pads

## Goal Statement
Design a massive, evolving, and wide background pad using Sytrus's additive harmonics engine.

## Step-by-Step Setup
1. **Sculpting:** In **OP 1 (Osc tab)**, right-click the harmonics editor and select **Analyze Audio File**. Pick a smooth string or vocal sample.
2. **Smoothing:** Set the **Additive Smoothing** (in the harmonics menu) to 20% to remove sharp transients.
3. **Unison:** Set **Unison Voices** to 9. Set **Unison Phase** to 100% (This makes the voices start at different points).
4. **Envelope:** Set a 3-second **Attack** and 4-second **Release** on OP 1's volume.
5. **FX:** Turn on all 3 Delay lines in the FX tab at slightly different timings.

## What to Listen For
- A "majestic" swell that takes up the entire stereo field.
- No "beating" or phase issues (thanks to the Unison Phase setting).
- A sound that feels "organic" despite being 100% digital.

## Automation Ideas
- **Harmonic Morph:** Use the **X-Y Controller** to fade between OP 1 (Soft harmonics) and OP 2 (Bright harmonics).
- **Phaser Speed:** Automate the built-in Chorus speed for "spinning" textures.
