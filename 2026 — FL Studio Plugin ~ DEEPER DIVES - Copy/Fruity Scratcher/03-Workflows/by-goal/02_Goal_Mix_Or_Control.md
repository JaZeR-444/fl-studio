# Fruity Scratcher — Goal: Mix & Control

## Workflow Goal
Use Scratcher for mixing applications: transitions, dynamics, and creative FX sends.

---

## Workflow 1: Tape Stop Transition (Mix Technique)

### Routing Context
- Insert Scratcher on drum bus or full mix → Limiter → Master

### Steps
1. Route drums/mix to Scratcher channel
2. SPD: 1x → 0x (automate over 2-4 beats)
3. ACC: 25-35% (gradual) or 85-95% (quick)
4. Place before section changes (verse → hook, hook → drop)
5. Add limiter to prevent clipping

### What to Listen For
- [ ] Smooth transition
- [ ] No clipping/distortion
- [ ] Timing aligns with downbeat

### Vibe: All (technique adapts to context)

---

## Workflow 2: Parallel Scratch Send

### Routing Context
- Scratcher on insert → Send to reverb/delay return → Blend with dry

### Steps
1. Insert Scratcher on vocal/sample channel
2. Route to Send track with heavy reverb + delay
3. Blend wet/dry (10-30% wet for depth)
4. Scratch dry signal, wet signal creates space
5. Use for psychedelic or vibey contexts

### Vibe: Psychedelic, Vibey

---

## Workflow 3: Sidechain Duck Scratches

### Routing Context
- Scratcher channel → Sidechain to lead vocals

### Steps
1. Insert Fruity Peak Controller on lead vocal
2. Link to Scratcher channel volume
3. Scratches duck when lead vocals play
4. Prevents clash, maintains clarity

### Vibe: All (mixing technique)

---

## Workflow 4: Automation-Based Mix Dynamics

### Routing Context
- Scratcher with SPD automation → Mixer automation

### Steps
1. Use SPD automation for tape stops
2. Automate mixer volume during scratches (swell in/out)
3. Create dynamic mix movement
4. Pair with filter automation

### Vibe: Creative, all vibes
