# Razer Chroma Troubleshooting Guide

## Common Issues & Solutions

### Connection Issues
**Problem**: Chroma not detected in FL Studio
**Solution**: 
1. Check Synapse is running
2. Verify USB connection
3. Restart FL Studio
4. Reinstall Chroma plugin

### Lighting Not Syncing
**Problem**: Lights don't match music
**Solution**:
1. Check MIDI routing
2. Verify plugin position in signal chain
3. Test with simple pattern
4. Check buffer settings

### Performance Issues
**Problem**: Audio glitches when Chroma active
**Solution**:
1. Increase audio buffer size
2. Reduce lighting refresh rate
3. Close unnecessary background apps
4. Update graphics drivers

### Profile Issues
**Problem**: Custom profiles not loading
**Solution**:
1. Verify profile file format
2. Check file permissions
3. Reimport profiles
4. Reset Synapse settings

## Advanced Troubleshooting

### Debug Mode
Enable debug logging in FL Studio:
1. Options → File Settings
2. Enable Debug Log
3. Reproduce issue
4. Check log files

### Clean Reinstall
1. Uninstall Synapse completely
2. Remove registry entries
3. Restart system
4. Reinstall latest version
