# Workflow: Instant Monster Voice

**Goal:** Turn a normal voice into a terrifying monster.

1.  **Insert:** Place Pitch Shifter on Mixer Track.
2.  **Mode:** Set to **Voice**.
3.  **Knobs:**
    *   **Pitch:** -12 (All the way Left).
    *   **Formant:** -5 (Left).
    *   **Mix:** 100% (Right).
4.  **Polish:** Add EQ afterwards and boost 100Hz for body.
