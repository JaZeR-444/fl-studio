# Slicex - Parameter Cheat Sheet

Plugin Type: Beat Slicer / Sampler
Category: Generator / Sampling
Official Manual: https://www.image-line.com/fl-studio-learning/fl-studio-online-manual/html/plugins/Slicex.htm

---

## Main Controls (Summary)

| Section | Control | Function | Quick Tip |
|---|---|---|---|
| Decks | A/B | Load two loops | Layer for hybrid drums |
| Regions | Marker | Defines slice start | Move to tighten timing |
| Regions | OUT | Mixer routing offset | Kick/snare to separate tracks |
| Regions | CUT | Choke groups | Closed hats cut open hats |
| Artic | ENV | Per-slice envelopes | Shape attack and tail |
| Artic | FILTER | Per-slice filter | Add tone variation |

---

## Decks
- Deck A / Deck B: independent sample decks.
- Balance and crossfade for layering.

## Regions (Slices)
- Marker: region start.
- OUT: mixer routing offset per region.
- CUT / CUT BY: choke groups.
- AMP: per-slice level/pan.
- FILTER: per-slice cutoff/resonance.
- SPEED: per-slice playback speed.
- START: per-slice start offset.

## Articulators (1-8)
- Assign one articulator per region.
- Targets: VOL, PAN, CUT, RES, SPEED, START.
- Envelopes and LFOs per articulator.

## Editing
- Wave editor for trimming and fades.
- Dump to Piano Roll for instant MIDI.

---

## Common Mistakes
- Leaving CUT/CUT BY unassigned for hats, causing overlap.
- Over-editing markers and losing groove; use small nudges.

## Automation Ideas
- Slow sweeps (16 bars) for evolving textures.
- Medium sweeps (4 bars) for musical motion.
- Fast sweeps (1 bar) for rhythmic effects.

## Mix Integration Checklist
- Confirm mono compatibility for wide settings.
- Control low-end with high-pass or low-bypass tools.
- Use light compression for dynamic stability.
- Avoid extreme modulation in dense mixes.

## Troubleshooting Matrix
- Harsh attack -> soften exciter/attack, reduce brightness.
- Thin body -> increase resonance or body emphasis.
- Too wide -> reduce spread, check mono.
- Too static -> add modulation or automation.
- Muddy low end -> reduce low-mid buildup or use high-pass.
