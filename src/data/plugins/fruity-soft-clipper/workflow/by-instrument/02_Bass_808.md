# Workflow: Bass/808 with Fruity Soft Clipper

## Goal
Create warm, saturated, or distorted bass using soft clipping.

## Routing Context

**808+Kick Bus:** Route both to bus → boost input → Soft Clipper  
**Bass Only:** Individual bass track → Soft Clipper

---

## Workflow 1: Trap 808 Distortion

### Setup (CRITICAL ORDER)
1. Route 808 and Kick to same bus
2. **BEFORE Soft Clipper:** Add Fruity Balance, boost +6 dB
3. Load Soft Clipper on bus
4. **Threshold:** -8.0 dB
5. **Post Gain:** +3.0 dB
6. **Enable mono monitoring** (Ctrl+M)
7. Verify bass doesn't vanish in mono

### What It Does
Creates signature "broken speaker" Trap bass sound

### Listen For
- Aggressive harmonic buzz
- "Farty" distorted character
- Bass remains present in mono

### Vibe Mapping
- **Upbeat:** -8 to -10 dB (extreme)
- **Psychedelic:** -10 to -12 dB (chaotic)
- **Vibey:** -3 dB (gentle saturation)
- **Moody:** Skip (keep clean)

## Workflow 2: Gentle Bass Warmth (R&B)

### Setup
1. Load Soft Clipper on bass track
2. **Threshold:** -2.0 dB
3. **Post Gain:** 0 dB

### What It Does
Adds warmth and presence without distortion

### Listen For
- Bass feels "rounder" and warmer
- No obvious distortion
- Subtle presence boost

### When to Use
- R&B bass (not 808)
- Live bass samples
- Upright bass (jazzy tracks)

---

## Workflow 3: Multiband Bass Clipping

### Setup (via Patcher)
1. Load Patcher
2. Use Stereo Shaper to split Low (20-100 Hz) and Mid/High (100 Hz+)
3. Apply Soft Clipper ONLY to Mid/High band (-4 dB)
4. Leave Low (sub) clean
5. Recombine with Stereo Shaper

### What It Does
Saturates mids/highs while preserving clean sub

### Listen For
- Warm mid-bass character
- Clean, powerful sub-bass
- Better mono compatibility

### When to Use
- When full-band clipping causes phase issues
- Moody tracks (need clean sub)

---

## Workflow 4: Parallel Bass Saturation

### Setup
1. Send bass to parallel track
2. Parallel Soft Clipper: **-10 dB** Threshold
3. Blend at 20-30%

### What It Does
Adds harmonics while preserving clean fundamental

### Listen For
- Fuller, denser bass
- Clean low-end retained
- Harmonic richness

## Starting Settings by Genre

| Genre | Threshold | Post Gain | Pre-Processing |
|-------|-----------|-----------|----------------|
| **Trap 808** | -8 dB | +3 dB | Boost input +6 dB |
| **R&B Bass** | -2 dB | 0 dB | None |
| **Vibey 808** | -3 dB | 0 dB | None |
| **Moody** | None (skip) | N/A | N/A |
| **Psychedelic** | -10 to -12 dB | +2 dB | Boost input |

---

## Mono Compatibility (CRITICAL)

### How to Check
1. Load Soft Clipper on bass
2. Enable mono: Ctrl+M
3. Play bass section
4. **Listen:** Bass should NOT vanish

### If Bass Disappears in Mono
**Fix 1:** Raise Threshold by +2 dB  
**Fix 2:** Use multiband (clip mids only)  
**Fix 3:** Accept some cancellation (if stereo priority)

---

## Automation Ideas

### Automation 1: 808 Build
- Intro: Clean (bypass Soft Clipper)
- Verse: -4 dB (gentle)
- Chorus: -8 dB (distorted)

### Automation 2: Drop Impact
- Pre-Drop: -6 dB
- Drop Hit: -10 dB (1 beat)
- Drop Sustain: -8 dB

---

## Pitfalls & Fixes

**Pitfall:** Bass gone in mono  
**Fix:** Raise Threshold to -6 dB or use multiband

**Pitfall:** Too aggressive/harsh  
**Fix:** Lower input gain or raise Threshold
