# Cinematic Horror Drones

**Goal:** Create an unsettling, non-repeating background atmosphere.

### The Source
Load a photo with complex, organic details (e.g., an X-ray, a picture of rust, or cracked earth).

### BeepMap Setup
- **Grainy:** ON. This breaks the smooth sine waves into jittery particles.
- **Length:** Set to 15-20 seconds (very slow scan).
- **Widen:** 100%.

### Post-Processing
- **Reverb:** Use a convolution reverb with a "Metallic" or "Large Hall" impulse response.
- **Frequency Shifter:** Add `Fruity Frequency Shifter` and automate a slow shift to create an "unearthly" pitch drift.
- **Result:** A wall of sound that feels like it's shifting and breathing.
