# Reference: Genre Style Board (Kick Design)

Sourced applications of drum synthesis in modern production.

## 1. Atlanta Trap Kicks (Upbeat)
- **Source**: Metro Boomin / Southside style.
- **Application**: Start Freq 800Hz. Hard Drive 40%. Sample layer HP filtered at 5kHz.
- **Vibe**: Aggression, digital "knock," and extreme chest pressure.

## 2. Minimal / Dark R&B Subs (Moody)
- **Source**: Noah "40" Shebib / Drake.
- **Application**: Pure Sine Base. No Sample layer. No Drive. Long Amp Decay.
- **Vibe**: Intimacy, ground-shaking sub weight, and smooth atmospheric power.

## 3. Lo-Fi Hip-Hop Thumps (Vibey)
- **Source**: J Dilla / Madlib style.
- **Application**: Triangle waveform (via Drive). Low Start Freq (200Hz). High Key Release noise (External).
- **Vibe**: Nostalgia, woodiness, and warm "hardware" character.

## 4. Industrial / Cyberpunk Kicks (Psychedelic)
- **Source**: Phonk / Gesaffelstein style.
- **Application**: Max Drive. High Resonance. Pitch LFO automated for shifting "screams."
- **Vibe**: Disorientation, intense harmonic grit, and mechanical coldness.
