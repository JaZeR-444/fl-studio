# 03: Vibe Translation Guide

## Vibe Targets in Sawer

### 1. Moody (Dark, Nostalgic, Gritty)
- **The Lever:** **LP Filter + Noise + Sub Phase.**
- **Setting Moves:**
  - Close the LP filter (24dB mode) to around 300Hz.
  - Add 5% Noise for "tape hiss" texture.
  - Set Sub Phase to 180° for a slightly "hollow" but deep bass.
- **What to listen for:** A muffled, "dusty" tone that feels like an old recording from the 80s.
- **Pitfall:** Too much resonance will make it "whistle" and break the moody vibe. Keep resonance below 20%.

### 2. Upbeat (Aggressive, Tearing, Modern Trap)
- **The Lever:** **Hard Sync + High Resonance.**
- **Setting Moves:**
  - Enable Hard Sync.
  - Set Resonance to 60%+ for that "acid" bite.
  - Use a fast Filter Envelope to create "stabs."
- **What to listen for:** A sound that "cuts" through the mix and demands attention.
- **Pitfall:** If the decay is too long, the aggressive filter will become annoying. Keep stabs short.

### 3. Psychedelic (Trippy, Moving, Evolving)
- **The Lever:** **Matrix Modulation + Phaser.**
- **Setting Moves:**
  - Map LFO to Filter Cutoff and Phaser Frequency.
  - Use a slow Sine LFO for "swirling" motion.
  - Enable high Unison detune (20%).
- **What to listen for:** A sound that feels like it's "breathing" or "spinning" around the stereo field.
- **Pitfall:** Don't modulate the pitch too much or it will become unmusical/out of tune.

### 4. Jazzy (Warm, Sophisticated, Analog Keys)
- **The Lever:** **Soft Attack + Chorus + Velocity.**
- **Setting Moves:**
  - Use a 50ms Attack on the Amp Envelope for "soft" starts.
  - Set Unison to 2 voices for a subtle "stereo width."
  - Route Velocity to Filter in the Matrix.
- **What to listen for:** A "Rhodes-like" response where soft playing is dark and hard playing is bright.
- **Pitfall:** Avoid the "Noise" knob; keep the signal clean and "classy."

### 5. Vibey (Lush, Wide, "Ear-Candy")
- **The Lever:** **Unison + Delay + Retrig.**
- **Setting Moves:**
  - 8 Voices of Unison with high Pan spread.
  - Use the built-in Delay with "Ping-Pong" enabled.
  - Set LFO to "Retrig" so the movement restarts on every note.
- **What to listen for:** A "expensive" sounding pad or lead that fills the speakers effortlessly.
- **Pitfall:** Ensure the low-end is mono; if the unison spreads the sub-bass too wide, the mix will collapse.
