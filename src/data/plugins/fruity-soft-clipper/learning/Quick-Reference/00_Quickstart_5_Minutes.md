# Fruity Soft Clipper: 5-Minute Quickstart

## What You Need to Know RIGHT NOW

**Fruity Soft Clipper = Instant loudness + warmth in 2 knobs.**

- **Threshold:** Lower = more clipping (start at -1 dB)
- **Post Gain:** Makeup volume after clipping (start at 0 dB)

**That's it. You're done.**

## 5-Minute Workflow (Master Bus Setup)

### Step 1: Load the Plugin (30 seconds)
1. Open FL Studio mixer (F9)
2. Click Master track
3. Find an empty FX slot
4. Click → Select → Fruity → Fruity Soft Clipper
5. Plugin window opens

### Step 2: Set Initial Values (30 seconds)
1. **Threshold:** Set to **-1.0 dB**
2. **Post Gain:** Leave at **0 dB**
3. Close plugin window (you can adjust by ear later)

### Step 3: Play Your Mix (1 minute)
1. Press **Space** to play
2. Listen for:
   - Mix sounds **louder**
   - Mix sounds **warmer**
   - Mix sounds **more cohesive**

### Step 4: A/B Test (1 minute)
1. Click the **bypass button** (power icon) on Soft Clipper slot
2. Toggle on/off while playing
3. Bypassed = original, Enabled = clipped
4. **If clipped sounds better, keep it. If not, adjust.**

### Step 5: Fine-Tune (2 minutes)
**If it sounds good:** Done! Move on.

**If it sounds too harsh:**
- Raise Threshold to **-0.5 dB**

**If it sounds too weak:**
- Lower Threshold to **-2.0 dB**

**If you want more volume:**
- Increase Post Gain to **+1 or +2 dB**
- **BUT:** Lower FL Studio's Master fader by the same amount (prevents red clipping)

## 3 Common First-Time Scenarios

### Scenario 1: "It Sounds Louder but WORSE"
**Cause:** You're comparing at different volumes  
**Fix:**
1. Note the volume when clipping is ON
2. Bypass the plugin
3. Turn UP the FL Studio master fader to match volume
4. Now compare tone at matched volumes

### Scenario 2: "Nothing is Happening"
**Cause:** Threshold is set to 0 dB (default)  
**Fix:** Lower Threshold to **-1 to -3 dB**

### Scenario 3: "It Sounds Harsh and Distorted"
**Cause:** Threshold is too low  
**Fix:** Raise Threshold back to **-0.5 to -1 dB**

## One-Sentence Rules for Instant Success

1. **Lower Threshold = More Effect** (like turning up the "intensity")
2. **Start at -1 dB** (conservative but effective)
3. **A/B Test at MATCHED VOLUME** (turn up master fader when bypassed)
4. **Use on Master OR Drums** (don't overthink placement)
5. **If unsure, use -1 dB Threshold, 0 dB Post** (safe default)

## The "Don't Panic" Troubleshooting Guide

| Problem | Instant Fix |
|---------|-------------|
| **"It sounds the same"** | Lower Threshold to -2 dB |
| **"It sounds harsh"** | Raise Threshold to -0.5 dB |
| **"It's too quiet"** | Increase Post Gain to +2 dB |
| **"My master is clipping (red)"** | Lower FL Studio's Master fader by -2 dB |
| **"I hear distortion on bass"** | Check in mono (Ctrl+M); if bass disappears, reduce Threshold |
