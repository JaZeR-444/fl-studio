# Workflow Recipes

## Recipe 1: The Paint-to-Audio Workflow
1.  **Open** Paint (or Photoshop).
2.  **Canvas:** Set size to 512x512, Black background.
3.  **Draw:** Use the Pencil tool.
    -   Draw **Red** dots for Left-ear blips.
    -   Draw **Green** dashes for Right-ear tones.
4.  **Save:** As BMP.
5.  **Load** into BeepMap.
6.  **Play:** You have just "composed" a track visually.

## Recipe 2: The "Grainy" Pad
1.  **Load** a smooth gradient image (e.g., a sunset).
2.  **Enable** the "Grainy" switch.
3.  **Adjust** "Length" to be very slow.
4.  **Add FX:** Add a massive Reverb (Fruity Reeverb 2, "Cathedral" preset) after BeepMap.
5.  **Result:** A lush, granular pad texture that sounds like a stretched sample.

## Recipe 3: Resynthesizing Audio (The Meta Loop)
1.  **Take** a short audio clip (e.g., a drum loop).
2.  **Open** it in Edison.
3.  **Spectral View:** Switch Edison to "Spectral" view.
4.  **Screenshot:** Take a screenshot of the spectral view.
5.  **BeepMap:** Load that screenshot into BeepMap.
6.  **Result:** BeepMap tries to recreate the original audio from the picture of its spectrum. It will sound lo-fi, ghostly, and spectral. Great for "memory" or "dream" sequences.
