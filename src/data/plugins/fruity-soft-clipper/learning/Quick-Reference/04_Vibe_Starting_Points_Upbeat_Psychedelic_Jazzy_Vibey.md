# Fruity Soft Clipper: Vibe Starting Points - Upbeat, Psychedelic, Jazzy, Vibey

## Upbeat Vibe

**Upbeat = Energetic, bouncy, punchy. Aggressive clipping for competitive loudness.**

### Quick Setup
```
Master: Threshold -2.5 dB, Post +2 dB
Drum Bus: Threshold -5 dB, Post +2 dB
808+Kick Bus: Threshold -8 dB, Post +3 dB (boost input +6 dB)
Vocals: Threshold -1 dB, Post 0 dB
```

### Listen For
- Mix "jumps out" of speakers
- Drums slam hard
- 808 has aggressive buzz
- Bright, energetic tone

## Psychedelic Vibe

**Psychedelic = Warped, disorienting, experimental. Extreme distortion, chaos.**

### Quick Setup
```
Master: Threshold -6 to -10 dB, Post Variable
Drum Bus: Asymmetric (Kick -2 dB, Snare -8 dB, Hats -4 dB)
Reverb Returns: Threshold -8 dB (crushed reverb)
Vocals: HPF 500 Hz → Threshold -10 dB (lo-fi effect)
```

### Listen For
- Obvious distortion artifacts
- Unpredictable dynamics
- Broken, degraded character
- Chaotic harmonics

## Jazzy Vibe

**Jazzy = Smooth, organic, vintage. Minimal clipping, wide dynamics, tape warmth.**

### Quick Setup
```
Master: Threshold -0.5 dB, Post 0 dB
Drums: No Soft Clipper (use light compression)
Bass (upright/live): Threshold -2 dB, Post 0 dB
Sample Loop: Threshold -3 dB, Post 0 dB
```

### Listen For
- Warm vintage tone
- Wide dynamics preserved
- Natural transients
- Tape-like saturation

## Vibey Vibe

**Vibey = Smooth, groovy, textural. Balanced clipping, cohesive atmosphere.**

### Quick Setup
```
Master: Threshold -1.5 dB, Post +1 dB
Drum Bus: Threshold -3 dB, Post +1 dB
Pad/Synth Bus: Threshold -2 dB, Post 0 dB
808: Threshold -3 dB, Post 0 dB
Reverb Send: Threshold -2 dB (smooth tails)
```

### Listen For
- Smooth cohesion
- Elements blend naturally
- Controlled but not crushed
- Warm, inviting tone
