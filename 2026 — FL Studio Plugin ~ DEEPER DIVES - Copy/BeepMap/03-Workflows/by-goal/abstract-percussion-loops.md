# Abstract Percussion Loops

**Goal:** Create rhythmic glitch loops using visual patterns.

### The Source
Use high-contrast geometric patterns: Barcodes, QR codes, or striped patterns.

### BeepMap Setup
- **Loop:** ON.
- **Length:** Set to match your project tempo. (Example: If your project is 140bpm, adjust Length until one scan equals 1 bar).
- **Scale:** Linear (Hz) for percussive "clicks".

### Workflow
1. Load a Barcode image.
2. The vertical lines will create sharp rhythmic pulses.
3. Use a **Gate** or `Fruity Love Philter` after BeepMap to tighten the clicks into percussive hits.
4. **Variation:** Rotate the image in an external editor to change the rhythm.
