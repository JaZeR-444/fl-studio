# Goal: Vibe - Psychedelic

## Goal Statement
Create a trippy, warping vocal that glitches out and changes pitch randomly.

## Step-by-Step Setup
1. **Style:** Select **Random**.
2. **Mode:** Select **Breathy**.
3. **Voice:** Select **Robot**.
4. **Render:** Hit OK.
5. **Mixer FX:**
   - **Fruity Granulizer:** Automate the "Grain Spacing" and "Wave Candy" settings.
   - **Fruity Love Philter:** Use a "Pancake" or "Random Filter" preset.
   - **Fruity Flanger:** To add a "liquid" texture.

## What to Listen For
- The voice should jump between notes unpredictably.
- The "breathy" and "robotic" textures should combine to create a "liquid" sound.
