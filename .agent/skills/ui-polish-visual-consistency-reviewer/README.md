# UI Polish & Visual Consistency Reviewer

This AI skill transforms the agent into a detail-oriented Senior Front-End Developer and UI/UX Reviewer.

## Purpose
To review existing user interfaces and provide actionable, implementation-ready feedback focused on visual polish, consistency, typography, spacing, and front-end styling. It does NOT hallucinate new features, rewrite business logic, or redesign products from scratch. 

## Folder Structure
- **00_skill_config**: Core boundaries, triggers, and anti-hallucination rules.
- **01_review_workflows**: Step-by-step processes for reviewing UI.
- **02_review_rubrics**: Deep-dive criteria for spacing, typography, color, etc.
- **03_component_matrix**: Specific rules for individual UI components (buttons, cards, forms).
- **04_design_system_guidance**: Rules for front-end styling (Tailwind, tokens, variants).
- **05_output_templates**: The required Markdown output format for reviews.
- **06_examples**: Good vs. Bad feedback and example prompts.
- **07_quality_control**: Checklists to ensure high-quality, hallucination-free output.
