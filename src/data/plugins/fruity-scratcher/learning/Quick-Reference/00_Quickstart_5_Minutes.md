# Fruity Scratcher — 5-Minute Quickstart

## Goal
Get scratching within 5 minutes.

## Step 1: Load Fruity Scratcher (30 seconds)
1. Open FL Studio
2. Press **F9** (Mixer)
3. Select an empty Insert track
4. Click empty effect slot → **Fruity Scratcher**
5. Plugin window opens

## Step 2: Load a Sample (30 seconds)
1. Click **folder icon** (top-left of plugin)
2. Navigate to a short vocal sample (1-3 seconds ideal)
   - Try: FL Studio default samples → Vocals → "Hey.wav" or "Yeah.wav"
3. Sample loads into waveform display

## Step 3: Basic Scratch Test (1 minute)
1. Click **Play** button (bottom transport controls)
2. **Click and drag** the center platter disc **left and right**
3. Listen: Sample plays forward (right drag) and backward (left drag)
4. Release mouse: Sample continues at current speed

**✓ Checkpoint:** Can you hear the sample scratching as you drag the platter?

## Step 4: Adjust Physics (1 minute)
1. **ACC (Acceleration) Knob:** Set to **50%**
   - This controls how "springy" the turntable feels
   - Higher = instant response; Lower = elastic, drifting feel
2. **SEN (Sensitivity) Knob:** Set to **50%**
   - This controls how much mouse movement affects speed
   - Higher = touchy; Lower = requires more drag for speed change
3. **Test Again:** Drag platter and feel the difference

**✓ Checkpoint:** Does the scratch feel more responsive with ACC at 50%?

## Step 5: Create a Tape Stop Effect (2 minutes)
1. Right-click **SPD (Speed) knob**
2. Select **"Create automation clip"**
3. In the **Playlist**:
   - Draw automation from **100%** (normal speed) down to **0%** (stopped) over 2 beats
4. Press **Space** to play
5. Listen: Sample slows down smoothly (tape stop effect)

**✓ Checkpoint:** Does the sample slow to a stop like a tape machine powering down?

## Quick Reference Card

| **Control** | **Function** | **Default** |
|-------------|--------------|-------------|
| **Platter (center disc)** | Click + drag to scratch | Interactive |
| **SPD** | Playback speed | 1.0x |
| **ACC** | Turntable motor response | 50% |
| **SEN** | Mouse/MIDI sensitivity | 50% |
| **Play** | Start continuous playback | Button |
| **Pause** | Freeze playback | Button |
| **Reverse** | Flip playback direction | Button |

## Next Steps

- **For Hip-Hop:** Load short vocal stabs and practice "chirp" scratches (forward-back-forward)
- **For Tape Stops:** Automate SPD from 1.0x → 0.0x over 2-4 beats
- **For MIDI Control:** Right-click SPD → "Link to controller" → move jog wheel/fader

---

## Common First-Timer Issues

**Problem:** "Clicking/popping sounds when I scratch"  
**Fix:** Increase ACC to 60-70% OR use samples with smoother attack transients

**Problem:** "Scratch feels too sluggish"  
**Fix:** Increase both ACC and SEN to 60-70%

**Problem:** "Sample cuts off mid-scratch"  
**Fix:** Load a longer sample (3-5 seconds) OR enable loop mode

**Problem:** "I hear nothing when I click Play"  
**Fix:** Check if **Hold** button is engaged (should be OFF)
