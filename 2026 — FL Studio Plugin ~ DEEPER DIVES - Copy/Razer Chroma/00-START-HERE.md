# Razer Chroma - Getting Started Guide for Hip-Hop/R&B

## Introduction

Welcome to the comprehensive research guide for Razer Chroma, FL Studio's hardware visualization plugin. This guide focuses on using Razer Chroma specifically for hip-hop and R&B production, creating synchronized lighting experiences that enhance your creative process.

## What is Razer Chroma?

Razer Chroma is a hardware visualization plugin that allows FL Studio to control RGB lighting on Razer hardware (Keyboards, Mice, Headsets, Hue Lights). It translates audio or project data into light shows, creating synchronized visual experiences that enhance your music production workflow.

## Getting Started

### Step 1: Hardware Setup
Ensure you have:
- Razer keyboard, mouse, headset, or other Chroma-enabled device
- Razer Synapse 3 installed and running
- "Chroma Connect" enabled in Synapse settings

### Step 2: Software Configuration
1. Open Razer Synapse 3
2. Go to "Connect" tab
3. Enable "FL Studio" as a connected application
4. Set FL Studio as high priority for lighting control

### Step 3: Plugin Installation
1. Launch FL Studio
2. Verify Razer Chroma appears in the browser
3. Load the plugin on a mixer track
