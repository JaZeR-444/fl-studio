# Goal: Aggressive Bass Design

## Goal Statement
Create a "mean," gritty analog bass that growls through the low-mids, perfect for dark trap or industrial-leaning beats.

## Routing Context
1. **Sawer:** Mono Mode, Legato ON.
2. **Fruity Blood Overdrive:** For extra "meat."
3. **Fruity Limiter:** Sidechain to the Kick.

## Step-by-Step Setup
1. **Oscillators:** Set **Saw** to 100%, **Sub Level** to 100%. Set **Sub Phase** to 180°.
2. **Filter:** Select **LP 24dB**. Set **Cutoff** to 15%.
3. **Resonance:** Turn **Resonance** up to 40% (the "Polivoks Growl").
4. **Envelope:** Set **Filter Env Amount** to +60%. Set **Filter Decay** to 800ms.
5. **Drift:** Turn up **Detune** (just slightly, 5%) even in Mono mode to add instability.

## Starting Settings
- **Filter Cutoff:** 15%
- **Resonance:** 40%
- **Filter Decay:** 800ms
- **Sub Level:** 100%

## Variations
- **Variation 1 (Sliding):** Increase **Glide** time for sliding 808-style movement.
- **Variation 2 (Buzzy):** Change Filter to **BP** mode for a nasal, mid-heavy "talkative" bass.
