# Sytrus - FM Synthesis Concepts

## Overview
Sytrus is a powerful FM (Frequency Modulation) and subtractive synthesizer that combines multiple synthesis methods. Understanding its core concepts enables producers to create complex, evolving sounds for hip-hop, trap, and EDM production.

## Core Synthesis Principles

### FM Synthesis Architecture
- **Operators**: 6 operators per patch (3 carriers, 3 modulators)
- **Algorithms**: 64 pre-configured routing schemes
- **Frequency Ratios**: Relative frequency relationships
- **Modulation Index**: Depth of frequency modulation
- **Feedback**: Self-modulation for harmonic complexity

### Subtractive Synthesis Components
- **Oscillators**: Multiple waveform generators
- **Filters**: Multi-mode filter section
- **Envelopes**: 3 envelopes per operator
- **LFOs**: 3 LFOs per patch
- **Effects**: Built-in effects processing

## Operator Configuration

### Operator Types
- **Carrier Operators**: Generate audible output
- **Modulator Operators**: Modulate carrier frequencies
- **Fixed Frequency**: Independent of note pitch
- **Ratio-Based**: Proportional to note pitch

### Operator Parameters
- **Waveform**: Sine, triangle, sawtooth, square, noise
- **Ratio**: Frequency multiplier
- **Fine**: Detuning adjustment
- **Level**: Output volume
- **Pan**: Stereo positioning
- **Phase**: Initial phase offset

## Algorithm Structure

### Algorithm Categories
- **Simple**: 1-2 operators for basic FM sounds
- **Complex**: 3-6 operators for rich textures
- **Parallel**: Multiple carriers for layering
- **Series**: Modulators in chain for complexity
- **Feedback**: Self-modulating structures

### Common Algorithm Types
- **Stack**: Modulators in series
- **Branching**: Single modulator affecting multiple carriers
- **Parallel Carriers**: Multiple independent carriers
- **Feedback Loops**: Self-modulating structures

## Modulation Techniques

### Operator Modulation
- **Frequency Modulation**: Carrier frequency modulation
- **Amplitude Modulation**: Volume modulation
- **Ring Modulation**: Complex harmonic generation
- **Sync Modulation**: Hard/soft sync effects

### Envelope Modulation
- **Operator Envelopes**: Per-operator amplitude control
- **Global Envelopes**: Overall patch modulation
- **Velocity Modulation**: Note velocity control
- **Aftertouch Modulation**: Pressure sensitivity

### LFO Modulation
- **Slow Modulation**: Vibrato, tremolo effects
- **Fast Modulation**: FM depth modulation
- **Random Modulation**: Texture variation
- **Step Sequencer**: Rhythmic modulation

## Troubleshooting Common Issues

### Harsh, Unpleasant Sounds
- **Reduce Modulation Index**: Lower FM depth
- **Use Sine Waves**: Cleaner modulation
- **Simplify Algorithms**: Fewer operators
- **Adjust Ratios**: More harmonic relationships

### Thin, Weak Sounds
- **Increase Operators**: More complex algorithms
- **Add Parallel Carriers**: Layering sounds
- **Use Rich Waveforms**: More harmonic content
- **Adjust Levels**: Balance operator volumes

### Muddy, Indistinct Sounds
- **Simplify Algorithm**: Reduce complexity
- **Use EQ**: Carve frequency space
- **Adjust Ratios**: More distinct frequencies
- **Reduce Feedback**: Less self-modulation

### Unstable Tuning
- **Check Ratios**: Ensure proper relationships
- **Use Fixed Frequencies**: For stability
- **Apply Pitch Correction**: Fine-tuning
- **Monitor Key Tracking**: Proper scaling
