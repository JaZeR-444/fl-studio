# Fruity Scratcher — Goal: Sample Flip & Chop

## Workflow Goal
Use scratching techniques to creatively manipulate samples—flipping loops, chopping breaks, and creating new rhythmic material.

---

## Workflow 1: Vinyl Flip (Lo-Fi Texture)

### Routing Context
- Scratcher on sample channel → Effector (vinyl) → Parametric EQ 2 → Mixer

### Steps
1. Load jazz/soul loop (4-8 bars)
2. SPD: 0.92x ↔ 1.08x (slow sine automation)
3. ACC: 35%
4. Add Effector (vinyl mode, 30% mix)
5. EQ: Boost 200-500 Hz, cut 8 kHz+
6. Record to audio, re-chop in Slicer

### What to Listen For
- [ ] Vintage vinyl character
- [ ] Subtle pitch wobble
- [ ] Warm, dusty tone

### Vibe: Jazzy, Vibey

---

## Workflow 2: Break Chop (Boom-Bap)

### Routing Context
- Scratcher on drum break → Edison (record) → Slicer

### Steps
1. Load classic break (Amen, Apache)
2. Manually scratch to find "hit" points
3. SPD: 1x, ACC: 80%, SEN: 65%
4. Record scratch performance to Edison
5. Export, chop in Slicer
6. Trigger slices via MIDI

### Vibe: Upbeat, Boom-Bap

---

## Workflow 3: Reverse Sample Flip (Moody)

### Routing Context
- Scratcher on sample → Reverb 2 → Delay 3 → Mixer

### Steps
1. Load melodic sample (vocal, synth, pad)
2. SPD: -0.7x (reverse)
3. ACC: 45%
4. Add reverb (60% mix) + delay (30% mix)
5. Low in mix as background atmosphere

### Vibe: Moody, Vibey, Psychedelic

---

## Workflow 4: Stutter Chop (Trap)

### Routing Context
- Scratcher on vocal/sample → Hold automation → Mixer

### Steps
1. Load short sample (1-2 sec)
2. SPD: 1x, ACC: 90%
3. Automate Hold button for rhythmic stutters
4. Create stutter pattern in time with hi-hats
5. Record to audio

### Vibe: Upbeat, Trap
