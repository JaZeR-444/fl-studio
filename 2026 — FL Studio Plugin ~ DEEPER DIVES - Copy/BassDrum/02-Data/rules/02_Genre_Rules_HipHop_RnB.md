# Genre Rules: Hip-Hop & R&B (BassDrum)

## 1. The "Frequency Alignment" Rule
- **Rule**: Always set the **End Freq** first. 
- **Why**: Hip-hop relies on the relationship between the kick and the 808. If your kick's tail is in a different key than your bass, they will clash and make the low end sound "muddy" or "blurry."
- **Action**: Match the Hz to your project root.

## 2. Transient Layering Mandate
- **Rule**: For Trap, use a **High Pass Filter** on the Sample layer (at ~5kHz).
- **Goal**: To capture the "crack" of the snare-like transient without adding unnecessary mid-range noise that would clutter the vocals.

## 3. The "Soft Clip" Strategy
- **Rule**: Use the **Clip** drive type for aggressive kicks, but follow with a **Fruity Soft Clipper** in the mixer.
- **Why**: BassDrum's internal clipping is "Hard," which can sound too digital. The external Soft Clipper "rounds off" the peaks for a more expensive professional sound.

## 4. Sub-Bass Stabilization
- **Rule**: When using BassDrum for 808s, set **Start Freq** to under 200Hz.
- **Why**: High start frequencies create a "kick" sound. To create a stable 808, you want a gentle pitch glide, not a percussive knock.
