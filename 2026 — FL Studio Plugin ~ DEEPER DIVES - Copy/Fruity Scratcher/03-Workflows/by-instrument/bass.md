# Fruity Scratcher — by-instrument: Bass

## Bass Scratching in Hip-Hop/R&B

Bass scratching (especially 808s) creates pitch effects and transitions. Less common than vocal/drum scratching but effective for specific applications.

---

## Mini-Recipe 1: 808 Pitch Drop (Trap/Moody)

### Parameters
- SPD: 1x → 0.5x (automate)  
- ACC: 55%  
- Sample: 808 bass one-shot (1-3 sec)

### Steps
1. Load 808 sample
2. Automate SPD from 1x to 0.5x over last 2 beats of bar
3. Creates "falling" bass effect
4. Use at end of phrases

### What to Listen For
- [ ] Smooth pitch drop
- [ ] Bass doesn't mud up low end
- [ ] Fits with track's minor key

### Vibe Mapping
- **Moody:** Drop to 0.4x-0.5x (very deep)
- **Vibey:** Subtle drop (1x → 0.85x)

## Mini-Recipe 2: Bass Note Scratch (Experimental)

### Parameters
- SPD: 1x  
- ACC: 75%  
- SEN: 60%  
- Sample: Bass note (0.5-2 sec)

### Steps
1. Load sustained bass note
2. Scratch rhythmically
3. Use sparingly (experimental technique)
4. Works best in minimal arrangements

### Vibe Mapping
- **Psychedelic:** Wide SPD range (0.7x ↔ 1.3x)
- **Jazzy:** Swung bass note scratches

## Mini-Recipe 3: 808 Tape Stop (Transition)

### Parameters
- SPD: 1x → 0x  
- ACC: 25-35%  
- Sample: 808 loop or sustained note

### Steps
1. Load 808 pattern
2. Automate SPD to 0x before drop
3. Low ACC for dramatic, heavy stop

### Vibe Mapping
- **Moody:** Very gradual (6-8 beats)
- **Trap:** Quick stop (2-4 beats)

---

## Mini-Recipe 4: Sub-Bass Reverse Swell

### Parameters
- SPD: 0x → -0.8x  
- ACC: 40%  
- Sample: Sub-bass note (3-5 sec)

### Steps
1. Load deep bass note
2. Automate SPD from 0x to -0.8x (reverse swell)
3. Use as riser before drop

### What to Listen For
- [ ] Creates tension
- [ ] Sub frequency build-up
- [ ] Peaks at downbeat
