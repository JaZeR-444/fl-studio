# Parameter Dictionary

## Oscillator Section
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Saw** | Continuous | Level of the main Sawtooth oscillator. | All |
| **Sub Level** | Continuous | Level of the -1 Octave Sub oscillator. | Moody/Upbeat |
| **Sub Phase** | Continuous | Phase alignment of the Sub relative to the Saw. | Upbeat |
| **Noise** | Continuous | White noise level for vintage texture. | Moody |
| **Sync** | Toggle | Enables Hard Sync between oscillators. | Upbeat/Psychedelic |

## Filter Section
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Cutoff** | Continuous | Filter frequency cutoff point. | All |
| **Resonance** | Continuous | Resonance feedback at the cutoff point. | Upbeat/Psychedelic |
| **Mode** | Stepped | LP (Low Pass), BP (Band Pass), HP (High Pass). | All |
| **Slope** | Stepped | 12dB or 24dB filter steepness. | Moody (24dB) |
| **KBD** | Continuous | Keyboard tracking intensity. | Jazzy |

## Modulation & Matrix
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **LFO Speed** | Continuous | Rate of LFO modulation. | Psychedelic/Vibey |
| **Matrix Source** | Stepped | Modulation source (LFO, Env, Vel, etc.). | Jazzy/Psychedelic |
| **Matrix Dest** | Stepped | Modulation destination (Pitch, Filter, Pan, etc.). | All |

## Effects & Master
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Unison Voices** | Stepped | Number of unison voices (1-8). | Vibey |
| **Unison Detune** | Continuous | Amount of detuning between voices. | Vibey/Psychedelic |
| **Glide** | Continuous | Portamento time between notes. | Upbeat/Moody |
