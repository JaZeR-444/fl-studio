- [Strong point 2]

## Biggest Visual Consistency Issues

- [Main problem 2 reducing polish]

## Component-Level Recommendations
- **[Component Name]:** [Specific, actionable recommendation]
- **[Component Name]:** [Specific, actionable recommendation]

## Typography & Hierarchy Recommendations
- [Explain how to improve scanability, text rhythm, labels, headings, or proof points.]

## Spacing, Layout & Section Rhythm Recommendations
- [Explain where spacing, alignment, section separation, or layout rhythm should improve.]

## Color, Contrast, Borders & Shadow Recommendations
- [Explain how to make the UI feel more cohesive and professional.]

## Accessibility & Usability Recommendations
- [Explain polish-related accessibility improvements such as contrast, focus states, target size, and readability.]

## Responsive Design Recommendations
- [Explain likely mobile, tablet, and desktop improvements.]

## Front-End Implementation Recommendations
- [Explain reusable class patterns, component variants, design tokens, and minimal code-level improvements. Omit if no code is provided.]
