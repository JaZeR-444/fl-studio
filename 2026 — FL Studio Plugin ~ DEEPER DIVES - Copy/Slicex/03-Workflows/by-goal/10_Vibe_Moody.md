# Goal: Vibe - Moody

## Goal Statement
Create a dark, "receding" sample chop that feels like a distant memory.

## Step-by-Step Setup
1. **Sample Choice:** Choose a piano or Rhodes loop.
2. **Reverse:** Reverse every 4th slice using `Ctrl + R` in the editor.
3. **Filter Articulation:** Assign all slices to **Articulator 1**. Select **LP filter**.
4. **Cutoff:** Set Cutoff to 300Hz (Very dark).
5. **Reverb (External):** Route Slicex to a mixer track with 100% Wet Reverb.
6. **Master Pitch:** Pitch the whole sample down -12 semitones (1 octave).

## What to Listen For
- A "thick" and "underwater" sound.
- The reversed slices should create a subtle "sucking" effect that adds mystery.
- The tone should be warm with zero high-end harshness.
