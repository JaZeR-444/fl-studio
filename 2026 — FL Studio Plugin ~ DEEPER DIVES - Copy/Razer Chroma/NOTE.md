# Note: Razer Chroma and ReWire

## Razer Chroma
Razer Chroma is a hardware/software integration for RGB lighting synchronization. It is **not an audio processing plugin** and therefore does not have:
- Sound presets
- Audio processing workflows
- Synthesis parameters

**Use Case:** Visual synchronization with Razer peripherals during production.

---

## ReWire
ReWire is a **protocol** for routing audio between different applications (e.g., FL Studio and Reason). It is **not an audio plugin** and therefore does not have:
- Sound presets
- Audio processing capabilities
- Synthesis parameters

**Use Case:** Real-time audio routing between DAWs.
