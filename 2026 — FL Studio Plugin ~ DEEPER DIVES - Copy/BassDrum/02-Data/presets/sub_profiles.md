# Sub-Bass Profile Library

## The "Deep House" Sub
- Base: 42Hz (E).
- Duration: 400ms.
- Slide: Fast.
- Output: Very clean sine.

## The "Trap" Long Kick
- Base: 32Hz (C).
- Duration: 1500ms+.
- Slide: Slow (creates the boom).
- Sample: Short high-pass click.

## The "Hardstyle" Punch
- Base: 55Hz (A).
- Duration: 300ms.
- Sampling Ratio: 40% (Adds ringing grit).
