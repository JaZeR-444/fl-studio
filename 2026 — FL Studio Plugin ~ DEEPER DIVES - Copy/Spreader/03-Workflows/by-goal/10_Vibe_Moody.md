# Goal: Vibe - Moody

## Goal Statement
Create a deep, centered, yet atmospheric texture for late-night moody tracks.

## Step-by-Step Setup
1. **Width:** Set to 20% (Very subtle).
2. **Low Bypass:** Set to 500Hz. This is higher than usual.
3. **Effect:** This keeps almost the entire frequency range mono, except for the high-end "air" and "sparkle."
4. **Processing:** Add a dark **Reverb** (External) BEFORE Spreader.
5. **Result:** The reverb gets widened while the dry instrument stays perfectly centered and intimate.

## What to Listen For
- A "stable" core sound with a "ghostly" wide tail.
- A feeling of depth rather than width.
