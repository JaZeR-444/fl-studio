# Drums Analysis with Fruity Spectroman

## Drum Element Frequency Signatures

### Kick Drum
**Fundamental:** 50-80 Hz (thump, weight)  
**Body/Tone:** 100-200 Hz (character)  
**Attack:** 3-5 kHz (click, punch)

**Spectroman Check:**
- Strong red at 50-80 Hz
- Moderate at 100-200 Hz
- Sharp peak at 3-5 kHz (attack)

---

### Snare Drum
**Fundamental:** 150-250 Hz (body)  
**Harmonics:** 500 Hz - 3 kHz (snap)  
**Attack:** 3-6 kHz (crack, presence)  
**Snare Wires:** 6-10 kHz (sizzle)

**Spectroman Check:**
- Present at 150-250 Hz
- Energy at 500 Hz - 3 kHz
- Clear attack at 3-6 kHz

---

### Hi-Hats
**Main Content:** 6-12 kHz (shimmer, presence)  
**Air:** 10-16 kHz (brightness, detail)

**Spectroman Check:**
- Visible at 6-12 kHz
- Extended to 12+ kHz for modern sound
- Should NOT dominate spectrum

---

## Drum Mixing Workflow

### Step 1: Kick Foundation (3 min)
1. Solo kick
2. Check 50-80 Hz in Spectroman
3. If weak: Boost fundamental
4. If boomy: Cut 100-200 Hz
5. Add attack at 3-5 kHz if needed

**Target:** Clear red spike at fundamental, visible attack

---

### Step 2: Kick vs. Bass Separation (5 min)
1. Solo kick + bass
2. Check 40-100 Hz overlap
3. If competing:
   - Sidechain bass to kick
   - OR tune to different frequencies
4. **Check Spectroman:** Clear separation visible

---

### Step 3: Snare Placement (3 min)
1. Add snare to mix
2. Check 150-250 Hz (body) and 3-6 kHz (attack)
3. If buried: Boost presence
4. If harsh: Cut resonant frequency

---

### Step 4: Hi-Hats Balance (2 min)
1. Add hi-hats
2. Check 6-12 kHz
3. Should add energy without dominating
4. If too loud: Reduce level, not just EQ

---

## Common Drum Issues

**Muddy Drums:**
- Too much 200-500 Hz
- Cut on kick, snare, toms

**Thin Kick:**
- Weak at 50-80 Hz
- Boost fundamental

**Harsh Cymbals:**
- Excessive 6-8 kHz
- Cut or reduce level

---

## Drum Checklist
- [ ] Kick fundamental clear (50-80 Hz)
- [ ] Snare has body and attack
- [ ] Hi-hats present but controlled
- [ ] No mud in 200-500 Hz
