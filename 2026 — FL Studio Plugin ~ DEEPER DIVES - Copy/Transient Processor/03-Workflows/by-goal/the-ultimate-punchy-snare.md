# Goal: The Ultimate Punchy Snare

## Goal Statement
Transform a "flat" or "dull" snare drum into a high-energy, sharp hit that cuts through a dense production.

## Routing Context
1. **Snare Channel:** Raw snare hit.
2. **Transient Processor:** The primary shaper.
3. **Fruity Blood Overdrive:** For post-shaping grit (Optional).
4. **Fruity Limiter:** To catch any extreme peaks.

## Step-by-Step Setup
1. **Attack:** Boost the **Attack** knob to +6.0dB. Watch the bottom histogram—you should see sharp "spikes" on every hit.
2. **Release:** Turn the **Release** knob down to -4.0dB. This removes any unnecessary "ring" or room tone from the snare.
3. **Protection:** Set **Split Freq** to 200Hz. This ensures the "body" of the snare doesn't distort.
4. **Fatness:** Set **Drive** to 10%. This adds a slight harmonic saturation to the peak, making it sound "fatter."
5. **Leveling:** Adjust the **Gain** knob so the snare's overall peak volume matches the original signal (use the Mixer meter to check).

## Starting Settings
- **Attack:** +6dB
- **Release:** -4dB
- **Split Freq:** 200Hz
- **Drive:** 10%

## Variations
- **Variation 1 (Extreme Snap):** Turn Attack to +10dB and use 50% Mix.
- **Variation 2 (Gated Snare):** Turn Release all the way to -15dB for a "dry" 80s pop snare feel.
