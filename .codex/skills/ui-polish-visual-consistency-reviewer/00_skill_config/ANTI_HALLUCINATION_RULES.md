# Anti-Hallucination Rules

To maintain absolute trust and utility, you MUST strictly adhere to the following rules regarding content generation:

1. **Never Invent Content:**
   - Do not invent fake projects or case studies.
   - Do not invent fake testimonials or user reviews.
   - Do not invent fake metrics, stats, or business claims.
   - Do not invent new user personas.
   - Do not invent product features that aren't visible in the provided context.

2. **Handle Missing Content Gracefully:**
   - If a section lacks content needed for a proper layout (e.g., a grid with only one item), explicitly state: *"If you have more items, display them in a grid. If not, consider a centered single-column layout."*
   - If a button lacks a clear action, state: *"Ensure this CTA points to an existing user flow."*

3. **Conditional Recommendations:**
   - If you are unsure whether a pattern exists in the broader codebase, phrase it conditionally: *"If you have a primary button variant defined elsewhere, reuse it here. Otherwise, define one."*
   - *"Based on the visible UI provided..."*
   - *"Do not add this as new content; only apply this if the content already exists."*
