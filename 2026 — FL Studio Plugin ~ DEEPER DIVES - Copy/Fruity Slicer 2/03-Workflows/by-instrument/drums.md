# Drums - Fruity Slicer 2 Workflows

**Instrument:** Drums (loops, breaks, one-shots)  
**Primary Use:** Slice, rearrange, and reconstruct drum patterns

---

## Workflow 1: Classic Breakbeat Reconstruction

### Goal
Slice a famous break (Amen, Think, Funky Drummer) and create custom pattern

### Time: 10 minutes

---

### Step-by-Step

**1. Load Break (1 min)**
- Load classic break into Slicer
- Common breaks:
  - Amen Break (138 BPM, 2 bars)
  - Think Break (135 BPM, 4 bars)
  - Funky Drummer (98 BPM, 8 bars)
  - Apache (117 BPM)

**2. Set BPM and Slice (2 min)**
- Enter correct BPM (see above)
- Auto-Slice @ 1/16 division
- Enable zero-crossing snap (avoid clicks)

**3. Identify Key Hits (2 min)**
- Play each slice:
  - Kick slices (usually C5, E5, etc.)
  - Snare slices (usually D5, F#5, etc.)
  - Hi-hat/cymbal slices
  - Ghost notes/fills
- Color-code in Piano Roll for visual reference

**4. Build Pattern (3 min)**
- Create basic boom bap:
  ```
  Beat 1: Kick (C5)
  Beat 2: Snare (D5)
  Beat 3: Kick (C5)
  Beat 4: Snare (D5)
  + Hi-hats on offbeats
  ```
- Add swing (60-70%) for groove

**5. Process (2 min)**
- Route kick slices to separate mixer track (Bass + punch)
- Route snare slices to separate track (Reverb)
- High-pass hi-hat slices at 300 Hz
- Optional: Parallel compression on drum bus

---

### Settings

**Slice Division:** 1/16  
**Stretch Mode:** Enabled (if changing project BPM)  
**Swing:** 60-70% (boom bap), 0% (trap)  
**Velocity:** Vary 60-100% (snare loud, hats quiet)

## Workflow 2: Trap Hi-Hat Rolls

### Goal
Create aggressive hi-hat rolls for trap drops/builds

### Time: 5 minutes

---

### Step-by-Step

**1. Load Hi-Hat Sample (30 sec)**
- Single hi-hat hit (bright, crisp)
- Or slice from hi-hat loop

**2. Slice (30 sec)**
- Auto-Slice creates single slice
- Or manual slice if from loop

**3. Create Roll Pattern (2 min)**
- Piano Roll: 1/32 note pattern (4 beats before drop)
- Example:
  ```
  4 bars before drop: straight 1/32 notes
  Builds tension
  ```

**4. Velocity Automation (1 min)**
- Crescendo: Start 60%, end 100%
- Creates build-up tension
- Common before drops/transitions

**5. Process (1 min)**
- High-pass at 500 Hz (bright, cutting)
- Very short decay (10-20 ms) - tight
- Optional: Slight reverb send (10-15%)

---

### Settings

**Slice Division:** Single hit or 1/32  
**Attack:** Instant (0 ms)  
**Decay:** 10-20 ms (very short)  
**Velocity Automation:** 60% → 100% crescendo

## Workflow 3: Live Drum Kit Reconstruction

### Goal
Slice drum loop, separate into kit pieces, rebuild custom pattern

### Time: 15 minutes

---

### Step-by-Step

**1. Load Drum Loop (1 min)**
- Full drum kit loop (1-2 bars)
- Live recording or programmed loop

**2. Slice by Instrument (3 min)**
- Auto-Slice @ 1/8 or 1/16
- Manually adjust to isolate:
  - Kick hits
  - Snare hits
  - Hi-hat hits
  - Cymbal crashes
  - Tom fills

**3. Route to Separate Tracks (3 min)**
- Right-click kick slices → Send to track "Kick"
- Right-click snare slices → Send to track "Snare"
- Repeat for all kit pieces
- Each instrument on its own mixer channel

**4. Process Individually (5 min)**
- **Kick:** EQ boost at 60 Hz (sub), HP at 30 Hz, compression
- **Snare:** EQ boost at 200 Hz (body), reverb send 25%
- **Hi-hats:** HP at 300 Hz, tight decay, light compression
- **Cymbals:** HP at 500 Hz, longer decay, reverb send 30%

**5. Rebuild Pattern (3 min)**
- Create new pattern in Piano Roll
- Use isolated kit pieces
- Build custom groove

---

### Settings

**Slice Division:** 1/8 or 1/16 (depends on loop complexity)  
**Routing:** Individual mixer tracks per instrument  
**Processing:** Unique EQ/compression per piece

## Workflow 4: Boom Bap Swing Pattern

### Goal
Create classic J Dilla / Pete Rock swing feel

### Time: 10 minutes

---

### Step-by-Step

**1. Load Break (1 min)**
- Soul/funk drum break
- 2-4 bars, 90-110 BPM ideal

**2. Slice and Set Swing (2 min)**
- Auto-Slice @ 1/16
- Set swing to 65-70% (J Dilla feel)
- Quantize to grid (then swing applies)

**3. Build Pattern with Swing (3 min)**
- Basic pattern:
  ```
  Kick on 1 and 3 (downbeats)
  Snare on 2 and 4 (backbeat)
  Hi-hats on all offbeats (swing applied)
  ```
- Swing shifts offbeats, creates laid-back groove

**4. Velocity Variation (2 min)**
- **Kick:** 95-100% (consistent punch)
- **Snare:** 100% (emphasis)
- **Hi-hats (downbeat):** 80-85%
- **Hi-hats (offbeat):** 65-75% (ghost notes)

**5. Add Fills (2 min)**
- Tom/cymbal slices for transitions
- End of 4/8 bar phrases
- Creates movement and interest

---

### Settings

**Swing:** 65-70%  
**Velocity Range:** 65-100%  
**Slice Division:** 1/16

## Workflow 5: DnB/Jungle Rapid-Fire Break

### Goal
170+ BPM complex breakbeat for drum & bass

### Time: 15 minutes

---

### Step-by-Step

**1. Load Amen Break (1 min)**
- Original Amen @ 138 BPM
- 2-bar loop

**2. Time-Stretch to 170-180 BPM (2 min)**
- Enable "Stretch" mode
- Set original BPM to 138
- Change project BPM to 170-180
- Slices auto-adjust timing

**3. Fine Slice (3 min)**
- Auto-Slice @ 1/32 (extreme granularity)
- Allows complex rearrangement
- More slices = more possibilities

**4. Rearrange Rapidly (5 min)**
- Shuffle kick and snare placements:
  ```
  Kick-Kick-Snare-Kick (rapid)
  Double-time hi-hats
  Chaotic, energetic
  ```
- Create signature DnB break edits

**5. Process for Energy (4 min)**
- Compression (heavy, 4:1 ratio)
- Parallel distortion (grit)
- High-pass at 40 Hz (sub clarity)
- Light reverb on snare only (10%)

---

### Settings

**BPM:** 170-180  
**Slice Division:** 1/32  
**Stretch:** Enabled  
**Compression:** Heavy (4:1, fast attack)

## Drum Slicing Tips by Style

### Boom Bap
- **Division:** 1/16
- **Swing:** 60-70%
- **Velocity:** Wide range (60-100%)
- **Processing:** Vintage saturation, short reverb

### Trap
- **Division:** 1/8 (kicks/snares), 1/32 (rolls)
- **Swing:** 0% (tight)
- **Velocity:** Narrow (80-100%), rolls with ramps
- **Processing:** Aggressive compression, minimal reverb

### DnB
- **Division:** 1/32
- **Swing:** 0%
- **Velocity:** Moderate variation
- **Processing:** Heavy compression, tight sound

### Lo-Fi
- **Division:** 1/8
- **Swing:** 65-75%
- **Velocity:** Very varied (50-100%)
- **Processing:** Vinyl crackle, tape saturation, warm

## Common Drum Mistakes

**Mistake 1: No Velocity Variation**
- Robotic, lifeless drums
- Fix: Vary 60-100%, emphasize snare

**Mistake 2: Wrong BPM Before Slicing**
- Off-beat slices, unusable
- Fix: Check BPM first, then slice

**Mistake 3: Over-Compressed**
- Squashed, no dynamics
- Fix: Lighter compression, preserve transients

**Mistake 4: Muddy Low-End**
- Hi-hats/cymbals have bass buildup
- Fix: High-pass at 300 Hz minimum

## The Bottom Line

**Drum slicing in Fruity Slicer 2: Load break → Set correct BPM → Auto-Slice @ 1/16 (boom bap) or 1/32 (DnB) → Isolate kick, snare, hi-hats → Rebuild pattern with swing (60-70% boom bap, 0% trap) → Vary velocities (60-100%) → Process per instrument (kick = sub, snare = reverb, hats = HP).** Classic breaks (Amen, Think) slice at 1/16. Trap hi-hat rolls at 1/32 with velocity crescendos. Route instruments to separate mixer tracks for individual processing. Always export sliced breaks for reuse.

**Quick Drum Win:** Amen Break @ 138 BPM → Slice 1/16 → Boom bap pattern + 65% swing → Instant classic sound.
