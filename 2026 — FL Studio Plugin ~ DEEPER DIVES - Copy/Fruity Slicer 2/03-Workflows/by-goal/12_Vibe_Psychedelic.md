# Vibe: Psychedelic

## Fruity Slicer 2 Psychedelic Flip

### Vibe Definition
**Psychedelic = Warped + Chaotic + Modulated + Trippy**

---

## Settings for Psychedelic

**Core Settings:**
- **Chromatic Mode:** ON for one slice, automate slice selection
- **Pitch:** Automate -12 to +12 wildly
- **Time-Stretch:** Mix modes (glitchy artifacts)
- **Slice Mode:** Manual (random slice points)
- **Envelope:** Automate filter/pitch envelopes per slice

---

## Step-by-Step

1. **Load any sample** (even mundane sources work)
2. **Manual slice at odd points** (mid-phrase, off-transient)
3. **Enable Chromatic** on slice 3, disable on slice 5, etc.
4. **Automate global pitch** wildly (-12 → +7 → -5)
5. **Rearrange slice order** randomly in slice list
6. **Add reverse slices** (right-click → Reverse)
7. **Automate filter envelopes** differently per slice
8. **Create chaos pattern:** Random note timing, off-grid

---

## Chop Pattern

```
<-C5  D5->  <-F5  G5->  B5(+12)  C4(-12)
```

- Reverse/forward alternating
- Pitch automation on each note
- No grid lock
