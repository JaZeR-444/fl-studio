# Goal: Vibe - Upbeat

## Goal Statement
Construct a "Laser-Pluck" synth that specializes in high-energy, fast-attack transients.

## Step-by-Step Setup
1. **Source:** Use a "Super-Saw" module (or layer 3 Saw primitives).
2. **Transients:** Use a "DSP Code" node to create an exponential decay envelope. This is faster than standard linear envelopes.
3. **Snap:** Create a second envelope that modulates the **Fine Pitch** of the saws by +1 octave over just 10ms.
4. **Filter:** Add a high-resonance LP filter that opens and closes instantly with the volume.
5. **Result:** An incredibly punchy lead that "clicks" and "pops" in a musical, high-energy way.

## What to Listen For
- The "knock" at the start of every note.
- A very clean, digital high-end that doesn't have analog "mush."
