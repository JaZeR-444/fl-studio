# SimSynth Live Parameter Cheat Sheet

| Section | Parameter | Sweet Spot | Vibe Insight |
| :--- | :--- | :--- | :--- |
| **Osc** | Warm Button | ON | Effectively doubles the synth's "size." |
| | Osc 2 Detune | 5 - 12 cents | Creates the "Analog Drift" feel. |
| | Ring Mod | 20% - 40% | For metallic R&B bells. |
| **SVF** | LP Mix | 100% | Standard warm analog tone. |
| | BP Mix | 20% - 50% | Nasal "wah" or "talkative" leads. |
| | HP Mix | 30% | Adds "air" to pads without cutting bass. |
| | Resonance | 10% - 30% | Adds a "hollow" whistle without grit. |
| **Env** | Filter Env | 40% - 70% | Essential for snappy 80s brass. |
| | Attack | 0ms - 50ms | Controls "Pluck" vs "Swell." |
| **Master** | Chorus | 30% - 60% | Massive width for "Vibey" pads. |
| | Polyphony | 8 - 12 | Safe range for chord progressions. |
