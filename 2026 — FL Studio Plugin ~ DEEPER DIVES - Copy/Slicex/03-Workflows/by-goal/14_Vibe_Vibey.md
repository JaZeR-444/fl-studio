# Goal: Vibe - Vibey

## Goal Statement
Create a lush, wide vocal or melodic chop that sits perfectly in a smooth R&B production.

## Step-by-Step Setup
1. **Sample:** Choose a female vocal run or a lush Rhodes chord.
2. **Layering:** Use **Deck B** to layer a subtle Sine wave sub underneath the sample.
3. **Articulation:** Set a long **Release** (500ms) on the Volume Envelope.
4. **Stereo:** In Articulator 1, set the **Pan** to follow a slow LFO.
5. **Reverb:** Use a "Large Hall" reverb with 20% Mix.

## Mini-Recipe: "The Cloud Chop"
- High-Pass Filter at 400Hz.
- Reverse the tail of the sample.
- Articulator Attack at 50ms (for a "swell" effect).
- *Result:* A sound that feels like a cloud—soft, wide, and evolving.
