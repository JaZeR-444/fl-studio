# 03: Vibe Translation Guide

## Vibe Targets in Speech Synthesizer

### 1. Moody (Dark, Eerie, Mysterious)
- **The Lever:** **Giant Voice + Whisper Mode.**
- **Setting Moves:**
  - Use the **Whisper** mode for a "secretive" feel.
  - Use the **Giant** voice at low pitch for "demonic" weight.
  - Render with **Natural** style for an unpredictable speaking cadence.
- **What to listen for:** An unsettling, low-fidelity vocal that feels "otherworldly."
- **Pitfall:** Don't use the "Child" or "Robot" voices; they sound too "playful" for a moody vibe.

### 2. Upbeat (High-Energy, Snappy, Pop-Trap)
- **The Lever:** **Fast Rate + Pitch Up.**
- **Setting Moves:**
  - Set **Rate** to 120% (Fast).
  - Pitch up by +12 semitones (1 Octave).
  - Use the **Classic** or **Robot** voice for a "technological" edge.
- **What to listen for:** A "chipmunk-like" or "fast-talking" vocal that adds rhythmic energy.
- **Pitfall:** If the rate is too fast, the words become unintelligible. Test with the "Listen" button.

### 3. Psychedelic (Trippy, Warped, Glitchy)
- **The Lever:** **Random Style + Granular Processing.**
- **Setting Moves:**
  - Select the **Random** style (jumps pitch randomly).
  - Select **Breathy** mode for a "ghostly" texture.
  - Render and load into **Fruity Granulizer** to warp the playback speed.
- **What to listen for:** A vocal that seems to "melt" or "glitch" as it speaks.
- **Pitfall:** Keep phrases short; long psychedelic phrases can become distracting and messy.

### 4. Jazzy (Organic-ish, Warm, Sophisticated)
- **The Lever:** **Whisper Mode + Heavy Processing.**
- **Setting Moves:**
  - Use **Whisper** mode (this removes the harsh synthetic pitch).
  - Route to the mixer and add **Chorus** and **Lush Reverb**.
  - Layer it *very quietly* behind a piano or sax.
- **What to listen for:** A "textural" vocal that sounds like a soft breath or an intimate whisper.
- **Pitfall:** Avoid the "Natural" speaking voice; it is too robotic for a classy jazz feel.

### 5. Vibey (Smooth, Wide, "Ear-Candy")
- **The Lever:** **Singing Syntax + Wide Reverb.**
- **Setting Moves:**
  - Use the **(Note)** syntax to make a short, smooth melody.
  - Use **Monotone** style for stability.
  - Set **Rate** to 40% (Slow and drawn out).
- **What to listen for:** A "vocal-synth" texture that floats in the stereo field.
- **Pitfall:** Don't use "Random" style; keep it melodic and predictable for a smooth vibe.
