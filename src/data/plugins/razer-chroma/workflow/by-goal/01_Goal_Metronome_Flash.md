# Workflow: Silent Metronome

**Goal:** Visual timekeeping without clicking.

1.  **Routing:** Create a new Mixer Track "Metronome".
2.  **Source:** Route the FL Metronome to this track (Preview Mixer Track in Audio Settings), OR create a helper pattern with a rimshot on every beat.
3.  **Plugin:** Add **Razer Chroma**.
4.  **Effect:** **Audio Level**.
5.  **Target:** Toggle OFF Mouse/Headset. Toggle ON Keyboard.
6.  **Result:** Keyboard flashes on beat. Great for recording vocals when you don't want headphone bleed from a click track.
