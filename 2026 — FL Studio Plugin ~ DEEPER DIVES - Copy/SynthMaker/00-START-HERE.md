# SynthMaker (FL Flowstone) - 00 START HERE

## Purpose
FL Flowstone (formerly SynthMaker) is a legacy 32-bit visual DSP environment for building instruments and effects. It is retained for legacy projects and hardware integration experiments.

## 10-Minute Orientation
1. Add Flowstone as an instrument or effect.
2. Use Show Panel to toggle between UI and schematic view.
3. Load .osm or .fsm schematics from the Browser.

## Required Files
- 01-Learning/Quick-Reference/component-library-overview.md
- 01-Learning/Quick-Reference/visual-coding-basics.md
- 02-Data/parameters/synthmaker-specs.json
- 04-Reference/32-bit-bridging-guide.md

## Automation Ideas
- Slow sweeps (16 bars) for evolving textures.
- Medium sweeps (4 bars) for musical motion.
- Fast sweeps (1 bar) for rhythmic effects.

## Mix Integration Checklist
- Confirm mono compatibility for wide settings.
- Control low-end with high-pass or low-bypass tools.
- Use light compression for dynamic stability.
- Avoid extreme modulation in dense mixes.

## Troubleshooting Matrix
- Harsh attack -> soften exciter/attack, reduce brightness.
- Thin body -> increase resonance or body emphasis.
- Too wide -> reduce spread, check mono.
- Too static -> add modulation or automation.
- Muddy low end -> reduce low-mid buildup or use high-pass.
