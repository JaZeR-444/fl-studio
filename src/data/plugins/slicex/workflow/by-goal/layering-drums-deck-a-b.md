# Goal: Layering Drums (Deck A/B)

## Goal Statement
Create a powerful, hybrid drum kit that combines the "feel" of a live drum break with the "punch" of modern electronic drums.

## Step-by-Step Setup
1. **Texture (Deck A):** Load a classic acoustic drum break (e.g., "Amen Break"). Use **Auto-slice (Medium)**.
2. **Power (Deck B):** Load a heavy electronic drum loop or individual hits. Use **Auto-slice**.
3. **Alignment:**
   - Select the Kick region in Deck A.
   - Select the Kick region in Deck B.
   - Ensure both are assigned to the same MIDI note (Region Properties -> Trigger Note).
4. **Mixing:**
   - Use the **Deck Crossfade** slider to find the balance between organic (A) and electronic (B).
   - Set the Kick slice in Deck B to **Out Offset +1**.
5. **Processing:** Apply a compressor to the Deck B mixer track to make it "slap," while leaving Deck A more dynamic.

## What to Listen For
- The "crunch" and "ghost notes" of the acoustic break (A).
- The "solid low-end" of the electronic kick (B).
- Both layers should hit at exactly the same time.

## Variations
- **Snare Swap:** Use the Snare from Deck B only, while keeping the Hats from Deck A.
- **Velocity Layering:** Map velocity to crossfade so that playing harder brings in more of Deck B.
