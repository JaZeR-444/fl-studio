# Goal: 80s Pop Brass

## Goal Statement
Create a bright, punchy brass stab for upbeat, funk-influenced hip-hop or pop tracks.

## Step-by-Step Setup
1. **Oscillators:** Osc 1 & 2 (Saw). Enable **Warm** on both.
2. **Filter:** LP Mix 100%. Cutoff at 800Hz.
3. **Envelope:** Filter Env Amount +60%. Decay 800ms.
4. **Resonance:** 20% to add that "brass" edge.
5. **Detuning:** Detune Osc 2 by 8 cents for that "unstable" 80s feel.

## Starting Settings
- **Filter Env Amount:** 60%
- **Decay:** 800ms
- **Osc Shape:** Saw
- **Warm:** ON

## Variations
- **Variation 1:** Use **Pulse** waves instead of Saws for a more "reedy" brass sound.
- **Variation 2:** Add 5% **Noise** to the mix for a "vintage tape" feel.
