# Genre-Sync Workflows with Razer Chroma

## Overview
This document details how to synchronize Razer Chroma lighting with different musical genres and subgenres, focusing on creating lighting patterns that match the emotional and rhythmic characteristics of hip-hop and R&B music.

## Genre-Specific Synchronization Principles

### Tempo-Based Synchronization
| Genre | Tempo Range | Lighting Response | Application |
|-------|-------------|------------------|-------------|
| Moody Hip-Hop/R&B | 60-80 BPM | Slow, deliberate pulses | Ballads, introspective tracks |
| Upbeat Hip-Hop/R&B | 80-100 BPM | Moderate, energetic pulses | Danceable tracks |
| Fast Hip-Hop/R&B | 100-120+ BPM | Fast, responsive pulses | High-energy tracks |
| Psychedelic | Variable | Evolving, unpredictable | Experimental tracks |

| Frequency Range | Genre Application | Lighting Color | Device Response |
|-----------------|-------------------|----------------|-----------------|

| Mid-Low (200-500Hz) | Hip-Hop kicks, R&B warmth | Warm orange | Center keys |
| Mid (500Hz-2kHz) | Vocals, melodic elements | Gold/yellow | Middle rows |

## Implementation Workflow

### Setup Phase
1. **Analyze Track**: Determine genre and subgenre characteristics
2. **Select Preset**: Choose appropriate lighting preset
3. **Route Tracks**: Connect appropriate mixer tracks to Chroma plugin
4. **Adjust Sensitivity**: Fine-tune response to audio levels
5. **Test Synchronization**: Verify lighting matches musical elements

### Calibration Phase
1. **Color Matching**: Adjust colors to match genre aesthetic
2. **Timing Alignment**: Ensure lighting aligns with musical timing
3. **Intensity Balancing**: Balance between subtle and overwhelming
4. **Device Coordination**: Coordinate lighting across all devices
5. **Performance Testing**: Verify no performance impact

### Optimization Phase
1. **Fine-tune Response**: Adjust to specific track characteristics
2. **Section Adaptation**: Modify for different song sections
3. **Creative Enhancement**: Add personal touches
4. **Template Creation**: Save settings for future use
5. **Documentation**: Record successful configurations

## Troubleshooting Synchronization Issues

### Timing Misalignment
- [ ] Check tempo matching between project and lighting
- [ ] Verify audio routing is correct
- [ ] Adjust buffer settings for lower latency
- [ ] Test with simple click track first

### Color Inconsistency
- [ ] Calibrate all devices in Synapse
- [ ] Check for firmware updates
- [ ] Verify color profile settings
- [ ] Test individual devices separately

### Performance Problems
- [ ] Reduce animation complexity
- [ ] Lower update rate temporarily
- [ ] Limit active devices during rendering
- [ ] Close other RGB software
