# Goal: Vibe - Psychedelic

## Goal Statement
Transform Sytrus into a warping, morphing texture that changes character unpredictably.

## Step-by-Step Setup
1. **Serial FM:** Route **OP 3 -> OP 2 -> OP 1 -> OUT**.
2. **Feedback:** Route **OP 1 -> OP 1** (Feedback) to 5%.
3. **X-Y Mapping:**
   - Link **X** to OP 2 -> OP 1 Amount.
   - Link **Y** to OP 3 -> OP 2 Amount.
4. **LFO:** Route a fast LFO to **Filter 1 Cutoff**.
5. **RM:** Tweak the OP 2 -> OP 1 knob to **Ring Modulation** mode (Blue).

## Automation Idea
- Record a "performance" on the X-Y pad while playing a simple chord. The sound will seem to "melt" through different dimensions.
