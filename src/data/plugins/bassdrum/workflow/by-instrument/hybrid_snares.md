# Designing Hybrid Snares

**Goal:** A snare with a synthesized "thump" and a sampled "sizzle".

## The Recipe
1. **Main Osc:**
   - Peak: 400Hz.
   - Base: 200Hz.
   - Slide: Instant.
   - (This provides the "body" of the snare).
2. **Sample:**
   - Load a "White Noise" or "Snare Crack" sample.
   - Filter: High Pass at 1000Hz.
3. **Click:**
   - Set Level high to provide the initial stick hit.
4. **Result:** A powerful, controllable snare that has the consistent low-end of a synth kick.
