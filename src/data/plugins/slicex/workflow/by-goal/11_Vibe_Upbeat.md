# Goal: Vibe - Upbeat

## Goal Statement
Create a high-energy, "choppy" drum sequence that drives a fast-paced track.

## Step-by-Step Setup
1. **Slicing:** Use **Sharp Auto-slice** to get very precise transient markers.
2. **Choking:** Set all slices to **Cut 1 / Cut By 1**. This creates a "staccato" machine-gun effect.
3. **Pitch:** Pitch the loop up by +200 cents.
4. **Velocity:** In the Piano Roll, vary the velocities to create "accents."
5. **Articulator:** Use **Articulator 1** to add a tiny bit of **Resonance** (20%) to the filter.

## What to Listen For
- A "snappy" and "mechanical" rhythm.
- No "bleeding" between sounds; every hit should stop exactly when the next begins.
