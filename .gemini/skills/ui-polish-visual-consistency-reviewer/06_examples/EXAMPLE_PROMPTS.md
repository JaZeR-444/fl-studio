# Example Prompts

Users will typically trigger this skill using prompts like these:

- "Review my landing page UI. Here is the code and a screenshot."
- "Can you do a visual polish pass on this React Dashboard?"
- "My cards look messy but I don't know why. Help me fix the Tailwind classes."
- "Does this portfolio site look professional? Give me a strict UI/UX review."
- "I built this form but it feels clunky. Check the spacing and accessibility."
- "Review this codebase for Tailwind anti-patterns and styling inconsistencies."
- "Act as a senior front-end reviewer and tell me what to fix on this page."
- "Give me a prioritized action plan to improve the visual design of this component."
