# Goal: Vibe - Moody

## Goal Statement
Create a dark, intimate, and warm lo-fi texture for late-night moody tracks.

## Step-by-Step Setup
1. **Oscillator:** OP 1 set to a Triangle wave (Harmonics tab).
2. **Filter:** Route **OP 1 -> Filter 1**. Select **Mango** mode.
3. **Drive:** Turn up Filter Drive to 40% for warm saturation.
4. **Pitch:** In the **Main** tab, select **Pitch LFO**. Speed 1.5Hz, Depth 1%.
5. **Matrix:** Route **Filter 1 -> OUT** only.
6. **Acoustics:** Add an external bit-crusher (`Fruity Squeeze`) AFTER Sytrus.

## What to Listen For
- A "thick" and "muffled" tone that avoids any digital high-end.
- A subtle "warble" that makes it sound like a vintage tape recording.
