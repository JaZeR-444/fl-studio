# Parameter Dictionary: Sytrus

| Parameter | Location | Vibe Impact | Mix Impact | Description |
| :--- | :--- | :--- | :--- | :--- |
| **Ratio** | OP Tab | **Upbeat** | **Pitch** | Frequency multiplier for FM. |
| **FM Matrix** | Main Grid | **Psychedelic**| **Texture** | Modulation depth between ops. |
| **Unison Order**| Main Tab | **Melodic** | **Width** | Number of detuned voices. |
| **Sub Detune** | Unison Tab | **Vibey** | **Phase** | Spreads unison in the low-end. |
| **Mod X / Y** | Main Bottom | **Psychedelic**| **Control** | Global macro controllers. |
| **Harmonics** | OP -> HAR | **Jazzy** | **Spectral** | Direct control over overtones. |

- **Vibe Impact Tag (FM):** Non-integer ratios (e.g., 1.37) create "Inharmonic" psychedelic bells. Integer ratios (2.0, 4.0) create "Harmonic" upbeat plucks.
- **Mix Impact Tag (Phase):** High unison counts can cause "Phase Smearing," making the sound feel less focused in the center. [SRC: IL-MAN]
