# Goal: Vibe - Moody

## Goal Statement
Create an intimate, dark, and melancholic texture using realistic acoustic SoundFonts.

## Step-by-Step Setup
1. **Instrument:** Load a "Mellow Grand" or "Cello Solo" SoundFont.
2. **Filter:** Enable Filter, set **Cut** to 35%. This makes the sound "recede" into the shadows.
3. **Resampling:** Set to **Standard** (not HQ) for a slightly softer tone.
4. **ADSR:** Increase **Attack** to 50ms to remove the harsh hammer/pluck sound.
5. **External FX:** Add `Fruity Delay 3` with "Sample Rate" turned down for a lo-fi moody grit.

## What to Listen For
- A "warm" and "underwater" sound.
- A feeling of intimacy, like the instrument is being played in a small, dark room.
