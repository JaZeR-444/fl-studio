# Common Mistakes & Fixes

| Mistake | Symptom | The Fix |
| :--- | :--- | :--- |
| **Synapse Closed** | "Plugin says 'Not Connected'." | Razer Synapse MUST be running in the background. Open it. |
| **Wrong Connect Priority** | "Lights are stuck on my Desktop profile." | Open Synapse -> Connect Tab -> Apps. Drag "FL Studio" to the top of the list. |
| **Hardware Disabled** | "Mouse works, Keyboard doesn't." | Check the icons at the top of the Chroma Plugin. Ensure the Keyboard icon is highlighted (On). |
| **Low Volume** | "Lights are barely flickering." | Turn up the **Scale** knob in the Audio Analysis section of the plugin. |
