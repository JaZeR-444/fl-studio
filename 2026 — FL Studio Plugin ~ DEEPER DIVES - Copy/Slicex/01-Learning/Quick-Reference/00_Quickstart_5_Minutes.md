# Quickstart: Slicex (5 Minutes)

1.  **Insert:** Load **Slicex** into the Channel Rack.
2.  **Load:** Drag an audio loop into the **Deck A** window (the main wave display).
3.  **Slice:** Click the **Knife/Auto-slice** icon. Select "Medium auto-slicing."
4.  **Play:** Press notes on your MIDI keyboard. Each note now triggers a different slice.
5.  **Dump:** Click the **Dump to Piano Roll** icon (the small folder/note icon) to put the original groove into the FL Studio sequencer.
6.  **Tweak:** Select a slice in the wave display. Adjust its **Pitch** or **Volume** in the region properties above.
7.  **Tip:** Use the **Deck B** tab to load a second loop and layer it with the first! [SRC: IL-MAN]
