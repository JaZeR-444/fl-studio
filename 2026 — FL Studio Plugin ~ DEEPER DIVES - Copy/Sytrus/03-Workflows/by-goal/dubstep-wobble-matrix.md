# Goal: Dubstep Wobble Matrix

## Goal Statement
Create an aggressive, rhythmic "wobble" bass using Sytrus's advanced modulation matrix and internal filters.

## Step-by-Step Setup
1. **Oscillator:** OP 1 set to Sawtooth (Harmonics editor).
2. **Filter:** Route **OP 1 -> Filter 1**.
3. **Filter Mode:** Select **LP 24dB** (Vanilla).
4. **Modulation:**
   - Go to the **Filter 1** tab.
   - Select **Articulator -> LFO**.
   - Enable the LFO. Draw a "Wobble" shape (e.g., Sine or Triangle).
   - In the **Main** tab, link the **X-Y Controller (X)** to the **LFO Speed**.
5. **Grit:** In the Matrix, route **OP 1 to itself (Feedback)** to 5%.

## What to Listen For
- A rhythmic filter sweep that speeds up or slows down as you move the X-Y controller.
- A "noisy" analog-style grit from the operator feedback.

## Automation Ideas
- **X-Y Pad:** Record your movement of the X-Y pad to create an evolving rhythmic sequence.
- **Filter Drive:** Automate the Filter 1 Drive to increase during the build-up.
