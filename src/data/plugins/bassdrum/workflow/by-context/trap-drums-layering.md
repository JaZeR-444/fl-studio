# Trap Drums Layering

**Context:** Modern Trap/Hip-Hop production.

### The "Spun" 808
You want a kick that punches hard but also has a distinct, long sub tail.

### Setup
1.  **Main Osc:**
    -   Peak: 80Hz.
    -   Base: 35Hz.
    -   Slide: Medium-Slow (gives that "bewww" drop).
2.  **Click:**
    -   Level: 0% (We will use a sample).
3.  **Sample:**
    -   Load a tight, dry "Rack Kick" sample.
    -   **Filter:** High Pass at 150Hz. This removes the sample's mud so it doesn't fight the Main Osc.
4.  **Alignment:**
    -   Play the track. Adjust **Sample Delay** until the punch hits hardest.
5.  **Processing:**
    -   Add **Fruity Soft Clipper** on the mixer track. Push the BassDrum Volume up until it hits the ceiling. This creates the signature "flat-top" distortion.
