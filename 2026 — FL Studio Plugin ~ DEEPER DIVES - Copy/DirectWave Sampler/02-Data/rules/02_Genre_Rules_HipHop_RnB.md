# Genre Rules: Hip-Hop & R&B (DirectWave)

## 1. The "CPU Survival" Rule
- **Rule:** Sample your heavy VSTs.
- **Application:** Use DirectWave's "Program Menu -> Create from VST" feature. This turns a 20% CPU Serum patch into a 1% CPU DirectWave patch. Essential for large "Upbeat" arrangements. [SRC: REPUTABLE]

## 2. Velocity-to-Filter Rule
- **Rule:** High velocity = High brightness.
- **Application:** In the **MOD** matrix, link **Velocity** to **Filter Cutoff**. This ensures that hard-hitting notes in an R&B melody sound "Brighter," just like a real instrument.

## 3. Mono-Sub Bass
- **Rule:** Don't layer stereo sub-samples.
- **Application:** If building a bass kit, ensure the low-velocity layers are Mono samples. Stereo sub-frequencies in DirectWave zones can cause massive phase cancellation.

## 4. Release Tail Discipline
- **Rule:** Long release for "Vibes," Short for "Drums."
- **Application:** For melodic pads, set **Release** to `1000ms+`. For a drum kit mapped in DirectWave, keep Release under `50ms` to keep the beat tight and punchy.

## 5. Root Key Accuracy
- **Rule:** Don't "chipmunk" your samples.
- **Check:** Ensure the **Root Key** matches the actual pitch of the WAV. If you play a C but the sample is an E, your whole melody will be out of tune. [SRC: IL-MAN]
