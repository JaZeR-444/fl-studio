# Synthetic 808 Design

1. **Duration:** Set Global Duration to 100% (Maximum).
2. **Main Osc:**
   - **Peak:** ~60-80Hz.
   - **Base:** ~30-40Hz.
   - **Slide:** Very slow (long sweep).
3. **Slave:** Add a subtle Square or Triangle wave at low level for harmonic saturation.
4. **Processing:** Add a `Fruity Soft Clipper` after the plugin to "square off" the sub for a modern Trap feel.
