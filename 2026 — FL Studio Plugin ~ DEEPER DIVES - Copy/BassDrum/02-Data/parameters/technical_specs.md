# BassDrum Technical Specs

- **Synthesis Type:** Hybrid (Analog Modeled + Sample Playback).
- **Max Polyphony:** 1 (Monophonic).
- **Oscillator Range:** 10Hz to 20,000Hz (Slide Peak).
- **Sample Engine:** 16/24/32-bit WAV support.
- **Internal Processing:** 32-bit floating point.
- **Unique Feature:** Aliased internal sample rate (Sampling Ratio).
