# Goal: Vibe - Jazzy

## Goal Statement
Create a "textural" vocal breath for sophisticated, jazzy R&B.

## Step-by-Step Setup
1. **Mode:** Select **Whispered**.
2. **Text:** Single long vowels (e.g., "Oooooohhhhh").
3. **Render:** Hit OK.
4. **Mixer FX:**
   - **Fruity Filter:** Low-pass at 800Hz (Mellow).
   - **Fruity Reeverb 2:** Large room, 20% Wet.
5. **Layering:** Place these breaths *very* quietly during the silent gaps between piano chords.

## What to Listen For
- An "organic" breathiness that fills the silence.
- A "human" element that doesn't sound robotic or synthetic.
