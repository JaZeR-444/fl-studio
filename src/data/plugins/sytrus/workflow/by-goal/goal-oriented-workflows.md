# Sytrus - Goal-Oriented Workflows for Hip-Hop/R&B

## Overview

This guide details how to use Sytrus to achieve specific production goals in hip-hop and R&B music. Each goal has unique requirements for FM synthesis parameters and techniques.

## Mixing Goals

### Creating Punchy Bass
| Goal | Technique | Parameter Settings | Application |
|------|-----------|-------------------|-------------|
| Punchy Bass | Fast envelopes, harmonic content | Algorithm 15-25, Fast attack (1-5ms), Medium decay (100-200ms) | Hip-Hop, Trap |
| Subtle Punch | Moderate settings | Algorithm 5-10, Medium attack (10-20ms), Medium decay (150-250ms) | R&B, Neo-Soul |
| Aggressive Punch | Complex harmonics | Algorithm 25-35, High modulation, Fast envelopes | Trap, Drill |

#### Application Notes:
- Use fast attack times (1-10ms) for punch
- Apply medium decay (100-300ms) for harmonic evolution
- Higher algorithms (20+) add harmonic complexity
- Consider sidechain compression for mix compatibility

### Achieving Warmth
| Goal | Technique | Parameter Settings | Application |
|------|-----------|-------------------|-------------|
| Vintage Warmth | Simple algorithms, soft waveforms | Algorithm 1-8, Triangle/sine waveforms, Low modulation | R&B, Neo-Soul |
| Analog Feel | Subtle complexity | Algorithm 8-15, Mixed waveforms, Moderate modulation | All genres |
| Harmonic Richness | Controlled complexity | Algorithm 15-25, Careful modulation | Smooth R&B |

#### Application Notes:
- Use algorithms 1-8 for clean, warm sounds
- Triangle and sine waveforms provide warmth
- Low to moderate modulation indices for musicality
- Apply subtle distortion for analog saturation

### Creating Space and Width
| Goal | Technique | Parameter Settings | Application |
|------|-----------|-------------------|-------------|
| Stereo Width | Chorus and pan settings | Algorithm 30-40, Operator panning, Built-in chorus | All genres |
| Spatial Depth | Reverb and delay | Algorithm 20-30, Built-in reverb/delay | R&B, Atmospheric |
| Air and Sparkle | High-frequency content | Algorithm 10-20, Sawtooth harmonics, EQ | Contemporary |

#### Application Notes:
- Use parallel algorithms (30-40) for stereo width
- Apply built-in chorus for analog-style width
- Use reverb/delay for spatial depth
- Sawtooth waveforms add high-frequency content

## Troubleshooting Goal-Oriented Applications

### Common Issues and Solutions
| Goal | Issue | Solution |
|------|-------|----------|
| All | Harshness | Reduce modulation index, try simpler algorithms |
| Punch | Loss of dynamics | Use parallel processing, lower settings |
| Width | Phase issues | Check mono compatibility, adjust panning |
| Warmth | Too cold/digital | Add subtle distortion, use warmer waveforms |
