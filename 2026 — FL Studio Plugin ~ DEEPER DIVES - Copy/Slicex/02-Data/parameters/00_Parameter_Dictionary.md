# Parameter Dictionary: Slicex

| Parameter | Location | Vibe Impact | Mix Impact | Description |
| :--- | :--- | :--- | :--- | :--- |
| **Deck A / B** | Top Tabs | **Upbeat** (Layer)| **Density** | Two independent sample slots. |
| **Markers** | Wave Window| **Jazzy** (Chops) | **Timing** | Defined start/end of slices. |
| **Articulators**| Left Side | **Melodic** | **Tone** | Filter/Vol/Pitch envelopes (1-8).|
| **Cut / Cut By** | Region Prop| **Upbeat** (Gate) | **Dynamics** | Choke groups for muting slices. |
| **Out Offset** | Region Prop| **Moody** (Split)| **Routing** | Sends slice to a new mixer track. |
| **KB Mapping** | Master Pan | **Psychedelic**| **Control** | Maps MIDI notes to parameters. |

- **Vibe Impact Tag (Articulators):** You can assign individual slices to different Articulator numbers, allowing you to filter the snare while keeping the kick clean.
- **Mix Impact Tag (Routing):** The **Out Offset** is essential for professional mixing—send the kick slice to its own mixer track for independent compression. [SRC: IL-MAN]
