# Hip-Hop Sub-Genre Soundgoodizer Workflows

## Moody Dark Trap (Mode A)
| Parameter | Setting |
|-----------|---------|
| Mode | A |
| Knob | 25% |
| Input Gain | 0dB |
| Target | 808 bus or Master |

### Tips
- Mode A adds low-mid warmth
- Perfect for dark aesthetics
- Great for 808-focused tracks
- Check on phone speakers
