# Parameter Dictionary

## Input Section
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Text Box** | Text | The phrase to be synthesized. Supports pitch syntax. | All |
| **Listen** | Action | Previews the speech without rendering to the project. | N/A |

## Voice Personality
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Voice** | Stepped | Classic, Giant, Child, Robot, Old, etc. | All |
| **Pitch** | Continuous | Fundamental frequency of the voice (Root note). | Moody/Upbeat |
| **Rate** | Continuous | Speed of the synthesized speech. | Upbeat/Vibey |

## Style & Texture
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Style** | Stepped | Natural, Monotone/Sing, Random. | Psychedelic/Vibey |
| **Mode** | Stepped | Normal, Breathy, Whispered. | Moody/Psychedelic |

## Output Section
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Output Type** | Stepped | Render as Audio Clip or Fruity Slicer instance. | All |
| **OK** | Action | Renders the audio to the project and closes the dialog. | N/A |
