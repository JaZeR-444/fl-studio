## Troubleshooting

| Issue | Solution |
|-------|----------|
| No low-end on bass | Increase Op2-4 gain, lower filter |
| Harsh leads | Reduce drive, increase cutoff |
| Muddy pads | High-pass at 100Hz, reduce lows |
| No width | Increase detune, add chorus |
| Clicking envelope | Increase attack to 5-10ms |
