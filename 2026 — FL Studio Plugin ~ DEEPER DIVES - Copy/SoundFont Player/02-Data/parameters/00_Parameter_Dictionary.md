# Parameter Dictionary

## Bank / Preset Section
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Load Bank** | Action | Opens a file browser to select a `.sf2` file. | N/A |
| **Preset Name** | Stepped | Selects the active instrument within the bank. | All |
| **Bank/Patch** | Stepped | Standard MIDI numbering for navigation. | N/A |

## ADSR Overrides
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Attack** | Continuous | Overrides the fade-in time of the instrument. | Moody/Vibey |
| **Decay** | Continuous | Overrides the time to reach the sustain level. | Upbeat |
| **Sustain** | Continuous | Overrides the volume held while the key is pressed. | All |
| **Release** | Continuous | Overrides the fade-out time after key release. | Vibey/Moody |
| **Override Switch**| Toggle | Small light enabling the ADSR sliders. | All |

## LFO & Filter
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **LFO Freq** | Continuous | Speed of the pitch vibrato. | Psychedelic/Jazzy |
| **LFO Amp** | Continuous | Depth of the pitch vibrato. | Psychedelic/Jazzy |
| **Filter Cut** | Continuous | Global filter cutoff frequency. | Moody/Lo-Fi |
| **Filter Mod** | Continuous | Filter envelope modulation depth. | Upbeat |

## Global & Resampling
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Resampling** | Stepped | Crunchy, Standard, HQ, Extreme HQ. | Moody (Crunchy) |
| **Reverb** | Toggle | Enables internal legacy reverb. | Moody |
| **Chorus** | Toggle | Enables internal legacy chorus. | Vibey |
| **Pitch** | Continuous | Global pitch shift (+/- 2 octaves). | All |
