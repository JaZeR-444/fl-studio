# R&B Visual Sync Workflows for Razer Chroma

## Overview

This guide details how to configure Razer Chroma lighting patterns specifically for R&B production. The visual elements should complement the smooth, soulful, and emotionally expressive nature of R&B music, enhancing the creative process and performance experience.

## Technical Implementation

### Audio Routing for R&B Lighting
| Track | Audio Source | Effect | Color |
|-------|--------------|--------|-------|
| Lead Vocals | Vocal bus | Smooth Flow | Warm Purple |
| Background Vocals | Harmony bus | Gentle Pulse | Soft Blue |
| Piano/Rhodes | Keys channel | Gentle Wave | Golden Amber |
| Bass | Bass bus | Smooth Pulse | Deep Blue |
| Strings | String section | Flowing Motion | Soft Lavender |

### Sensitivity Settings
- **Vocals**: Medium sensitivity (60-70%) for expressive response
- **Keys**: Low-medium sensitivity (40-50%) for smooth response
- **Bass**: Low sensitivity (30-40%) for gentle response
- **Strings**: Low sensitivity (25-35%) for subtle response
- **Harmonies**: Medium-low sensitivity (35-45%) for gentle response

### Device-Specific Configurations

#### Keyboard Lighting
- **Function Keys**: VU meter for vocal levels
- **Letter Keys**: Main melody/lyrical expression
- **Number Keys**: Harmony section indicators
- **Space Bar**: Breath/transition indicator

#### Mouse Lighting
- **Scroll Wheel**: Vocal intensity indicator
- **Main Buttons**: Recording/playback status
- **Logo Light**: Overall mood lighting

#### Headset Lighting
- **Ear Cups**: Left/right vocal channel indication
- **Headband**: Overall mood lighting
- **Microphone**: Recording indicator

## Troubleshooting Common Issues

### Synchronization Problems
- **Audio Delay**: Adjust buffer settings in Synapse
- **Pattern Mismatch**: Verify audio routing to Chroma plugin
- **Color Drift**: Recalibrate colors across devices
- **Intensity Issues**: Adjust sensitivity settings

### Performance Issues
- **Lag**: Reduce update rate or active devices
- **Overload**: Simplify lighting patterns
- **Inconsistent**: Check device connections
- **Dimming**: Verify power supply to devices
