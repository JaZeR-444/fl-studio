# BeepMap Audio Quality Rules

## Rule 1: Anti-Aliasing
BeepMap generates pure sine waves. In "Linear" mode, high-frequency pixels can easily exceed the Nyquist frequency if the FREQ knob is too high.
- **Rule:** If you hear "fold-back" or weird low-frequency ringing that shouldn't be there, turn down the **FREQ** knob.

## Rule 2: Stereo Balance
- Pure Red = Left. Pure Green = Right.
- **Rule:** If your sound is leaning too far to one side, check your source image for "tinting". Convert the image to Grayscale first if you want a perfect center-panned sound.

## Rule 3: Grainy Mode
- This mode is excellent for Lo-Fi but destroys harmonic clarity.
- **Rule:** Use "Grainy" for SFX and Drones, but leave it OFF if trying to create musical chords or logos.
