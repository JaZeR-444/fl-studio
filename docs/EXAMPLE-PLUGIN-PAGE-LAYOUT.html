Mixing 808s

  • Mono Mode: Always on.
  • Envelope: Box shape (High Sustain).
  • Filter: Open, use distortion macro.

Cinematic Strings

  • Attack: Slow/Swell.
  • Reverb: Hall/Large.
  • Layering: Octaves (+12st).

CPU Optimization

  • Polyphony: Reduce max voices.
  • Reverb: Disable if unused.
  • Unison: High CPU cost, use carefully.

Preset Surfing Workflow

  1. Lock Master Filter & Arp/Limiter.
  2. Select Tag (e.g., "Bass").
  3. Use Arrow Keys to browse rapidly.
  4. Star/Favorite sounds immediately.
  5. Don't tweak yet—find the vibe first.

Extracting MIDI from Loops

Did you know? Some loop presets have built-in scores.

How to Extract:
  • Right-click Piano Roll.
  • Select "Dump Score to Piano Roll".
  • Choose time alignment.

Fast Fixes

  • Too Bright: Low Pass + Res down.
  • Too Muddy: High Pass + Unison down.
  • Too Dry: Unlock Reverb + Wet up.
