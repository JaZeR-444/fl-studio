## Initial Setup and Quick Wins

Welcome to the DirectWave Sampler research project! This guide will help you get started with documenting this advanced FL Studio sampling engine. Follow these steps to begin your research:

### Step 1: Basic Familiarization (15 minutes)
1. Open FL Studio and insert DirectWave Sampler on a channel
2. Load a simple sample (kick drum, piano note, or vocal snippet)
3. Play the sample across different keys to understand basic playback
4. Explore the interface and identify major sections (sample mapping, modulation, effects)
5. Take screenshots of the main interface panels

### Step 2: Parameter Mapping (30 minutes)
1. Create a temporary text file called "directwave-initial-notes.txt"
2. Document every visible parameter and control in DirectWave
3. Change each parameter and note the effect
4. Group parameters by function (sample mapping, playback, modulation, effects)
5. Save this as your starting point for parameter-cheat-sheet.md

### Step 3: Hip-Hop/R&B Specific Testing (45 minutes)
1. Load a drum sample kit (kick, snare, hi-hats)
2. Map samples across the keyboard using DirectWave's mapping tools
3. Create a simple drum kit with velocity switching
4. Test round-robin techniques for realistic drum sounds
5. Document how DirectWave handles hip-hop-style sampling

### Step 4: Create Your First Documentation File (20 minutes)
1. Create the parameter-cheat-sheet.md file in Quick-Reference/
2. Organize parameters by function
3. Include practical applications for hip-hop production
4. Add screenshots showing different interface sections

### Step 5: Set Up Research Schedule
- **Daily (15 min):** Test one new feature or workflow
- **Weekly (2-3 hours):** Complete one major documentation file
- **Monthly (5+ hours):** Review and expand all previous work

## Troubleshooting Common Issues

- If samples don't load, check file format compatibility
- If mapping seems complex, start with simple single-sample mapping
- If performance is sluggish, reduce polyphony or effects
- If sounds are clicking, adjust loop points and crossfades
