# Speech Synth Parameter Cheat Sheet

| Parameter | Type | Range | Vibe Insight |
| :--- | :--- | :--- | :--- |
| **Voice** | Stepped | Classic - Giant | Changes the "Formant" structure. |
| **Style** | Stepped | Natural - Sing | Controls the pitch "inflection." |
| **Mode** | Stepped | Normal - Whisper | "Whisper" is non-tonal/atmospheric. |
| **Pitch** | Continuous | +/- 2 Octaves | "Giant" + Low Pitch = Demonic. |
| **Rate** | Continuous | 50% - 200% | Controlling "comprehension" speed. |
| **Listen** | Action | N/A | Preview without adding to project. |

## Hidden Syntax:
- **(NoteNameOctave):** e.g., `(C5)Hello`. Sets the word's pitch.
- **Vowel Repeat:** e.g., `Heeeelooo`. Stretches the word's duration.
