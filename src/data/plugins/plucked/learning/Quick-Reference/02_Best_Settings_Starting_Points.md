# Best Settings Starting Points

## 1. Muted Guitar (Trap Melody)
*   **Decay:** 15% (Very Short).
*   **Color:** 80% (Bright).
*   **Gate:** ON.
*   **Widen:** OFF.

## 2. Dream Harp (Intro/Pad)
*   **Decay:** 90% (Long).
*   **Color:** 60%.
*   **Gate:** OFF.
*   **Widen:** ON.

## 3. "Koto" (Ethnic)
*   **Decay:** 40%.
*   **Color:** 100% (Metallic).
*   **Gate:** ON.
*   **Widen:** OFF.
