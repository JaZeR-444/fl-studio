# Workflow: Syncing Lights to Kick

**Goal:** Keyboard flashes Red every time 808 hits.

1.  **Routing:** Select your Kick Mixer Track.
2.  **Plugin:** Add **Razer Chroma** to Slot 8/9/10 (Post-FX).
3.  **Effect:** Set to **Breathing** or **Single Harmonic**.
4.  **Settings:**
    *   **Color:** Red.
    *   **Scale:** Adjust until it only lights up on the peak louder hits.
    *   **Decay:** Set to fast (left) so it turns off quickly before the next hit.
5.  **Result:** Visual metronome synced to the kick.
