# Fruity Scratcher — Goal: Creative Effect

## Workflow Goal
Push Scratcher beyond traditional scratching—experimental FX, glitch techniques, and psychedelic soundscapes.

---

## Workflow 1: Glitch Reverse (Experimental)

### Routing Context
- Scratcher → Reverb 2 → Delay 3 → Phaser → Limiter

### Steps
1. Load drum loop or vocal
2. SPD: Rapid jumps (-1x, -0.5x, 0x, 1x) via step sequencer automation
3. ACC: 80%
4. Heavy FX chain
5. Use limiter (prevents loud spikes)

### What to Listen For
- [ ] Unpredictable, glitchy stutters
- [ ] "Broken tape" aesthetic
- [ ] Controlled chaos

### Vibe: Psychedelic

---

## Workflow 2: Feedback Loop [UNVERIFIED]

### Routing Context
- Scratcher out → Send (reverb/delay) → back to Scratcher in

### Steps
1. Route Scratcher output to Send track
2. Add reverb + delay to Send
3. Route Send output back to Scratcher input
4. Set send level LOW (10-15%)
5. Monitor with limiter

### What to Listen For
- [ ] Self-sustaining texture
- [ ] Evolving feedback
- [ ] No harsh screech

### Warning: Can create loud bursts—use limiter

### Vibe: Psychedelic, Experimental

---

## Workflow 3: Multi-Layer Scratch Stack

### Routing Context
- 3 Scratcher instances (different samples) → Mixer → Master

### Steps
1. Load 3 different samples (vocal, drum, FX)
2. Each Scratcher: Different SPD automation
3. Layer for complex texture
4. Pan left/center/right for width
5. Mix to taste

### Vibe: Psychedelic, Creative

---

## Workflow 4: Pitch Chaos (Wide Automation)

### Routing Context
- Scratcher → Pitcher (±12 semitones) → Reverb → Delay → Limiter

### Steps
1. Load sustained sound (pad, vocal)
2. SPD: 0.5x ↔ 1.8x (random automation)
3. Add Pitcher for additional pitch shifts
4. Heavy reverb/delay
5. Creates disorienting soundscape

### Vibe: Psychedelic
