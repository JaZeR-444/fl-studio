# Goal Workflow: Hip-Hop Kick Creation (The Knock)

*Goal: Designing a punchy, aggressive kick drum that cuts through a dense Trap arrangement.*

## 🎛️ Routing Context
- **Routing**: BassDrum -> Mixer Track -> Fruity Soft Clipper.

## 🚶 Step-by-Step Setup
1. **The Base Tone**:
   - Set **End Freq** to your song's key (e.g. 49Hz for G).
   - Set **Start Freq** to **800Hz**.
   - *Result*: This creates a strong "knock" in the chest range.
2. **The Speed**:
   - Set **Pitch Decay** to **15%**.
   - *Result*: The frequency drops very fast, creating a sharp, percussive hit.
3. **The Sample Edge**:
   - Go to the **SAMPLE** tab. Select a sharp "Crack" sample.
   - Set the HP Filter to 3kHz.
   - *Move*: This ensures the "click" is prominent but doesn't muddy the mids.
4. **The Drive**:
   - Go to the **DRIVE** tab. Select **Hard**.
   - Set Amount to **35%**.
   - *Listen*: The harmonics will brighten up, making the kick audible on phone speakers.
5. **The Envelope**:
   - Set **Amp Decay** to 300ms.
   - *Move*: This keeps the tail short so it doesn't conflict with your 808 notes.

## 🔄 Variations
- **The "Drill" Kick**: Use a longer Amp Decay and add a slight pitch-bend automation to the End Frequency.
- **The "Boom-Bap" Classic**: Disable the Drive tab and use a "Wooden" sample layer.

## ⚠️ Pitfalls & Fixes
- **Problem**: Kick sounds too "laser-like."
- **Fix**: Reduce the **Start Frequency** or speed up the **Pitch Decay**.
