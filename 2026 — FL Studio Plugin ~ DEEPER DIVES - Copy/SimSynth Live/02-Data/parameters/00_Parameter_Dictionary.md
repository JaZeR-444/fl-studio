# Parameter Dictionary

## Oscillator Section (1, 2, & 3)
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Shape** | Stepped | Waveform: Sine, Triangle, Saw, Square, Pulse, Noise. | All |
| **Warm** | Toggle | Doubles the oscillator with a detuned copy. | Vibey/Upbeat |
| **Level** | Continuous | Volume of the individual oscillator. | All |
| **Fine Tune** | Continuous | Micro-pitch adjustment (-100 to +100 cents). | Vibey/Psychedelic |

## SVF Section (Filter)
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **LP Mix** | Continuous | Level of the Low-Pass filter component. | Moody/Jazzy |
| **BP Mix** | Continuous | Level of the Band-Pass filter component. | Psychedelic |
| **HP Mix** | Continuous | Level of the High-Pass filter component. | Vibey |
| **Cutoff** | Continuous | Master filter frequency. | All |
| **Resonance** | Continuous | Feedback intensity at the cutoff point. | Upbeat/Psychedelic |

## Modulation Section
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **LFO Target** | Stepped | Pitch, Filter, or PWM. | All |
| **LFO Speed** | Continuous | Rate of modulation. | Psychedelic |
| **Filter Env** | Continuous | Amount of envelope applied to filter cutoff. | Upbeat |

## Effects Section
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Chorus** | Continuous | Stereo widening and shimmer effect. | Vibey/Jazzy |
| **Ring Mod** | Continuous | Multiplication intensity of Osc 1 and Osc 2. | Psychedelic/Vibey |
