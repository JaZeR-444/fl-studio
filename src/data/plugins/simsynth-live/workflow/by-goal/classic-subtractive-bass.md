# Goal: Classic Subtractive Bass

## Goal Statement
Create a "round," solid analog bass that provides a foundation for Boom Bap or West Coast Hip-Hop.

## Routing Context
1. **SimSynth Live:** Mono Mode, Warm OFF.
2. **Fruity Limiter:** In "Comp" mode to glue the dynamics.
3. **Fruity Parametric EQ 2:** Slight boost at 60Hz.

## Step-by-Step Setup
1. **Oscillators:** Osc 1 (Square), Osc 2 (Sine). Set Osc 2 level to 100% and Osc 1 to 50% for "bite."
2. **Filter:** LP Mix 100%. Cutoff at 200Hz.
3. **Resonance:** Set to 10% to add a little "analog weight."
4. **Envelope:** Amp Attack 0, Decay 1s, Sustain 50%.
5. **Warm Mode:** Keep OFF to ensure the phase is consistent.

## Starting Settings
- **Osc 1:** Square (50% Volume)
- **Osc 2:** Sine (100% Volume)
- **Cutoff:** 200Hz
- **Resonance:** 10%

## Variations
- **Variation 1 (Gritty):** Change Osc 1 to **Saw** and increase the **BP Mix** to 20%.
- **Variation 2 (Sub-Only):** Mute Osc 1 and 2, turn up **Osc 3 (Sine)**.
