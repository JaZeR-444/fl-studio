# SoundFont Player - 00 START HERE

## Purpose
SoundFont Player loads .sf2 banks for fast, lightweight playback. It offers simple overrides for filter, LFO, and resampling quality.

## 10-Minute Orientation
1. Load an .sf2 file and select a preset.
2. Test Resampling modes on transposed notes.
3. Use LFO2 and Filter overrides to shape the tone.
4. Set Program mode to Instrument or Drums if notes behave oddly.

## Listening Tests
- Crunchy vs HQ resampling on high transpositions.
- Filter override on bright vs dark presets.
- LFO2 vibrato with and without predelay.

## Mix Integration Checklist
- Confirm mono compatibility for wide settings.
- Control low-end with high-pass or low-bypass tools.
- Use light compression for dynamic stability.
- Avoid extreme modulation in dense mixes.

## Troubleshooting Matrix
- Harsh attack -> soften exciter/attack, reduce brightness.
- Thin body -> increase resonance or body emphasis.
- Too wide -> reduce spread, check mono.
- Too static -> add modulation or automation.
- Muddy low end -> reduce low-mid buildup or use high-pass.
