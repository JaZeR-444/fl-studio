# Sample Mapping Workflows for DirectWave Sampler

## Overview
This document details comprehensive workflows for mapping samples in DirectWave Sampler, with specific focus on hip-hop, rap, and R&B production techniques. These workflows cover everything from basic sample loading to advanced multi-layered instrument creation.

## Basic Sample Mapping Workflow

### 1. Single Sample Mapping (10 minutes)

#### Objective
Load and map a single sample to a specific key range.

#### Prerequisites
- Sample file ready for import
- DirectWave Sampler inserted on a channel
- Basic understanding of MIDI note values

#### Steps
1. **Load Sample** (2 minutes)
   - Click the sample slot in DirectWave
   - Browse to your sample file
   - Select and load the sample
   - Verify sample loads correctly

2. **Set Key Range** (3 minutes)
   - Set Key Start to desired note (e.g., C3 for kick)
   - Set Key End to same note for single-key triggering
   - Adjust Root Key to match sample pitch if needed
   - Test playback across intended range

3. **Configure Playback** (3 minutes)
   - Set appropriate volume level
   - Adjust tuning if necessary
   - Configure loop settings (usually off for drums)
   - Set envelope parameters for natural decay

4. **Test and Verify** (2 minutes)
   - Play the mapped key to test sample
   - Adjust parameters as needed
   - Verify sample behaves as expected
   - Document settings for future reference

#### Hip-Hop Application
- Use for mapping individual drum sounds (kicks, snares, hats)
- Map vocal ad-libs to convenient keys
- Create simple one-shot sample instruments

### 2. Multi-Sample Drum Kit Mapping (20 minutes)

#### Objective
Create a complete drum kit with multiple samples mapped across the keyboard.

#### Prerequisites
- Complete drum sample kit (kicks, snares, hats, cymbals, etc.)
- Understanding of GM drum map standard
- Basic mapping experience

#### Steps
1. **Organize Sample Kit** (5 minutes)
   - Sort drum samples by type (kick, snare, hat, etc.)
   - Verify sample quality and consistency
   - Group samples logically for mapping
   - Prepare for systematic mapping approach

2. **Map Foundation Sounds** (8 minutes)
   - Map kick drum to C3 (MIDI note 60)
   - Map snare to D3 (MIDI note 62)
   - Map closed hi-hat to F3 (MIDI note 65)
   - Map open hi-hat to G3 (MIDI note 67)
   - Adjust individual sample levels and tuning

3. **Add Additional Sounds** (5 minutes)
   - Map crash cymbal to B3 (MIDI note 71)
   - Map ride cymbal to C4 (MIDI note 72)
   - Map toms to appropriate keys (F#3, G#3, A#3)
   - Map percussion sounds to upper keys
   - Fine-tune all sample parameters

4. **Test and Optimize** (2 minutes)
   - Play through all mapped sounds
   - Adjust levels for balanced kit
   - Verify no unwanted bleed-through
   - Test velocity response across all samples

#### Hip-Hop Application
- Essential for classic drum programming
- Use GM standard for compatibility with patterns
- Map 808 sounds to lower keys for bass programming
- Include vocal chops and ad-libs in kit mapping

## Advanced Mapping Workflows

### 3. Velocity Layering for Dynamic Expression (25 minutes)

#### Objective
Create multiple samples per key range that trigger based on velocity values.

#### Prerequisites
- Multiple samples of the same sound at different velocities
- Understanding of velocity values (1-127)
- Experience with basic mapping

#### Steps
1. **Prepare Velocity Samples** (5 minutes)
   - Organize samples by velocity level (soft, medium, hard hits)
   - Ensure samples are recorded at consistent pitch
   - Name samples clearly for identification
   - Verify sample quality and consistency

2. **Map First Velocity Layer** (6 minutes)
   - Load soft hit sample
   - Set Key Start/End to desired range
   - Set Velocity Start to 1, Velocity End to 64
   - Adjust tuning and level appropriately
   - Set appropriate envelopes for soft hit

3. **Map Second Velocity Layer** (6 minutes)
   - Load medium hit sample
   - Set same Key Start/End as first layer
   - Set Velocity Start to 45, Velocity End to 96
   - Adjust tuning to match first layer
   - Set envelopes for medium hit character

4. **Map Third Velocity Layer** (6 minutes)
   - Load hard hit sample
   - Set same Key Start/End as previous layers
   - Set Velocity Start to 77, Velocity End to 127
   - Adjust tuning to match other layers
   - Set envelopes for hard hit characteristics

5. **Test and Refine** (2 minutes)
   - Play across different velocity levels
   - Verify smooth transitions between layers
   - Adjust velocity ranges if needed
   - Fine-tune levels for consistent output

#### Hip-Hop Application
- Essential for realistic drum programming
- Use for creating expressive 808 patterns
- Apply to vocal samples for dynamic expression
- Create expressive instrumental samples

### 4. Round-Robin Mapping for Realism (30 minutes)

#### Objective
Create multiple samples per key that alternate to prevent repetition and add realism.

#### Prerequisites
- Multiple samples of the same sound (3-6 variations)
- Understanding of sample variation techniques
- Experience with velocity layering

#### Steps
1. **Prepare Round-Robin Samples** (5 minutes)
   - Collect 3-6 slightly different samples of the same sound
   - Ensure samples are at consistent pitch and level
   - Name samples clearly for identification
   - Verify all samples are of high quality

2. **Map First Round-Robin Instance** (6 minutes)
   - Load first sample variation
   - Set Key Start/End to desired range
   - Set Velocity Start/End to cover full range (1-127)
   - Adjust tuning and level appropriately
   - Set appropriate envelopes

3. **Map Additional Instances** (15 minutes)
   - Repeat for each additional sample variation
   - Use identical Key and Velocity ranges
   - Adjust tuning to match other instances
   - Set consistent envelope parameters
   - Ensure all samples have similar levels
   - (Repeat for 2-5 more instances)

4. **Configure Alternation Logic** (2 minutes)
   - Verify DirectWave alternates between samples
   - Test rapid triggering to confirm alternation
   - Adjust if needed for proper alternation
   - Ensure no stuck samples occur

5. **Test and Optimize** (2 minutes)
   - Rapidly trigger the mapped key
   - Verify samples alternate properly
   - Listen for consistency in output
   - Adjust levels if needed for consistency

#### Hip-Hop Application
- Perfect for realistic drum programming
- Use for 808 multiplicity (different 808 hits)
- Apply to vocal ad-libs for variety
- Create realistic instrumental textures

### 5. Multi-Zone Mapping for Complex Instruments (35 minutes)

#### Objective
Create complex instruments with multiple zones covering different key and velocity ranges.

#### Prerequisites
- Comprehensive sample set for instrument
- Understanding of instrument range and articulation
- Experience with velocity layering and round-robin

#### Steps
1. **Analyze Instrument Structure** (5 minutes)
   - Identify different articulations (staccato, legato, etc.)
   - Determine key ranges for different registers
   - Plan velocity layers for expression
   - Organize samples by articulation and register

2. **Map Lower Register** (10 minutes)
   - Load samples for lower register
   - Set appropriate Key Start/End for range
   - Implement velocity layers if needed
   - Apply round-robin if multiple samples exist
   - Set tuning and envelopes for register

3. **Map Middle Register** (10 minutes)
   - Load samples for middle register
   - Set Key Start/End to avoid overlap with lower
   - Implement velocity layers and round-robin
   - Match tuning and character to lower register
   - Adjust envelopes for register characteristics

4. **Map Upper Register** (8 minutes)
   - Load samples for upper register
   - Set Key Start/End to avoid overlap
   - Apply appropriate articulations
   - Match tuning and character to other registers
   - Adjust for register-specific characteristics

5. **Test and Integrate** (2 minutes)
   - Play across full keyboard range
   - Verify smooth transitions between zones
   - Check for consistent character across registers
   - Adjust levels and tuning as needed

#### Hip-Hop Application
- Create realistic piano or keyboard instruments
- Build complex vocal instrument patches
- Construct multi-sampled horn sections
- Design expressive string arrangements

## Troubleshooting Mapping Issues

### Common Problems and Solutions

#### 1. Sample Not Triggering
- **Problem**: Sample doesn't play when key is pressed
- **Solution**: Check key range settings, verify sample path, ensure velocity range matches

#### 2. Clicking or Popping
- **Problem**: Audible artifacts when sample plays
- **Solution**: Adjust loop points, enable crossfades, check sample start/end points

#### 3. Wrong Pitch
- **Problem**: Sample plays at incorrect pitch
- **Solution**: Adjust Root Key setting, verify sample's original pitch

#### 4. Velocity Not Responding
- **Problem**: Sample doesn't respond to velocity changes
- **Solution**: Check velocity range settings, verify velocity curve

#### 5. Polyphony Issues
- **Problem**: Voices cut off unexpectedly
- **Solution**: Adjust voice priority settings, increase polyphony if needed
