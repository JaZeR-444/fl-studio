## TRAP / MODERN HIP-HOP

### Trap Vocal Chops (Upbeat Bounce)
**Use Case:** Pop Smoke, Lil Uzi, Travis Scott vocal flips

```
Threshold: 35-45%
Crossfade: 5-8 ms
Time Stretch: 1.2x
Pitch: +2 to +3 semitones
Pattern Density: 16+ notes per bar (1/16th)
Velocity Range: 85-115 (high, dynamic)
Swing: 0-50% (straight or slight)
Tempo: 140-160 BPM

FX Chain:
- Fruity Compressor: 4:1, attack 5 ms, release 80 ms
- Fruity Soft Clipper: -3 dB threshold (add punch)
- Fruity Delay 3: 1/8 note, 30% feedback, 20% mix
```

**What to Listen For:** Bouncy, crisp, in-your-face energy

### Trap 808 Chops (Sub-Bass Slicing)
**Use Case:** Chopped 808 patterns for rhythmic bass

```
Threshold: 65-75% (conservative, few slices)
Crossfade: 3 ms (very short, preserve transient)
Time Stretch: 1.0x (original tempo)
Pitch: 0 semitones (preserve low-end)
Pattern Density: 4-8 notes per bar (sparse)
Velocity Range: 100-127 (very loud)
Swing: 0% (straight)
Tempo: 140-160 BPM

FX Chain:
- Fruity Soft Clipper: -10 dB threshold (saturation)
- Fruity Parametric EQ 2: HPF at 25 Hz, boost 50 Hz (+3 dB)
- Fruity Compressor: 2:1, attack 30 ms (preserve transient)
```

**CRITICAL:** Mono compatibility check mandatory (club systems)

**What to Listen For:** Punchy transients, solid low-end, no phase issues

## BOOM-BAP / CLASSIC HIP-HOP

### Break Chopping (J Dilla Style)
**Use Case:** Amen, Apache, Funky Drummer rearrangement

```
Threshold: 50-60%
Crossfade: 8-12 ms
Time Stretch: 1.0x (respect original)
Pitch: 0 semitones
Pattern Density: Use "Dump to Piano Roll" (original pattern)
Velocity Range: 65-85 (moderate, natural)
Swing: 58-66% (MANDATORY - J Dilla territory)
Tempo: 85-100 BPM

FX Chain:
- Vintage EQ: HPF 50 Hz, LPF 12 kHz, boost 200 Hz (+2 dB), boost 3 kHz (+1 dB)
- RC-20 Retro Color (or tape saturation): 20-30% drive
- Fruity Compressor: 2:1, attack 30 ms, release 200 ms (glue)
- Optional: Vinyl crackle layer
```

**What to Listen For:** Laid-back swing, warm vintage character, grooves naturally
