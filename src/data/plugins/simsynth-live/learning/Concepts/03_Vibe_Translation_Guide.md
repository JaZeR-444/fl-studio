# 03: Vibe Translation Guide

## Vibe Targets in SimSynth Live

### 1. Moody (Dark, Intimate, Emotional)
- **The Lever:** **LP Filter + Triangle Waves.**
- **Setting Moves:**
  - Use **Triangle** waves for a softer, less "buzzy" foundation.
  - Set **LP Mix** to 100%, Cutoff to 20%.
  - Slow **LFO -> Pitch** (1%) for a "tired" analog drift.
- **What to listen for:** A warm, "felt-like" tone that sits in the background of a mix.
- **Pitfall:** High resonance will make it too "aggressive." Keep Res below 10%.

### 2. Upbeat (Punchy, Bright, 80s Pop)
- **The Lever:** **Saw Waves + Warm Mode + Filter Snap.**
- **Setting Moves:**
  - All 3 Oscillators set to **Saw** with **Warm** ON.
  - **Filter Env Amount** at 70%, short **Decay**.
  - **HP Mix** at 10% to cut extreme mud.
- **What to listen for:** A "brass-like" hit that is bright and energetic.
- **Pitfall:** Don't use the Chorus if you want it to be "punchy"—Chorus can sometimes soften transients.

### 3. Psychedelic (Warped, Moving, Evolving)
- **The Lever:** **Ring Mod + SVF Blending.**
- **Setting Moves:**
  - Blend **LP** and **BP** filters at 50/50.
  - Turn up **Ring Mod** for metallic overtones.
  - Automate the **LFO Speed** from slow to fast.
- **What to listen for:** "Hollow" or "robotic" textures that shift harmonically.
- **Pitfall:** Too much Ring Mod can become unmusical. Use it as a "seasoning."

### 4. Jazzy (Organic, Sophisticated, Clean)
- **The Lever:** **Sine/Square Mix + Soft Attack.**
- **Setting Moves:**
  - Mix **Osc 1 (Sine)** and **Osc 2 (Square)** for a "hollow" organ/Rhodes tone.
  - Set **Attack** to 50ms for a "human" touch.
  - Use the **BP filter** to isolate the "warm" mid-range frequencies.
- **What to listen for:** A sound that feels like a vintage keyboard or a clean electric bass.
- **Pitfall:** Avoid the "Noise" shape for Jazzy vibes; keep it clean.

### 5. Vibey (Lush, Wide, Modern R&B)
- **The Lever:** **Warm Mode + Chorus + Detune.**
- **Setting Moves:**
  - All oscillators in **Warm** mode.
  - **Chorus Mix** at 50%.
  - Detune **Osc 2** by +5 cents and **Osc 3** by -5 cents.
- **What to listen for:** An "expansive" sound that feels like it's surrounding the listener.
- **Pitfall:** Check mono compatibility; extreme detuning + chorus can cause "thinness" in mono.
