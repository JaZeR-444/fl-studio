## Why

To fully populate the research folder structures for 9 FL Studio plugins, moving technical data out of top-level READMEs and into organized, topic-specific files (Learning, Data, Workflows, Reference) as originally intended.

## What Changes

- Create and populate subfolders for each plugin:
  - `01-Learning/` (Cheat sheets, quick refs)
  - `02-Data/` (JSON specs, presets)
  - `03-Workflows/` (Goal/Context/Genre guides)
  - `04-Reference/` (Deep technical theory)
- Generate specific markdown and JSON files defined in each plugin's research plan.
- Revert/Clean top-level `README.md` files to serve as navigation guides rather than content dumps.

## Capabilities

### New Capabilities
- `plugin-data-population`: Creation of structured research content for FL Studio plugins.

### Modified Capabilities
- `plugin-deep-dives`: Refining the documentation structure (moving content from README to subfiles).

## Impact

- File system structure for 9 plugin directories.
- Content organization.
