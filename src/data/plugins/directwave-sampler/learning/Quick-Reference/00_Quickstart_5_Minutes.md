# Quickstart: DirectWave Sampler (5 Minutes)

1.  **Insert:** Load **DirectWave** into the Channel Rack.
2.  **Import:** Drag and drop a WAV file into the **Zone** window.
3.  **Map:** Drag the edges of the sample box in the zone editor to set its **Key Range** (which notes play it) and **Velocity Range**.
4.  **Edit:** Click the **ZONE** tab to adjust Pitch, Filter, and ADSR for that specific sample.
5.  **Loop:** Click the **LOOP** tab to set a sustain loop if you want the sound to hold indefinitely.
6.  **VST Sampling:** Right-click a plugin in the Browser -> **Create DirectWave instrument**. This is the fastest way to turn a VST into a DirectWave bank.
7.  **Tip:** Use the **MASTER** tab to add global Reverb and Chorus to your multi-sampled kit. [SRC: IL-MAN]
