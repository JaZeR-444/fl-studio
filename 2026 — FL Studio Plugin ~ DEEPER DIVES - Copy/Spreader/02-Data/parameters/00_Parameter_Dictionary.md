# Parameter Dictionary

## Spatial Controls
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Width** | Continuous | Increases the intensity of the stereo expansion (0% to 100%). | All |
| **Separation** | Continuous | Balances the center signal vs the side signal. "Separated" pushes sound outward. | Vibey/Jazzy |

## Low Bypass Section
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Freq** | Continuous | The cutoff frequency below which the signal is unaffected by width. | Moody/Upbeat |
| **Mono** | Toggle | Sums the bypassed low-frequency signal to pure mono. | Upbeat |

## Master Section
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Gain** | Continuous | Adjusts the output level (-/+ 12dB). | N/A |
| **Vectorscope**| Visual | Real-time stereo image feedback. | All |
