# Controls Reference

## Main Knobs
-   **FREQ:** Master frequency range.
-   **Length:** Duration of scan (Time).
-   **Widen:** Stereo width enhancer.
-   **Vol:** Output volume.

## Switches
-   **Loop:** Toggles looping of the bitmap scan.
-   **Linear / Log (Scale):**
    -   *Linear:* Frequencies are spaced by Hz. (100Hz, 200Hz, 300Hz...).
    -   *Log:* Frequencies are spaced by Pitch. (Octaves).
-   **Grainy:** Enables granular readout mode.
-   **Use Blue:** (On some versions) Uses the Blue channel to determine frequency range per pixel, adding complex spectral shifts.

## Image Interaction
-   **Load Image:** Click the folder icon to open `.bmp`, `.jpg`, `.png`.
-   **Paste:** Paste image from Windows Clipboard.
-   **Max Bitmap Height:** Defines resolution. Higher = clearer sound but higher CPU.

## Note Input
-   BeepMap responds to MIDI notes.
    -   **Pitch:** Transposes the entire frequency map up/down.
    -   **Velocity:** Controls volume.
