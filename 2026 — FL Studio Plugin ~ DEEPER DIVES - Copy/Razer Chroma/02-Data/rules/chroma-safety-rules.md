# Razer Chroma Safety Best Practices

## Hardware Safety
- Ensure proper USB connections before activating lighting
- Monitor device temperature during extended sessions
- Use official Razer cables and accessories only

## Software Safety
- Keep Synapse software updated
- Backup custom lighting profiles
- Test lighting patterns at low intensity first

## Performance Safety
- Monitor CPU usage when using complex lighting patterns
- Avoid running Chroma with CPU-intensive plugins simultaneously
- Set reasonable refresh rates for lighting animations

## Eye Safety
- Use appropriate brightness levels for your environment
- Take regular breaks from RGB lighting exposure
- Avoid strobe effects if sensitive to light

## Troubleshooting Safety
- Disconnect devices before troubleshooting
- Restart FL Studio after major configuration changes
- Contact Razer support for hardware issues
