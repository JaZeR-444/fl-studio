# Spacing, Layout & Rhythm Rubric

Use this rubric to evaluate the use of whitespace and layout grids.

## 1. Vertical Rhythm (Section Spacing)
- **Section Gaps:** Is there clear, consistent breathing room between major page sections? (e.g., `py-16` or `py-24`).
- **Related Grouping:** Are related elements closer together than unrelated ones? (Law of Proximity).

## 2. Horizontal Rhythm (Grids & Layouts)
- **Grid Consistency:** Do column gaps match the design system? (e.g., `gap-6` or `gap-8`).
- **Max Width:** Is the main layout constrained to a sensible max width? (e.g., `max-w-7xl mx-auto`).

## 3. Internal Padding
- **Breathing Room:** Do cards and containers have adequate internal padding? (e.g., `p-6` or `p-8`).
- **Optical Balance:** Is the padding balanced? If not equal, does it follow a pattern (e.g., slightly more vertical padding than horizontal)?

## 4. Empty Space
- **Intentionality:** Is whitespace used intentionally to guide the eye, or does it feel like a "hole" where content is missing?
- **Cramping:** Are elements touching the edges of the screen on mobile devices without adequate horizontal padding? (Recommend `px-4` or `px-6` globally).
