# Goal: Vibe - Vibey

## Goal Statement
Create a lush, wide R&B "cloud" pad that feels expensive and expansive.

## Step-by-Step Setup
1. **Oscillator:** All 3 Oscillators set to **Saw**. Enable **Warm** on all.
2. **Detuning:** Osc 1 (+3c), Osc 2 (-3c), Osc 3 (+7c).
3. **Filter:** LP Mix 70%, HP Mix 30%. Cutoff 800Hz.
4. **Chorus:** Mix 50%.
5. **Envelopes:** Attack 1s, Release 2s.

## Mini-Recipe: "Silk Texture"
- Osc 1 only (Sine, Warm).
- Chorus 40%.
- LP filter at 200Hz.
- *Result:* A smooth, wide "hum" that fills the stereo field without taking up any frequency room.
