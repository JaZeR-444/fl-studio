# Common Workflows: BassDrum

## 1. The "Perfect 808"

Synthesizing a clean, tunable 808 sub.

1.  **Main Base:** Set to your Key (e.g., C2).
2.  **Main Peak:** Set only *slightly* higher than Base (e.g., +5 semitones).
    *   *Why:* 808s don't have aggressive pitch slides; they are smooth.
3.  **Slave:** Turn volume to 0 (Keep it pure).
4.  **Duration:** Max.
5.  **Drive:** 10-20% for saturation.
6.  **Sub-Bass:** Boost +3dB.

## 2. The "Layered Stomp" (EDM Big Room)

1.  **Main:** Short, punchy slide.
2.  **Sample:** Load a "Clap" or "Snare" sample.
3.  **Sample Filter (FLT):** Low Pass (Cut the highs of the clap).
4.  **Layering:** The filtered clap adds "Body" and "Width" to the mono kick.
5.  **Delay:** Adjust Sample Delay to -5% (Pre-shift) to line up the transient peaks.

## 3. Industrial / Glitch Kicks

Using the 'Sampling Ratio' for destruction.

1.  **Setup:** Create a standard kick.
2.  **Action:** Automate the **Sampling Ratio** knob.
3.  **Envelope:** Create a fast decay curve on automation.
4.  **Result:** The tail of the kick "disintegrates" into digital noise, while the attack stays relatively clean.

## 4. Phase Cancellation Sculpting

1.  **Concept:** Use the Slave oscillator as an EQ.
2.  **Setup:** Main and Slave at equal volume.
3.  **Slave Pitch:** Set to +0 (Unison).
4.  **Phase:** Sweep the Phase knob.
5.  **Physics:** When Phase is at 180 degrees (approx), the fundamental cancels out. When at 90 degrees, upper harmonics might cancel.
6.  **Usage:** Use this to remove "mud" (200Hz-300Hz) without using an EQ plugin.
