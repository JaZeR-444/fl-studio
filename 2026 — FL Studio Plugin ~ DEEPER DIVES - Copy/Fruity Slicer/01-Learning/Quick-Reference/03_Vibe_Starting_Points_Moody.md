# Fruity Slicer: Vibe Starting Points - Moody

## Moody Vibe: Slow, Smooth Chops

**Moody = Dark, introspective, emotionally heavy. Slow vocal chops, smooth loop rearrangement.**

[SRC: REPUTABLE]

---

## 30-Second Moody Setup

### Sample Selection
- **Use:** Vocal phrases, ambient loops, pad textures
- **Avoid:** Fast drum breaks (too energetic)

### Slice Settings
- **Threshold:** 60-70% (fewer, longer slices)
- **Crossfade:** 20-30 ms (very smooth transitions)
- **Time Stretch:** 0.8x to 1.0x (slower playback)
- **Pitch:** -2 to -5 semitones (darker tone)

### MIDI Pattern
- **Tempo:** 60-90 BPM
- **Note Length:** Long (1/2 to whole notes)
- **Velocity:** 60-80 (gentle triggering)
- **Rhythm:** Sparse, spacious (lots of rests)

---

## What to Listen For

- [ ] Chops feel "pulled back," not aggressive
- [ ] Smooth transitions (no clicks)
- [ ] Dark, introspective tone
- [ ] Wide dynamic range (quiet parts stay quiet)
- [ ] Reverb-friendly (chops blend with reverb)

---

## Moody DON'Ts

❌ **Don't use fast drum breaks** (too energetic)  
❌ **Don't set Crossfade below 15 ms** (will sound clicky)  
❌ **Don't use aggressive MIDI velocities** (keep gentle)  
❌ **Don't create dense patterns** (moody needs space)

## Example Moody Workflow

**Drake-Style Vocal Chop:**
1. Load isolated vocal phrase
2. Auto-slice (Threshold 70%)
3. Pitch down -4 semitones
4. Draw sparse MIDI pattern (whole notes)
5. Add reverb (3-4 second tail)
6. Add gentle delay (1/4 note dotted)

**Result:** Emotional, atmospheric vocal texture
