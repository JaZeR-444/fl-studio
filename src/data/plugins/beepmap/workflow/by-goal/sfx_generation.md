# BeepMap Goal-Oriented Workflows

## Goal: Create a "Dream Sequence" Texture
- **Image:** Load a photo of a blurred face or a cloudy sky.
- **Settings:**
  - Length: Very slow.
  - Widen: Max.
  - Grainy: On.
- **Workflow:** Add a `Fruity Delay 3` with high feedback. The "Grainy" mode will create a shimmering, ethereal bed that sounds like a fading memory.

## Goal: Create a "Malfunctioning Robot" SFX
- **Image:** Load a QR code or a screenshot of computer code.
- **Settings:**
  - Scale: Linear (Hz).
  - Length: Fast.
  - Loop: On.
- **Workflow:** Automate the "Length" knob. As it speeds up and slows down, the "robot" sounds like it's processing data at different rates.
