# Genre Rules: Hip-Hop & R&B

## The "Warm" Low-End Rule
- **Rule:** For the main 808 or sub-bass, **Turn "Warm" mode OFF**. "Warm" creates two oscillators with shifting phases, which causes the sub-bass volume to "waver" or "fade." Keep your sub-bass mono and solid.
- **Rule:** Use **Warm** mode for mid-bass and leads to add the necessary analog thickness.

## Filter Blending for Hip-Hop
- **Rule:** To make a bass cut through on phone speakers, mix in 10-20% **Bandpass (BP)** with your Lowpass. This emphasizes the mid-range "punch."
- **Rule:** For "under-the-vocal" pads, use 10-20% **Highpass (HP)** to clear out the mud without losing the "body" of the sound.

## Transient Control
- **Rule:** SimSynth has very fast envelopes. If your pluck "clicks" too hard for a smooth R&B vibe, increase the **Attack** to 10-20ms.
- **Rule:** For aggressive trap leads, set **Attack** to 0 and use the **Filter Env** to create a sharp "pluck" at the start of every note.

## Stereo Strategy
- **Rule:** SimSynth's built-in **Chorus** is very wide. If using it on a main melody, check your mono compatibility frequently. If it sounds "thin" in mono, reduce the Chorus mix to 25%.
- **Rule:** For "Vibey" background textures, go full 100% Chorus—the phasing in mono won't matter as much for background layers.

## Avoiding "Mud"
- **Rule:** Because you have 3 oscillators, it’s easy to create a messy sound. Keep **Osc 1** as your main tone, and use **Osc 2 and 3** at lower levels (40-60%) for harmonic support.
- **Rule:** If the sound is too "noisy," check if the **Noise** shape is enabled on any oscillator.
