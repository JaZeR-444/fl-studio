# Fruity Scratcher — by-instrument: Drums

## Drum Scratching in Hip-Hop/R&B

Scratching drum samples creates percussive, rhythmic effects. This guide covers kick, snare, hi-hat, and full loop scratching techniques.

---

## Mini-Recipe 1: Kick Drum Scratch (Boom-Bap Accent)

### Parameters
- SPD: 1x  
- ACC: 85%  
- SEN: 65%  
- Sample: Dry kick hit (0.2-0.5 sec)

### Steps
1. Load punchy kick sample
2. Scratch on off-beats (between main kick hits)
3. Use baby scratch technique
4. 1-2 scratches per 8 bars (sparse)

### What to Listen For
- [ ] Adds syncopation without cluttering
- [ ] Clean transient (no click artifacts)
- [ ] Fits with existing drum pattern

### Vibe Mapping
- **Upbeat:** Rapid kick scratches, SPD = 1.2x
- **Moody:** Sparse, darker kick samples

## Mini-Recipe 2: Snare Scratch (Trap Accent)

### Parameters
- SPD: 1x  
- ACC: 90%  
- SEN: 70%  
- Sample: Snare or clap (0.3-0.6 sec)

### Steps
1. Load snare/clap sample
2. Scratch in triplet patterns (between hi-hat rolls)
3. Use transformer scratch (Hold button for cuts)
4. Record performance

### What to Listen For
- [ ] Tight, percussive cuts
- [ ] Complements trap drums
- [ ] Doesn't clash with main snare

### Automation Ideas
- Automate SPD to 1.3x for final scratch (pitch rise)

## Mini-Recipe 3: Hi-Hat Scratch (Syncopated Texture)

### Parameters
- SPD: 1x  
- ACC: 90%  
- SEN: 75%  
- Sample: Closed hi-hat (0.1-0.3 sec)

### Steps
1. Load short hi-hat sample
2. Scratch rapidly in off-beat positions
3. Use scribble scratch technique
4. Layer with existing hi-hats

### Vibe Mapping
- **Upbeat:** Rapid hi-hat scratches
- **Jazzy:** Swung timing, not straight 16ths

---

## Mini-Recipe 4: Full Drum Loop Scratch (Tape Stop)

### Parameters
- SPD: 1x → 0x (automate)  
- ACC: 30% (gradual) or 90% (quick)  
- Sample: Drum loop (2-8 bars)

### Steps
1. Load full drum break
2. Automate SPD from 1x to 0x
3. ACC = 30% for gradual stop, 90% for quick
4. Use before drop or section change

### Vibe Mapping
- **Moody:** Gradual stop (ACC = 25-35%)
- **Upbeat:** Quick stop (ACC = 85-95%)
