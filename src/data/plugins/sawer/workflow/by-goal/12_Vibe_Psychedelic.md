# Goal: Vibe - Psychedelic

## Goal Statement
Create a "morphing" sound that cycles through different textures and stereo positions.

## Step-by-Step Setup
1. **LFO:** Set to "Saw" or "Square" waveform for sharp changes.
2. **Matrix:**
   - LFO -> Filter Cutoff (30%).
   - LFO -> Pan (50%).
   - LFO -> Phaser Speed (10%).
3. **Phaser:** Mix 60%, Feedback 50%.
4. **Acoustics:** Delay Feedback 60%, Ping-Pong ON.
5. **Unison:** 8 Voices, Max Pan.

## Automation Idea
- **LFO Rate:** Speed up the LFO over 2 bars from 1/4 to 1/16 for a "spiraling" effect.
