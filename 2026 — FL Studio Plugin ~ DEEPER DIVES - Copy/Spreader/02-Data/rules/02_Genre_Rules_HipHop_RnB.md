# Genre Rules: Hip-Hop & R&B

## The 808 "Sub-Safe" Rule
- **Rule:** Never use a stereo widener on a main 808 without a low-end bypass.
- **Action:** In Spreader, set the **Low Bypass** to at least **120Hz** and enable the **Mono** switch. This ensures your 808 hits hard in mono club systems while still sounding wide on headphones.

## The Lead Vocal "Halo"
- **Rule:** For professional R&B vocals, don't go over **40% Width**.
- **Action:** Adjust the **Separation** toward "Merged" to keep the vocal's core "weight" in the center. This creates a "halo" of width rather than a "doubled" effect.

## Hi-Hat "Shimmer"
- **Rule:** Avoid widening low-frequency percussion (Kicks/Claps). Widen the high-frequency elements (Hats/Percs).
- **Action:** Set **Low Bypass** to **2kHz**. Now only the "air" of the hats is spread, creating a sophisticated top-end.

## Mono Summing Verification
- **Rule:** Always check your mix in **Mono** after using Spreader.
- **Action:** Use the FL Studio Master Mono switch. If the instrument's tone changes drastically, reduce the **Width** or adjust the **Separation**.

## Ad-Lib Immersion
- **Rule:** Ad-libs should always be wider than the lead vocal.
- **Action:** Use **80-100% Width** on ad-lib tracks. Since they are background elements, you can be more aggressive with the separation.
