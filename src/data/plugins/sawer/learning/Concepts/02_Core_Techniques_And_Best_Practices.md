# 02: Core Techniques and Best Practices

## 1. The "Phase-Aligned" 808
When using Sawer for sub-bass, keep the **Sub Phase** consistent. If it's set to "Free," every note will have a different amount of punch. Set it to a fixed position (try 0% or 180%) for a consistent "thump" in every hit. [SRC: REPUTABLE-03]

## 2. The "Screaming" Sync Lead
Enable **Hard Sync**. Map the **LFO** to the **Oscillator Pitch** in the Matrix. This creates that classic "tearing" sound where the harmonics of the sync shift rhythmically.

## 3. Vintage "Drift" Pad
To get a truly "unstable" analog feel:
1. Enable **Unison** (4 voices).
2. Set **Unison Detune** to 10-15%.
3. In the Matrix, route a slow LFO to **Master Pitch** with a very small amount (1-2%). This simulates pitch drift.

## 4. "Dirty" Filter Plucks
Set the Filter to **LP 24dB**. Crank the **Resonance** to 70%. Use a fast **Filter Envelope** with 0 Attack and short Decay. The result is a "chirp" that sounds more like a hardware synth than a digital one.

## 5. Noise-Layered Percussion
Turn down the Saw and Sub oscillators. Turn up the **Noise**. Use a very short Amp Decay and Filter Decay. This creates "analog hats" or "snares" that have a unique Soviet texture.

## 6. Matrix "Vel-to-Filter"
In modern R&B, "feeling" is everything. Route **Velocity** to **Filter Cutoff** in the Matrix. Now, playing harder makes the sound brighter, just like a real acoustic instrument.

## 7. The "Warm" Button (Secret Trick)
Check the top bar/menu for "Warm" or "Analog" options (depending on version). Enabling this adds a subtle saturation to the master output that glues the sound together.

## Common Pitfalls + Fixes
- **Pitfall:** Sound is too "buzzy."
  - **Fix:** Lower the Oscillator mix or apply more Filter Damping/LP filter.
- **Pitfall:** Unison is making it muddy.
  - **Fix:** Use the **Unison Pan** to spread voices wider, or reduce voices to 2.
- **Pitfall:** Arpeggiator is out of time.
  - **Fix:** Ensure the "Sync" button in the Arp section is enabled.
