# Non-Kick Percussion in BassDrum

While named "BassDrum", the synthesis engine is capable of other percussion:

## Creating Toms
- Set the **Base** frequency higher (e.g., 80Hz - 150Hz).
- Increase the **Duration**.
- Use a moderate **Slide** time to get that classic "boomy" tom sweep.

## Creating Industrial Snares
- Use a very high **Peak** frequency (e.g., 5000Hz+).
- Set **Base** to around 200Hz.
- Crank the **Click** level.
- Add a "Snare Wire" sample in the Sample slot and high-pass it.

## Creating "Laser" SFX
- Set **Peak** to max.
- Set **Base** to min.
- Set **Slide** to a very slow value.
- This creates the classic 8-bit or Sci-Fi laser beam sound.
