# Vibe Configuration Shortlist - Fruity Spectroman

## Overview

This guide provides **quick-reference display configurations** optimized for achieving and verifying specific vibes in your mixes using Fruity Spectroman.

---

## MOODY Vibe Configuration

### Visual Target Profile

**Spectrum Signature:**
- Dark, bottom-heavy appearance
- Strong red/yellow at 60-200 Hz
- Blue/black above 8 kHz
- Subdued presence zone (2-5 kHz)

### Recommended Settings

**Display Configuration:**
- FFT Size: 4096 (detail in bass and low-mids)
- Decay Time: Medium-Slow (see sustained character)
- Peak Hold: OFF (average energy view)
- Averaging: Medium
- Frequency Range: Full

**Why These Settings:**
- Larger FFT shows warmth/weight detail in low-mids
- Slower decay reveals sustained dark character
- Average energy shows overall moody tilt

### Quick Verification Checklist

✅ **Moody Confirmed When:**
- [ ] Heavy presence at 80-200 Hz (red/yellow)
- [ ] Warm low-mids at 200-400 Hz (yellow/green)
- [ ] Restrained at 2-5 kHz (green, not red)
- [ ] Dark roll-off above 8 kHz (blue/black)
- [ ] Vectorscope shows moderate width (intimate)

### EQ Adjustments to Achieve Moody Visual

**If spectrum looks too bright:**
- Cut 5-10 kHz (-2 to -4 dB)
- High-shelf cut above 10 kHz (-2 to -3 dB)
- Check: Highs should fade to blue/black

**If lacking weight:**
- Boost 80-120 Hz (+2 to +4 dB)
- Boost 200-300 Hz (+1 to +2 dB)
- Check: More red in low-end zone

## UPBEAT Vibe Configuration

### Visual Target Profile

**Spectrum Signature:**
- Extended highs with visible content to 15+ kHz
- Clean low-mids (not muddy)
- Strong presence zone (2-5 kHz forward)
- Bright, open top-end

### Recommended Settings

**Display Configuration:**
- FFT Size: 2048-4096
- Decay Time: Medium (responsive but readable)
- Peak Hold: ON (catch transient energy)
- Averaging: Light
- Frequency Range: Full

**Why These Settings:**
- Medium FFT balances detail and response
- Peak hold shows energetic transients
- Full range emphasizes extended highs

### Quick Verification Checklist

✅ **Upbeat Confirmed When:**
- [ ] Extended highs visible (yellow/green to 12+ kHz)
- [ ] Clean 200-500 Hz (green, not heavy red)
- [ ] Strong 2-5 kHz presence (red/yellow)
- [ ] Air and sparkle above 10 kHz (green/cyan)
- [ ] Wide vectorscope (energetic stereo field)

### EQ Adjustments to Achieve Upbeat Visual

**If spectrum looks too dark:**
- Boost 3-5 kHz (+2 to +3 dB) - presence
- High-shelf boost at 10-12 kHz (+2 dB) - air
- Check: Extended red/yellow in highs

**If low-mids are muddy:**
- Cut 300-400 Hz (-1 to -3 dB)
- Check: Less red in mud zone, cleaner overall

## PSYCHEDELIC Vibe Configuration

### Visual Target Profile

**Spectrum Signature:**
- Dynamic, moving spectrum (not static)
- Rich harmonic content across full range
- Wide stereo field (oval vectorscope)
- Visible modulation effects

### Recommended Settings

**Display Configuration:**
- FFT Size: 2048 (responsive to movement)
- Decay Time: Fast-Medium (see spectrum movement)
- Peak Hold: OFF (see dynamic changes)
- Averaging: OFF (preserve movement)
- Frequency Range: Full

**Why These Settings:**
- Faster decay shows modulation movement
- No averaging preserves spectral dynamics
- Real-time response shows psychedelic effects

### Quick Verification Checklist

✅ **Psychedelic Confirmed When:**
- [ ] Spectrum is MOVING (sweeping, pulsing patterns)
- [ ] Multiple simultaneous frequency peaks
- [ ] Extended high-frequency content (reverb tails)
- [ ] Wide, active vectorscope (circular/oval)
- [ ] Visible modulation (spectrum changes visibly)

### Effects to Add for Psychedelic Visual

**To increase movement:**
- Phaser/Flanger - creates sweeping spectrum
- Filter automation - visible frequency sweeps
- Check: Spectrum actively moves

**To widen stereo field:**
- Stereo enhancement on pads/synths
- Wide reverb
- Check: Vectorscope expands to oval

**To extend harmonics:**
- Saturation/distortion adds overtones
- Check: Additional frequency peaks appear

## JAZZY Vibe Configuration

### Visual Target Profile

**Spectrum Signature:**
- Mid-range focused (200 Hz - 5 kHz dominant)
- Natural roll-off in extremes
- Warm, organic appearance
- Smooth spectral shape (not aggressive)

### Recommended Settings

**Display Configuration:**
- FFT Size: 2048-4096
- Decay Time: Slow (capture natural dynamics)
- Peak Hold: OFF (average organic character)
- Averaging: Medium (smooth, musical view)
- Frequency Range: Full

**Why These Settings:**
- Slow decay + averaging shows natural character
- Medium FFT captures warmth without over-analysis
- Smooth view reflects organic nature

### Quick Verification Checklist

✅ **Jazzy Confirmed When:**
- [ ] Strong mid-range (200 Hz - 5 kHz red/yellow)
- [ ] Natural bass (not artificially boosted sub)
- [ ] Smooth, gradual roll-off (no harsh edges)
- [ ] Warm at 200-800 Hz (body and richness)
- [ ] Moderate vectorscope width (natural stereo)

### EQ Adjustments to Achieve Jazzy Visual

**To enhance warmth:**
- Boost 250-500 Hz (+2 to +3 dB)
- Check: Increased warmth zone presence

**For natural presence:**
- Gentle boost at 2-4 kHz (+1 to +2 dB)
- Check: Smooth rise, not spike

**Natural high-end:**
- Slight roll-off above 12 kHz
- Avoid artificial air boost
- Check: Gradual fade to blue

## VIBEY Vibe Configuration

### Visual Target Profile

**Spectrum Signature:**
- Smooth, lush distribution (no harsh peaks)
- Full mid-range with warmth
- Reverb presence in highs (5-12 kHz)
- Balanced but rich

### Recommended Settings

**Display Configuration:**
- FFT Size: 2048-4096
- Decay Time: Medium-Slow (lush, averaged)
- Peak Hold: OFF (smooth energy view)
- Averaging: Medium-Heavy (lush appearance)
- Frequency Range: Full

**Why These Settings:**
- Averaging creates smooth, lush visual
- Medium-slow decay shows sustained richness
- Full range captures reverb/space

### Quick Verification Checklist

✅ **Vibey Confirmed When:**
- [ ] Smooth spectrum (no sharp peaks anywhere)
- [ ] Lush mid-range (500 Hz - 5 kHz full)
- [ ] Reverb visible (extended 5-15 kHz content)
- [ ] Warm but controlled (not muddy)
- [ ] Moderate-wide vectorscope (immersive)

### EQ Adjustments to Achieve Vibey Visual

**To add richness:**
- Boost 200-400 Hz (+2 dB) - warmth
- Boost 1-2 kHz (+1 to +2 dB) - fullness
- Check: Fuller, richer visual profile

**For smooth clarity:**
- Gentle boost at 3-4 kHz (+1 dB)
- Wide Q (smooth curve)
- Check: No sharp peak, smooth rise

**To add space:**
- Reverb/delay extends into 5-15 kHz
- Check: Visible reverb tail in high frequencies

## Quick Vibe Switch Guide

### From Moody to Upbeat
1. Increase high-shelf at 10 kHz
2. Cut 200-400 Hz (reduce warmth)
3. Boost 3-5 kHz (add presence)
4. **Check:** Spectrum extends higher, cleaner low-mids

### From Upbeat to Psychedelic
1. Add modulation effects
2. Widen stereo (not bass)
3. Add reverb/delay
4. **Check:** Spectrum moves dynamically

### From Jazzy to Vibey
1. Add reverb (extends high frequencies)
2. Layer textures
3. Smooth EQ curves (no sharp moves)
4. **Check:** Smoother, more lush visual

## The Bottom Line

**Each vibe has an optimal Spectroman configuration and visual signature.** For moody, use larger FFT and slower decay to see sustained weight and darkness. For upbeat, use peak hold and medium settings to catch energetic transients and extended highs. For psychedelic, use fast decay with no averaging to see movement. For jazzy, use slow decay with averaging for natural, smooth character. For vibey, use medium-heavy averaging for lush, smooth appearance. Match your display configuration to your target vibe for better visual verification.

**Quick Vibe Check:**
- Moody? → Dark highs, heavy bass
- Upbeat? → Extended highs, clean mids  
- Psychedelic? → Moving spectrum, wide field
- Jazzy? → Mid-focused, natural roll-off
- Vibey? → Smooth, lush, spacious
