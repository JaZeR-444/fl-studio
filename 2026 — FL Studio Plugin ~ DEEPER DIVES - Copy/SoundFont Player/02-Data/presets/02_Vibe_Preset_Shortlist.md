# Vibe Preset Shortlist

## 1. Moody (Dark & Nostalgic)
- **Dusty Grand Piano:** Load a Piano SF2, Resampling "Crunchy", Filter Cut 40%.
- **Lonely String Pad:** Cello/Violin patch, Attack 200ms, Release 1s.
- **Distant Choir:** Choir patch, Reverb ON, High-Pass filter (External).
- **Muffled Bass:** Upright Bass SF2, Filter Cut 30%, Resampling "Crunchy".
- **Old Organ:** Hammond SF2, Chorus ON, Vibrato 5Hz/3%.

## 2. Upbeat (Snappy & Bright)
- **Sharp Slap Bass:** Electric Bass SF2, Decay 300ms, Filter Cut 100%.
- **Tension Violins:** String patch, Attack 0ms, Release 50ms, Extreme HQ.
- **Punchy Brass:** Trumpet/Section SF2, Filter Mod 50%, Extreme HQ.
- **Bell Pluck:** Glockenspiel or Chime SF2, Decay 600ms.
- **Nylon Pop:** Acoustic Guitar SF2, Pitch +12 semitones, Bright.

## 3. Psychedelic (Trippy & Moving)
- **Warbling Flute:** Flute patch, LFO Amp 10%, LFO Freq 6Hz.
- **Sea-Sick Piano:** Piano patch, LFO Amp 5%, LFO Freq 2Hz (Slow drift).
- **Reverse Ghost:** Any patch reversed via external Sampler (Resample first).
- **Infinite Sitar:** Sitar patch, Loop mode enabled (External), high Delay.
- **Phase Shift Brass:** Brass patch, detuned by 20 cents, high Chorus.

## 4. Jazzy (Organic & Sophisticated)
- **Real Grand Piano:** SGM-V2.0 Piano, Resampling Extreme HQ, Vibrato OFF.
- **Warm Upright:** Double Bass SF2, Release 200ms, Filter Cut 60%.
- **Jazz Sax:** Saxophone SF2, LFO Amp 2% (Subtle), Velocity sensitivity High.
- **Breezy Flute:** Flute patch, Attack 40ms, Reverb Mix 10%.
- **Clean Rhodes:** Rhodes SF2, Chorus ON (Subtle), sustain pedal active.

## 5. Vibey (Lush & Wide)
- **Silk Strings:** String Section, 8 Voices Unison (via external), Chorus ON.
- **Cloud Pad:** Female Vocal SF2, Attack 500ms, Release 1.5s, Reverb Size 100%.
- **Wide Electric Piano:** Rhodes/E-Piano, Chorus Max, Panned slightly Left.
- **Soft Woodwinds:** Oboe or Clarinet, Filter Cut 50%, Release 400ms.
- **Lush Harp:** Harp patch, high Reverb Mix, Delay feedback 40%.
