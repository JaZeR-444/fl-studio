# Razer Chroma Parameter Dictionary

| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Effect Type** | Menu | Audio Level, Wave, Breathing, Static, Spectrum. | **CRITICAL** (Animation) |
| **Scale** | Knob | Audio input sensitivity multiplier. | **High** (Brightness) |
| **Speed** | Knob | How fast the Wave moves or Breath cycles. | **Medium** (Energy) |
| **Decay** | Knob | How fast the light turns off after a peak. | **Medium** (Snappiness) |
| **Device Icons** | Toggles | KB, Mouse, Mousepad, Headset. | **Logistical** (Targeting) |
