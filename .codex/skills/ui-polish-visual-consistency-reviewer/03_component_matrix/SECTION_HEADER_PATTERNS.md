# Section Header Patterns

## Standard Structure
A professional section header often contains three elements:
1. **Eyebrow:** Small, uppercase, tracked-out text above the title. Establishes context. (e.g., `text-sm font-semibold tracking-wide text-blue-600 uppercase`).
2. **Title:** The main headline. Bold, tight line-height. (e.g., `text-3xl md:text-4xl font-bold tracking-tight text-gray-900`).
3. **Subtitle/Body:** Explanatory text below the title. Constrained width. (e.g., `mt-4 max-w-2xl text-lg text-gray-600`).

## Alignment Options
- **Centered:** Best for marketing sections, hero areas. Ensure the subtitle has `mx-auto` to stay centered.
- **Left-Aligned:** Best for dashboards, content-heavy sections, or sections with a top-right CTA button.

## Spacing
Ensure sufficient spacing below the header before the content begins (e.g., `mb-12` or `mb-16`).
