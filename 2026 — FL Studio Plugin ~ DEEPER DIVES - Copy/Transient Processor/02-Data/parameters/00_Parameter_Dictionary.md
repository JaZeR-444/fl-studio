# Parameter Dictionary

## Detection Controls
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Attack** | Continuous | Boosts or cuts the volume of the initial transient. | Upbeat/Vibey |
| **Release** | Continuous | Boosts or cuts the volume of the sustain/tail. | Moody/Upbeat |
| **Split Freq** | Continuous | Crossover point to protect low-end from processing. | All (Safety) |

## Enhancement Controls
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Drive** | Continuous | Adds soft-clipping saturation to processed transients. | Upbeat |
| **Mix** | Continuous | Dry/Wet balance for parallel processing. | Vibey |
| **Gain** | Continuous | Master output volume adjustment. | N/A |

## Visual Section
| Parameter | Type | Description | Vibe Impact |
| :--- | :--- | :--- | :--- |
| **Histogram** | Visual | Real-time display of transient detection. | All |
