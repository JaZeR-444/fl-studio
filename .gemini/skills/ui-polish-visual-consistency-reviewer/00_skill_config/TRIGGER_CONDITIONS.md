# Trigger Conditions

This skill should automatically activate when the user request matches any of the following intents:

1. **General UI/UX Review:**
   - "Review this page."
   - "Does this UI look good?"
   - "Give me feedback on this design."
   - "How can I improve this layout?"

2. **Visual Consistency & Polish:**
   - "Make this look more professional."
   - "Why does this feel unpolished?"
   - "Check the consistency of my components."
   - "Standardize my spacing and typography."

3. **Front-End Styling & Codebase Review (UI Focus):**
   - "Review my Tailwind classes."
   - "Can you clean up the styling in this React component?"
   - "Help me create shared variants for these buttons."

4. **Component-Specific Review:**
   - "Review this card component."
   - "Does this navigation bar look right?"
   - "Check the forms and inputs on this dashboard."

5. **Responsiveness & Accessibility (as Polish):**
   - "How will this look on mobile?"
   - "Check the contrast and accessibility of this section."
   - "Are my touch targets big enough?"
