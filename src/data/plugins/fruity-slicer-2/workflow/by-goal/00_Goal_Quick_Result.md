# Goal: Quick Result - Fruity Slicer 2

**Time:** 5-10 minutes  
**Skill Level:** Beginner  
**Result:** Sliced, playable drum loop ready for rearrangement

---

## The 5-Minute Workflow

### Step 1: Load Your Sample (30 seconds)
1. Drag audio file into Fruity Slicer 2
2. Sample appears in waveform view

**Best Samples for Quick Results:**
- Drum loops (1-2 bars)
- Classic breaks (Amen, Think, Funky Drummer)
- Percussion loops
- Short vocal phrases

---

### Step 2: Set BPM (30 seconds)
1. Check sample info or tap tempo to find BPM
2. Enter BPM in Slicer "Tempo" field
3. If unsure, use auto-detect

**Common Break BPMs:**
- Amen Break: 138 BPM
- Think Break: 135 BPM
- Funky Drummer: 98 BPM
- Apache: 117 BPM

**Tip:** Wrong BPM = off-beat slices

---

### Step 3: Auto-Slice (1 minute)
1. Click "Auto-Slice" button
2. Choose division:
   - **1/4 notes:** Simple loops (4 slices per bar)
   - **1/8 notes:** Moderate detail (8 slices per bar)
   - **1/16 notes:** Complex breaks (16 slices per bar)
3. Click "OK"

**Recommendation for Beginners:** Start with 1/8 division

**Result:** Slices appear as markers on waveform

---

### Step 4: Test Slices (1 minute)
1. Play C5 on keyboard/MIDI controller (Slice 1)
2. Play C#5 (Slice 2), D5 (Slice 3), etc.
3. Verify each slice sounds clean (no clicks)

**If Clicks Heard:**
- Enable "Snap to zero-crossings"
- Re-run Auto-Slice

---

### Step 5: Create Simple Pattern (2-3 minutes)
1. Open Piano Roll
2. Place notes for each slice:
   - C5 = Slice 1 (usually kick)
   - D5 = Slice 2 (usually snare or next hit)
   - E5 = Slice 3, etc.
3. Create basic 1-bar pattern

**Quick Pattern Example:**
```
Bar 1:
Beat 1: C5 (Kick)
Beat 2: D5 (Snare)
Beat 3: C5 (Kick)
Beat 4: D5 (Snare)
```

---

### Step 6: Export Slices (1 minute)
1. File → Export → Sliced audio to Slicer dump folder
2. Name file descriptively (e.g., "Amen_170BPM_16th")
3. Slices saved for future use

**Why Export?**
- Reusable across projects
- No need to re-slice
- Permanent library

---

## Quick Result Settings

### For Drum Loops
- **BPM:** Match original sample
- **Division:** 1/8 or 1/16
- **Stretch:** Enabled (adjusts to project tempo)
- **Envelope:** Default (fast attack, medium decay)

### For Vocal Chops
- **BPM:** Match original (or disable stretch)
- **Division:** Manual (syllable boundaries)
- **Stretch:** Disabled (preserve pitch)
- **Envelope:** Short attack, medium release

### For Melodic Loops
- **BPM:** Match original
- **Division:** 1/4 or 1/8 (musical phrases)
- **Stretch:** Enabled
- **Envelope:** Default

## 3 Quick Results in 5 Minutes Each

### Result 1: Instant Breakbeat (5 min)
**Goal:** Playable Amen Break

1. Load Amen Break
2. Set BPM to 138
3. Auto-Slice @ 1/16
4. Play slices on keyboard
5. Rearrange in Piano Roll

**Output:** Customized breakbeat pattern

---

### Result 2: Vocal Chop Hook (5 min)
**Goal:** Melodic vocal stabs

1. Load short vocal phrase (1-2 seconds)
2. Manually slice at syllables (3-5 slices)
3. Map to C5-E5
4. Play melodically on keyboard
5. Record MIDI pattern

**Output:** Catchy vocal hook

---

### Result 3: Trap Hi-Hat Roll (5 min)
**Goal:** Rapid hi-hat build

1. Load single hi-hat sample
2. Auto-Slice (creates single slice)
3. Piano Roll: 1/32 note pattern (4 beats)
4. Velocity automation (crescendo: 60 → 100%)
5. Place before drop

**Output:** Professional hi-hat roll

## Troubleshooting Quick Fixes

**Problem:** Slices off-beat  
**Fix:** Check BPM, re-slice

**Problem:** Clicks on slices  
**Fix:** Enable zero-crossing snap

**Problem:** Lost slices after closing project  
**Fix:** Export sliced audio before closing

---

## The Bottom Line

**For instant results: Load sample → Set correct BPM → Auto-Slice @ 1/8 or 1/16 → Test slices → Create simple pattern → Export.** Takes 5-10 minutes. Use classic breaks (Amen, Think) for guaranteed quick wins. Enable zero-crossing snap to avoid clicks. Export sliced audio to save work. Start with 1/8 division for simplicity. Match BPM to sample for accurate slicing. Create basic kick-snare patterns in Piano Roll.

**Fastest Path:** Amen Break @ 138 BPM → Auto-Slice 1/16 → Done in 5 minutes.
