# Goal: Classic FM Electric Piano

## Goal Statement
Recreate the iconic, "glassy" electric piano sound of the 80s and 90s, perfect for smooth R&B or soulful Hip-Hop.

## Routing Context
1. **Sytrus:** Main patch.
2. **Fruity Chorus:** Fat setting for width.
3. **Fruity Delay 3:** 1/4 note timing.

## Step-by-Step Setup
1. **The Body (OP 1):** Set to Sine wave. Frequency Ratio 1.000. Volume Envelope: 50ms Attack, 2s Release.
2. **The Tine (OP 2):** Set to Sine wave. Frequency Ratio 14.000 (Very high). Volume Envelope: 0ms Attack, 150ms Decay (Short "ping").
3. **Matrix:** Route **OP 2 -> OP 1** at 25%.
4. **Saturation:** Route **OP 1 -> Filter 1**. In Filter 1, select **Mango** mode and turn up the **Drive**.
5. **Final Path:** Turn up **Filter 1 -> OUT** in the Matrix.

## Starting Settings
- **OP 1 Ratio:** 1.000
- **OP 2 Ratio:** 14.000
- **FM Amt:** 25%
- **Filter Drive:** 20%

## Variations
- **Variation 1 (Warmer):** Lower the OP 2 Ratio to 2.000 for a "Rhodes" rather than "DX7" feel.
- **Variation 2 (Wider):** Enable 4-voice Unison with 2% detune.
