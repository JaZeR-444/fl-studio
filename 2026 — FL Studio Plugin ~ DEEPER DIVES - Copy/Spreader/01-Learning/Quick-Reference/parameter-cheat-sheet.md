# Spreader Parameter Cheat Sheet

| Parameter | Sweet Spot | Mix Role | Research Insight |
| :--- | :--- | :--- | :--- |
| **Width** | 25% - 45% | Main Vocals | Safe "Halo" width without phasing. |
| | 60% - 100% | Background FX | Immersive "surround" textures. |
| **Separation** | Merged (Left) | Guitars/Pianos | Keeps the instrument's center weight. |
| | Separated (Right) | Ad-libs/Glitch | Pushes sound to the far speaker edges. |
| **Low Bypass** | 120Hz - 180Hz | 808s / Bass | Essential for club-ready mono sub. |
| | 3kHz - 5kHz | Hi-Hats | Widens only the "sparkle" and air. |
| **Mono Switch** | ON | Master Mix | Forces low frequencies to stay centered. |
| **Gain** | +1dB to +2dB | Makeup | Compensation for stereo volume loss. |
