# Genre Style Board: SimSynth Live

## Hip-Hop
- **Technique:** "SEM Bass." Use the LP+BP filter blend. It provides a specific analog "thump" that sits perfectly underneath dusty Boom Bap drums.
- **Reference Idea:** Think of the warm, rounded basslines in early 2000s Neptune or Timbaland productions.

## Rap
- **Technique:** "Warm Saw Lead." Use 3 Saws in Warm mode. It creates a massive, wide lead that fills the speakers in a modern Trap anthem.
- **Reference Idea:** High-pitched, whiny leads similar to Mike Dean's synth work for Travis Scott or Kanye West.

## R&B / Pop-Hip-Hop
- **Technique:** "Vibey Analog Clouds." Use the Warm mode on all oscillators and the built-in Chorus. It creates a lush background for smooth vocal performances.
- **Reference Idea:** The "expensive" sounding synth pads in modern R&B like Summer Walker or Bryson Tiller.

## Key Technique References
- **Analog Detune:** Fine-tune Osc 2/3 by 3-7 cents. [SRC: REPUTABLE-04]
- **SVF Notch:** 50% LP + 50% HP blend. [SRC: IL-MAN-03]
- **PWM Thickness:** LFO -> PWM on Square wave. [SRC: IL-MAN-03]
