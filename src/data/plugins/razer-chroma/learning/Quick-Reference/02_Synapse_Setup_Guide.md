# Synapse Setup Guide

The plugin is useless without the driver configuration.

## 1. Installation
1.  Download **Razer Synapse 3** (or 4 Beta).
2.  During install, ensure **CHROMA CONNECT** module is checked. This is the API bridge.

## 2. Windows Settings
1.  Open Synapse.
2.  Go to **Connect** (Top Tab).
3.  Ensure "Chroma Connect" switch is **ON**.

## 3. Prioritization
1.  With FL Studio open, look at the **Apps** list in the Connect tab.
2.  You should see `FL Studio.exe` or `FL64.exe`.
3.  If it is below other apps (like "Wallpaper Engine"), dragging it to the **Top**.
4.  **Locking:** You can click the "Lock" icon to force FL Studio to keep control even if you Alt-Tab away.
