## UPBEAT (Bouncy, Energetic)

**Definition**: Fast, bright, rhythmic, makes you bounce. Think Lil Uzi Vert, Playboi Carti, modern trap energy.

### Core Levers for Upbeat with Slicer 2
1. **Short envelopes** → fast attack/release = percussive bounce
2. **High slice density** → trigger many slices rapidly
3. **Pitch up +3 to +7** → brighter = more energy
4. **Stutter edits** → retrigger same slice 4-8 times per beat
5. **Chromatic mode OFF** → rhythmic triggering, not melodic
6. **Tight quantization** → locked to grid = tight bounce

### Upbeat Starting Point: Rapid Vocal Stutter

```
SLICE SETTINGS:
- Auto-detect: ON (capture all transients)
- Select: Short vocal syllables ("yeah," "uh," "hey")
- Chromatic mode: OFF
- Pitch: +3 to +5 semitones (brighter)

ENVELOPE:
- Attack: 0ms (instant)
- Release: 50-100ms (short, tight)
- Filter: High-pass 300Hz, boost 2-5kHz
- Pan: Rapid auto-pan or hard L/R alternation

TRIGGERING:
- 1/16 note stutters (4 hits per beat)
- Velocities: 100-127 (loud, energetic)
- Pattern: Trigger on-beat, leave off-beats sparse

OUTPUT:
- Fruity Delay 3: 1/16 dotted, feedback 20%
- Fruity Limiter: Push 2-3dB for punch
- Subtle distortion for grit
```

**What to Listen For**:
✅ Immediate bounce, head-nod trigger
✅ Bright, forward in the mix
✅ Feels like it's rushing forward

❌ **Don't**: Long release (kills bounce), low pitch (too heavy), loose timing

## PSYCHEDELIC (Trippy, Disorienting)

**Definition**: Warped, unpredictable, reality-bending. Think Travis Scott, Asap Rocky's experimental tracks, acid rap.

### Core Levers for Psychedelic with Slicer 2
1. **Extreme time-stretching** → 300-500% stretch = unnatural
2. **Random slice triggering** → break expectations
3. **Heavy modulation** → automate filter, pitch, pan wildly
4. **Reverse + forward mix** → disorient the ear
5. **Chromatic mode abuse** → play atonal/microtonal intervals
6. **Glitch stutters** → retrigger at odd divisions (1/7, 1/13)

### Psychedelic Starting Point: Warped Melodic Chop

```
SLICE SETTINGS:
- Auto-detect: OFF
- Manual slice: 1-2 slices only (create texture from single source)
- Chromatic mode: ON
- Pitch: Automate between -12 and +12 semitones randomly

TIME-STRETCH:
- Elastique Efficient (allow artifacts)
- Stretch: 300-400% (extremely slowed)
- Formant: OFF (let it sound broken)

ENVELOPE:
- Attack: Random per note (0-200ms)
- Release: Long tail (500-1000ms) with reverb
- Filter: Automate cutoff 200Hz-10kHz, high resonance

PERFORMANCE:
- Play notes NOT in scale (Bb over C major, etc.)
- Use pitch bend wheel aggressively
- Trigger at odd timings (not on grid)

OUTPUT:
- Fruity Flangus or Phaser: extreme settings
- Fruity Delay 3: Feedback 60%+, ping-pong
- Fruity Reeverb 2: Shimmer reverb, 100% wet
```

**What to Listen For**:
✅ "What the hell was that?" reaction
✅ Sounds underwater/in a tunnel
✅ Timing feels unstable, drunk

❌ **Don't**: Stay on-grid, use natural pitch, keep it clean

## JAZZY (Swung, Organic)

**Definition**: Loose timing, swing groove, live-feel, musical sophistication. Think A Tribe Called Quest, Anderson .Paak, jazz-rap.

### Core Levers for Jazzy with Slicer 2
1. **Swing quantization** → 54-65% swing on slice triggers
2. **Velocity variation** → humanize velocities 70-110
3. **Chromatic mode ON** → play actual chord progressions (ii-V-I)
4. **Organic sample sources** → upright bass, Rhodes, brass
5. **Slightly loose timing** → shift notes ±10-20ms off-grid
6. **Natural envelopes** → match real instrument ADSR

### Jazzy Starting Point: Swung Rhodes Chop

```
SLICE SETTINGS:
- Auto-detect: OFF
- Manual slice: Single Rhodes chord stab or bass note
- Chromatic mode: ON
- Pitch: Original (transpose in piano roll for chords)

ENVELOPE:
- Attack: 5-10ms (slight softness, like real piano)
- Release: 300-600ms (natural decay)
- Filter: OFF or very subtle low-pass (let sample breathe)
- Pan: Slight stereo width, not hard L/R

PERFORMANCE:
- Play jazz chords: Dm7, G7, Cmaj7, Am7
- Velocity: 75-105 (dynamic, not robotic)
- Timing: Apply 58% swing in piano roll
- Add grace notes, slight pushes/pulls

OUTPUT:
- Fruity Parametric EQ: Boost 200Hz (warmth), gentle 5kHz air
- Fruity Chorus: Subtle width
- Fruity Reeverb 2: Small room or studio, 15-25% wet
```

**What to Listen For**:
✅ Groove feels "pushed" (slightly ahead) or "laid back"
✅ Sounds like a live musician played it
✅ Chord voicings sound musical, not random

❌ **Don't**: Perfect quantization, robotic velocities, no dynamics

## VIBEY (Atmospheric, Textural)

**Definition**: Mood-setting, background layer, emotional texture. Not the main focus, but sets the tone. Think Bryson Tiller, SZA, modern R&B production.

### Core Levers for Vibey with Slicer 2
1. **Long, washy envelopes** → attack + release both extended
2. **Reverb-soaked** → more wet than dry
3. **Subtle, repetitive triggering** → same slice looped, not varied
4. **Mid-range focus** → filter out extreme highs/lows
5. **Movement via modulation** → slow LFO on filter/pan
6. **Low in the mix** → 30-50% volume vs main elements

### Vibey Starting Point: Textured Sample Loop

```
SLICE SETTINGS:
- Auto-detect: ON
- Select: 1-2 textural slices (not percussive)
- Chromatic mode: OFF (or ON for static pad note)
- Pitch: -3 to +0 semitones (neutral to slightly dark)

ENVELOPE:
- Attack: 100-200ms (very gradual fade-in)
- Release: 600-1200ms (long sustain)
- Filter: Band-pass 500Hz-3kHz (sit in mid-range pocket)
- Pan: Slow auto-pan or stereo width

TRIGGERING:
- Loop 2-4 bar pattern
- Trigger same slice(s) every 2 beats
- Minimal variation (vibe = consistency)

OUTPUT:
- Fruity Reeverb 2: Long plate, 60-80% wet
- Fruity Delay 3: 1/4 dotted, low feedback (10-20%)
- Fruity Love Philter: Gentle filter movement via LFO
- MIXER: Pan slightly off-center, volume -6 to -10dB
```

**What to Listen For**:
✅ "Sets the room" feeling—you'd miss it if it disappeared
✅ Blends into the background, not attention-grabbing
✅ Repetitive but hypnotic

❌ **Don't**: Make it loud/bright, vary too much, short/dry sound

## Combining Vibes

**Upbeat + Psychedelic** = High-energy glitch trap (Carti, experimental trap)  
**Jazzy + Vibey** = Chill lo-fi hip-hop (Nujabes, Knxwledge)  
**Moody + Vibey** = Dark R&B atmosphere (6LACK, Brent Faiyaz)  
**Upbeat + Jazzy** = Bouncy boom-bap (Anderson .Paak, Kaytranada)

## Pitfalls Per Vibe

### Upbeat Pitfalls
❌ Too long release → kills bounce  
❌ Low pitch → sounds heavy, not energetic  
❌ Loose timing → loses the "locked" feel

### Psychedelic Pitfalls
❌ Too clean → needs artifacts, distortion, weirdness  
❌ Predictable timing → break the grid  
❌ Normal pitch → automate pitch or use extremes

### Jazzy Pitfalls
❌ Perfect quantization → sounds stiff, not swung  
❌ Same velocity → robotic, not human  
❌ Ignoring chord theory → random notes ≠ jazzy

### Vibey Pitfalls
❌ Too loud → should be background  
❌ Too varied → vibe = repetition  
❌ Too short/dry → needs space, sustain
