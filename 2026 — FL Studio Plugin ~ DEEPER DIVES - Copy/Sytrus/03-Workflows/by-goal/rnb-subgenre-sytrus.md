# R&B Sub-Genre Sytrus Workflows

## Overview
Sytrus's six-operator FM synthesis capabilities make it ideal for creating authentic R&B sounds across various subgenres. This document details how to configure Sytrus for characteristic R&B tones in different subgenres.

## Moody R&B (Dark, Intimate)
| Parameter | Setting | R&B Application |
|-----------|---------|-----------------|
| Operators | 3 Sine + 1 Saw mix | Warm, intimate tones |
| Detune | +/- 2-3 cents | Subtle warmth |
| Cutoff | 2500Hz | Warm, mellow character |
| Resonance | 20% | Gentle emphasis |
| Drive | 10% | Subtle saturation |
| Envelope | 50/600/65/800 | Slow, sustained |
| Reverb Mix | 40% | Intimate space |

### Tips for Moody R&B
- Use sine waves for warmth and intimacy
- Apply slow attack for smooth entry
- Use moderate release for sustained notes
- Perfect for ballad-style R&B

### Operator Configuration
- **Operator 1**: Sine, carrier, full volume
- **Operator 2**: Sine, modulator, 20% modulation
- **Operator 3**: Sine, modulator, 15% modulation
- **Operator 4**: Saw, carrier, 30% volume
- **Operators 5-6**: Off or minimal use

## Integration with R&B Production Chain

### Pre-Sytrus Processing
- [ ] Apply gentle EQ to shape tone
- [ ] Use compression for consistency
- [ ] Set appropriate gain staging

### Post-Sytrus Processing
- [ ] Add reverb for space
- [ ] Apply subtle delay for depth
- [ ] Final EQ adjustments if needed

## Troubleshooting Common Issues

### Harsh High Frequencies
- [ ] Reduce cutoff frequency
- [ ] Lower resonance
- [ ] Use more sine waves
- [ ] Apply high-frequency roll-off after

### Muddy Low-End
- [ ] Increase cutoff frequency
- [ ] Reduce low-frequency operators
- [ ] Apply high-pass filtering
- [ ] Check for frequency buildup

### Loss of Clarity
- [ ] Reduce operator modulation
- [ ] Use fewer operators
- [ ] Apply EQ after Sytrus
- [ ] Lower drive settings

## Expert Tips for R&B Production

### Creative Applications
- Use operator modulation for evolving textures
- Apply different envelopes to different operators
- Create vintage sounds with proper operator ratios
- Experiment with detuning for character

### Performance Optimization
- Use fewer operators for CPU efficiency
- Freeze tracks when possible
- Use Sytrus in multi-timbral mode
- Apply to multiple instruments efficiently

## Success Metrics

Your R&B Sytrus application is successful when:
- [ ] The sound matches the intended subgenre character
- [ ] The tone is appropriate for R&B
- [ ] The sound sits well in the mix
- [ ] The harmonic content is rich but not harsh
- [ ] The processing adds to rather than detracts from the emotion
