# Goal: Patch Customization

## Goal Statement
Take a generic SoundFont instrument and customize it using the internal overrides to fit your specific production.

## Step-by-Step Setup
1. **Envelope Shaping:**
   - For a **Pad:** Set Attack to 25%, Release to 50%.
   - For a **Pluck:** Set Attack to 0%, Decay to 40%, Sustain to 0%.
2. **Filter Movement:**
   - Enable the Filter.
   - Turn the **Mod** slider to +50%. This makes the filter open during the note's attack.
3. **Vibrato (The "Vibe"):**
   - Enable LFO.
   - Set **Freq** to 4Hz and **Amp** to 3%. This adds a gentle, human-like pitch wobble.
4. **Stereo Width:**
   - Enable the internal **Chorus** to widen a solo instrument.
5. **Verification:** Toggle the "Override" switches to compare your custom version with the original SoundFont patch.

## What to Listen For
- How the ADSR changes the "rhythm" of the instrument.
- How the Filter Mod adds "bite" to the attack.
- The humanization added by the slow LFO.
