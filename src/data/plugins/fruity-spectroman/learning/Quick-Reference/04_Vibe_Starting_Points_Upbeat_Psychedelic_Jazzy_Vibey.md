# Vibe Starting Points - UPBEAT / PSYCHEDELIC / JAZZY / VIBEY

## Multi-Vibe Spectrum Guide

This guide covers four distinct vibes and their spectral signatures in Fruity Spectroman.

---

## 1. UPBEAT Spectrum Signature

### Ideal Upbeat Visual Profile

```
20-40 Hz:    Blue/minimal (clean, no rumble)
40-80 Hz:    Yellow (present but controlled bass)
80-200 Hz:   Yellow/green (groove and energy)
200-500 Hz:  Green/cyan (clean low-mids, not muddy)
500-2k Hz:   Yellow/red (forward energy)
2k-5k Hz:    Red/yellow (clarity and excitement)
5k-10k Hz:   Yellow/green (brightness and sparkle)
10k-20k Hz:  Green/cyan (air and extension)
```

**Visual Characteristics:**
- Extended highs (content visible to 15+ kHz)
- Clean low-mids (less 200-500 Hz than moody)
- Strong presence zone (2-5 kHz forward)
- Bright, open top-end

### Upbeat Spectroman Checks

✅ **Upbeat Vibe Confirmed:**
- High-frequency extension (red/yellow reaching 10-12 kHz)
- Clean 200-500 Hz (green, not heavy red)
- Strong 2-5 kHz presence (vocals/leads pop)
- Wide vectorscope (energetic stereo field)

### EQ for Upbeat Spectrum

**Brighten Top-End:**
- +2 to +3 dB at 3-5 kHz (presence)
- +2 dB high-shelf at 10-12 kHz (air)
- Check: Extended red/yellow in highs

**Clean Low-Mids:**
- -1 to -3 dB at 300-400 Hz (reduce mud)
- Check: Less red in low-mid zone

**Control Bass:**
- Tight, punchy bass (not boomy)
- High-pass at 35-40 Hz
- Check: Bass present but not dominating

## 2. PSYCHEDELIC Spectrum Signature

### Ideal Psychedelic Visual Profile

```
Full-Spectrum Presence:
- Energy across entire 20 Hz - 20 kHz range
- Movement and modulation (spectrum constantly changing)
- Harmonic complexity (multiple simultaneous peaks)
- Extended highs with reverb tails
```

**Visual Characteristics:**
- Dynamic, moving spectrum
- Rich harmonic content (many frequency peaks)
- Wide stereo field (oval vectorscope)
- Visible modulation effects

### Psychedelic Spectroman Checks

✅ **Psychedelic Vibe Confirmed:**
- Spectrum is **moving** (not static)
- Multiple peaks across range (harmonic richness)
- Extended high-frequency content (reverb/delay tails)
- Wide, active vectorscope
- Pulsing or sweeping patterns visible

### Creating Psychedelic Spectrum

**Add Movement:**
- Modulation effects (spectrum sweeps/pulses)
- Check: Visible frequency sweeping

**Widen Stereo:**
- Stereo enhancement on pads/synths
- Check: Vectorscope expands to oval

**Extend Highs:**
- Reverb/delay adds high-frequency tail
- Check: Content visible above 12 kHz

**Add Harmonics:**
- Saturation, distortion on synths
- Check: Additional overtone peaks appear

## 3. JAZZY Spectrum Signature

### Ideal Jazzy Visual Profile

```
20-40 Hz:    Blue/minimal (natural, not boosted)
40-80 Hz:    Green/yellow (acoustic bass fundamental)
80-200 Hz:   Yellow/green (bass harmonics)
200-500 Hz:  Yellow/red (warmth and body)
500-2k Hz:   Red/yellow (instrumental presence)
2k-5k Hz:    Yellow/green (natural clarity)
5k-10k Hz:   Green/cyan (cymbals, brass overtones)
10k-20k Hz:  Cyan/blue (gentle natural roll-off)
```

**Visual Characteristics:**
- Mid-range focused (200 Hz - 5 kHz)
- Natural roll-off (not hyped)
- Warm and balanced
- Smooth spectral shape (not aggressive)

### Jazzy Spectroman Checks

✅ **Jazzy Vibe Confirmed:**
- Strong mid-range (200 Hz - 5 kHz dominant)
- Natural roll-off in highs (gradual fade)
- Warm low-mids (200-800 Hz presence)
- Not over-processed (smooth spectrum, no sharp peaks)
- Moderate vectorscope width (natural stereo)

### EQ for Jazzy Spectrum

**Enhance Warmth:**
- +2 to +3 dB at 250-500 Hz
- Check: Increased warmth zone presence

**Natural Presence:**
- +1 to +2 dB at 2-4 kHz (clarity without harshness)
- Check: Smooth boost, not spike

**Gentle High-End:**
- Slight roll-off above 12 kHz (natural)
- Avoid boosting above 10 kHz artificially
- Check: Gradual fade to blue

**Preserve Dynamics:**
- Light compression (spectrum stays dynamic)
- Check: Spectrum varies with musical dynamics

## 4. VIBEY Spectrum Signature

### Ideal Vibey Visual Profile

```
20-40 Hz:    Blue/minimal (clean foundation)
40-80 Hz:    Yellow (controlled bass)
80-200 Hz:   Yellow/red (warmth and fullness)
200-500 Hz:  Yellow/green (body and emotion)
500-2k Hz:   Red/yellow (musical core)
2k-5k Hz:    Yellow/green (smooth clarity)
5k-10k Hz:   Green/cyan (spacious without harshness)
10k-20k Hz:  Cyan/blue (delicate air)
```

**Visual Characteristics:**
- Smooth, lush distribution (no harsh peaks)
- Full mid-range (body and warmth)
- Reverb presence in highs (5-12 kHz)
- Balanced but rich

### Vibey Spectroman Checks

✅ **Vibey Vibe Confirmed:**
- Smooth spectrum (no sharp spikes)
- Lush mid-range (500 Hz - 5 kHz full)
- Reverb/delay visible (extended highs)
- Warm without mud (controlled 200-500 Hz)
- Moderate to wide vectorscope (immersive)

### EQ for Vibey Spectrum

**Add Richness:**
- +2 dB at 200-400 Hz (warmth)
- +1 to +2 dB at 1-2 kHz (fullness)
- Check: Fuller, richer visual profile

**Smooth Clarity:**
- +1 dB at 3-4 kHz (clarity without harshness)
- Gentle, wide Q (smooth boost)
- Check: No sharp peak, smooth rise

**Add Space:**
- Reverb extends spectrum into 5-15 kHz
- Check: Visible reverb tail in highs

**Avoid Harshness:**
- Cut 5-7 kHz if harsh
- Check: Smooth spectrum, no red spikes
