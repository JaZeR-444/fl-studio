# BassDrum Design Rules

## Rule 1: Tune to Root
- Always set the **Base** frequency to the root note of your song.
- This ensures the kick doesn't clash with the bassline and creates a "solid" low-end foundation.

## Rule 2: Sub-40Hz Safety
- Avoid setting the **Base** frequency below 30Hz for club tracks, as most sub-woofers cannot reproduce it and it will just eat up headroom.
- **Sweet Spot:** 40Hz to 55Hz.

## Rule 3: Sample Isolation
- Never play a sample with its low-end intact if you are using the synth oscillators.
- **Rule:** Always use the high-pass filter on the **Sample** tab to cut below 200Hz.

## Rule 4: Mono Compatibility
- Keep the Main Oscillator 100% Mono.
- Use the Sample layer or Slave oscillator for any stereo widening (if absolutely necessary), but keep the sub-frequencies centered.
