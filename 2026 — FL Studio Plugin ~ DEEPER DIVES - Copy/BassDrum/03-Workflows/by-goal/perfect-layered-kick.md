# Perfect Layered Kick Workflow

1. **Sub:** Set Main Osc to Sine. Tune Base to your root note.
2. **Attack:** Load an acoustic kick "top" sample into the Sample slot.
3. **Filter:** Set Sample Filter to **High Pass**. Cut everything below 300Hz.
4. **Phase:** While playing the kick, slowly turn the Slave **Phase** knob until the low end feels "thickest".
5. **Snap:** Add a tiny bit of the **Click** generator for extra cut-through.
