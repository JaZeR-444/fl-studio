# Genre Style Board: Speech Synthesizer

## Hip-Hop
- **Technique:** "The Robot Producer Tag." Instead of a human tag, use the **Classic** voice with the **Monotone/Sing** style. Use the `(Note)` syntax to make the tag "sing" the hook's first note.
- **Reference Idea:** Think of the technological, AI-influenced producer tags in early Pierre Bourne or Pharrell Williams productions.

## Rap
- **Technique:** "Demonic Ad-libs." Render short aggressive words (e.g., "Yeah!", "Go!") using the **Giant** voice pitched down 2 octaves. This creates a "heavy" backdrop for hype verses.
- **Reference Idea:** The deep, processed ad-libs found in dark trap (21 Savage, Travis Scott).

## R&B / Pop-Hip-Hop
- **Technique:** "Textural Whispers." Use the **Whisper** mode to render short, intimate phrases. Pan them wide and place them at the start of the chorus.
- **Reference Idea:** Intimate vocal breathiness in modern R&B like Summer Walker or Brent Faiyaz.

## Key Technique References
- **Melodic Syntax:** `(C5)Hello`. [SRC: IL-MAN-06]
- **Special Formats:** Using `.SPEECH` files in Slicex for word detection. [SRC: IL-KB-06]
- **Robotic Stretches:** Using Fruity Granulizer on speech renders. [SRC: REPUTABLE-07]
