# Workflow Recipes

## Recipe 1: The Phase-Check Protocol
Whenever layering in BassDrum, follow this routine:
1.  Turn **Sample Level** to 0. Listen to Main Osc.
2.  Turn **Sample Level** up.
3.  Close your eyes.
4.  Sweep the **Sample Delay** knob slowly.
5.  Stop when the transient sounds "tightest" (loudest impact).
6.  If using Slave Osc, do the same with the **Slave Phase** knob.

## Recipe 2: Random Kick Generator
1.  Load BassDrum.
2.  Go to the FL Studio Plugin Menu (Triangle top left).
3.  Select **"Randomize"**.
4.  *Warning:* BassDrum randomizes well, but watch your speakers (Volume can jump).
5.  **Refine:** Usually, you just need to re-tune the **Base** frequency after randomizing to get a usable, unique kick.

## Recipe 3: The Ghost Kick (Sidechain Source)
1.  Set **Duration** to minimum (very short).
2.  Set **Click** to max.
3.  Set **Osc Levels** to 0.
4.  **Use:** This creates a tiny, inaudible "tick". Use this audio signal to trigger Compressors (Sidechain) on other tracks without hearing a heavy kick drum sound.

## Recipe 4: Velocity Mapping
1.  Link Note Velocity to **Main Osc Level** (default behavior usually).
2.  Link Note Velocity to **Filter Cutoff** (using Mod X/Y or Patcher).
3.  **Result:** Hard hits are brighter and louder; soft hits are duller and quieter (mimics acoustic drums).
