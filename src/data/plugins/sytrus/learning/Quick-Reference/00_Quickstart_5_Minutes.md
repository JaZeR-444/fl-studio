# Quickstart: Sytrus (5 Minutes)

1.  **Load:** Open **Sytrus** and select the "Default" preset (a single sine wave).
2.  **Harmonics:** Go to the **OP 1** tab and then the **HAR** sub-tab. Draw some bars to add harmonic thickness.
3.  **Matrix:** Go to the **MAIN** tab. Find the grid on the right. 
    - Drag the knob where **Column 2** meets **Row 1**. This is FM modulation.
4.  **Envelopes:** Go to **OP 1** -> **VOL** -> **ENV**. Click the "Enable" LED and draw a plucky shape.
5.  **Filter:** Go to the **FILT 1** tab. Set it to **Mango Lowpass**.
6.  **Unison:** On the **MAIN** tab, increase the **Order** knob to 3 or 5 for instant width.
7.  **Tip:** Use the **Mod X/Y** pad at the bottom to morph your sound in real-time. [SRC: IL-MAN]
