# Fruity Slicer: Vibe Starting Points - Upbeat, Psychedelic, Jazzy, Vibey

## Upbeat Vibe

**Upbeat = Energetic, bouncy, in-your-face. Fast chops, rhythmic patterns.**

### Quick Setup
```
Sample: Drum loop or vocal phrase
Threshold: 40% (many slices, tight chops)
Crossfade: 5-10 ms (crisp, punchy)
Time Stretch: 1.1x to 1.3x (faster energy)
Pitch: 0 to +3 semitones (brighter)
MIDI Pattern: Dense, rhythmic (1/16th notes)
BPM: 140-160
FX: Light compression, subtle saturation
```

### Listen For
- Fast bounce, aggressive energy
- Crisp transients (no mushiness)
- Rhythmic drive

---

## Psychedelic Vibe

**Psychedelic = Warped, disorienting, experimental. Glitch, stutter, chaos.**

### Quick Setup
```
Sample: Any loop (vocals, synths, drums)
Threshold: 20% (extreme slicing, many tiny slices)
Crossfade: 0 ms (intentional clicks for glitch)
Time Stretch: 0.5x to 2.0x (extreme variation)
Pitch: Random (-12 to +12, automate wildly)
MIDI Pattern: Erratic, stuttering (rapid 1/32nd notes)
BPM: Any
FX: Reverb (crushed), delay (ping-pong), distortion
```

### Listen For
- Obvious artifacts and glitches
- Unpredictable, chaotic character
- Warped, disorienting sound

---

## Jazzy Vibe

**Jazzy = Smooth, swung, vintage. Clean chops with swing timing.**

### Quick Setup
```
Sample: Jazz loop (piano, horns, upright bass)
Threshold: 55% (balanced slicing)
Crossfade: 15 ms (smooth but defined)
Time Stretch: 1.0x (original tempo)
Pitch: 0 semitones (keep original key)
MIDI Pattern: Swung (apply 50-66% swing in Piano Roll)
BPM: 90-120
FX: Vinyl crackle, gentle tape saturation, vintage EQ
```

### Listen For
- Swung, groovy feel
- Vintage warmth
- Natural, organic character

---

## Vibey Vibe

**Vibey = Smooth, groovy, textural. Balanced chops, cohesive atmosphere.**

### Quick Setup
```
Sample: Synth loop, pad, or textured vocal
Threshold: 50% (moderate slicing)
Crossfade: 15-20 ms (smooth and cohesive)
Time Stretch: 0.95x to 1.05x (subtle variation)
Pitch: -1 to +1 semitones (slight detuning)
MIDI Pattern: Flowing, melodic (1/8th notes)
BPM: 100-130
FX: Reverb (subtle), chorus (light), delay (1/8th)
```

### Listen For
- Smooth, flowing texture
- Cohesive atmosphere
- Groove-oriented feel
