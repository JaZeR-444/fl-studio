# Instrument: Lo-Fi Keys

## Best Use Cases
- Main chord progression in Lo-Fi Hip-Hop.
- Emotional R&B intros.
- Dusty background layers.

## Mini-Recipe: "Cracked Vinyl Keys"
1. **Osc:** Saw 40%, Noise 15%.
2. **Filter:** LP 12dB, Cutoff 40%.
3. **Matrix:** LFO (Random) -> Pitch (2%).
4. **FX:** Chorus Mix 40%.
- *Vibe Mapping:* Moody/Vibey.

## Mini-Recipe: "Sunday Jazz Keys"
1. **Osc:** Saw 50%, Sub 10%.
2. **Env:** Attack 40ms, Release 400ms.
3. **Matrix:** Velocity -> Filter (50%).
- *Vibe Mapping:* Jazzy.
