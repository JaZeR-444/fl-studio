# Goal: Vibe - Psychedelic

## Goal Statement
Create a "hollow," moving sound that warps through the stereo field and changes character over time.

## Step-by-Step Setup
1. **Filter:** LP Mix 50%, HP Mix 50% (Notch Filter).
2. **Modulation:** LFO -> Cutoff (Amount 40%, Speed 2Hz).
3. **Ring Mod:** Turn up **Ring Mod** to 30% for metallic overtones.
4. **Chorus:** Max Chorus Mix.
5. **Acoustics:** Add an external Delay with high feedback.

## Automation Idea
- **LFO Speed:** Speed up the LFO over 4 bars to create a "spiraling" tension.
